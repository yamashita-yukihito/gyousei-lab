## 使い方

○×学習の「ことばで探す」へ **`FP` と入れるだけで、かぶり分野の17枚が通しで出ます。**
出題範囲は「全問題を出す」にしておくと、習得済みも含めて全部出ます。

17枚には「具体的な場面」の最後に**FP2級での問われ方を1文**入れてあります。
解いている最中に「ここはFPとかぶる」と気づけますし、その1文が検索の目印にもなっています。
他の193枚には `FP` が出てこないので、余計なカードは混ざりません。

## カードにしていない論点と、その理由

かぶり分野の47論点のうち、次はカードにしていません。**FP側のページで勉強してください。**

### ① 行政書士試験の直近10年に肢が無い

ラボのカードは「⑤ 実際の肢」に**平成28年度以降の行政書士の過去問**を原文で載せる決まりで、
既存の全カードがこれを持っています。肢が無い論点は、いまの決まりのままでは作れません。
**このうち2回以上出ているものは、末尾の「未決」で扱いを決める必要があります。**

| FP側の論点 | 行政書士での状況 |
|---|---|
| **相続分**（養子・実子は同じ、半血兄弟1/2、配偶者と兄弟姉妹3:1） | 平成19年問35・平成24年問35で止まっている |
| **代襲相続**（相続分・放棄では代襲しない・兄弟姉妹は一代限り） | 平成19年問35・平成21年問35で止まっている |
| 遺言による分割禁止（5年以内） | 直近10年に無い |
| 公正証書遺言の証人欠格 | 直近10年に無い（令和5年問35は共同遺言と撤回だけ） |
| 死因贈与（遺贈の規定を準用） | 直近10年に無い |
| 贈与の諾成性（549条） | 直近10年に無い |
| **借地借家法**（存続期間30年・定期借地・建物引渡しの対抗力・正当事由） | 平成18年問30・平成20年問10で止まっている |

**相続と借地借家法は、FPでは主力なのに行政書士の直近10年では出ていません。**
直近10年の相続枠（問35）は、遺言の方式・遺産分割・配偶者居住権に寄っています。
ただし20年で見れば**2回ずつ出ている**ので、「最近出ていないから薄い」とは言えません。
末尾の未決事項です。それまではFP側のページで回してください。

### ② そもそも行政書士試験の範囲外

かぶり分野の資料自身が「行政書士試験での直接出題はほぼない」「試験科目ではない」としています。

- **区分所有法**（共用部分の持分・建替え決議5分の4・敷地利用権の分離処分禁止）
- **都市計画法・開発許可**（区域区分・用途地域・開発許可の例外）
- **不動産登記法の手続**（甲区・乙区・登記事項証明書の交付請求）

区分所有法は民法の「共有」の理解には効くので、`min-property-co-ownership-claims-001` を
読んでおくと橋渡しになります。

## 8月〜9月の回し方

- **FP2級までは、検索欄へ `FP` と入れて17枚を回す。**
- カードにできなかった論点は、FP側のページ（`/services/sakura-tools/quiz/fp2_gyosei_overlap/`）で回す。
  そちらには行政書士の条文・判例・実際の肢が重ねてあります。
- **9月のFP学科が終わったら、行政書士の全210枚へ戻る。** かぶり分野は先に済んでいるので、
  行政法・憲法・基礎知識へ時間を寄せられます。

かぶり分野は民法と基礎知識に集中していて、**行政法（112点・最大の得点源）とは重なりません**。
FP対策の時間が行政書士の行政法を削らないよう、8月中は行政法へ手をつけないと割り切るか、
少しだけでも触れておくかは、9月の残り時間を見て決めてください。

## 決定済み: 旧10年にしか出ていない論点（2026-08-03・A案を採用）

平成18〜27年度の肢も⑤へ出せるようにし、次の4つをカード化しました。
⑤の肢はe-Govで現行法の正誤を確かめてあり、画面に「現行法で再確認済み」と出ます。

| 論点 | カード | 頻出度 |
|---|---|---|
| 法定相続分と養子の相続分 | `min-inheritance-statutory-share-001` | 重要論点 |
| 代襲相続の原因（欠格・廃除・放棄） | `min-inheritance-substitution-cause-001` | 繰り返し出題 |
| 相続放棄の効果と詐害行為取消権 | `min-inheritance-renunciation-effect-001` | 重要論点 |
| 借地借家法が適用される範囲 | `min-contract-leased-land-act-scope-001` | 重要論点 |

**この4枚にもFP2級での問われ方を書いてあるので、検索欄の `FP` で一緒に出ます（21枚）。**

**遺留分（1042条・1046条）だけは作れていません。** 2回のうち1回が記述式（平成24年問46）で、
記述式は⑤へ出さない決まりのためです。FP側のページで回してください。

上の「カードにしていない論点」のうち、遺言による分割禁止・公正証書遺言の証人欠格・死因贈与・
贈与の諾成性は**20年で1回だけ**なので、線引きどおり作りません。
