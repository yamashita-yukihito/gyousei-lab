# gyousei-lab で行政書士試験に受かるために

- **作成日**: 2026-07-31
- **作成者**: Antigravity (Claude Opus 4.6)
- **目的**: 現在の gyousei-lab の強みと弱みを分析し、2026年11月8日の本試験に向けて何を優先すべきかを提案する

---

## 1. 現状の評価

### このツールの強み

学習エンジンの設計が堅い。1人用の学習ツールとしてはかなり作り込まれている。

- **A → B → C の段階表示**。肢の原文（A）→ やさしい言い換え2案（B1/B2）→ 最短要約（C）→ ○×回答 → correction + deepDive + commonSenseChallenge という流れは、「条文の要件を自分の言葉で言い換えられるか」を鍛える構造になっている。市販の一問一答にはない独自の強み。
- **回答履歴が全部残る追記型設計**。正答率の推移、連続不正解、忘却リスクまで追跡している。弱点分析に使えるデータが日々積み上がっている。
- **弱点分析エンジンが稼働中**。6段階の判定（unlearned → learning → watch → weak → recovering → mastered）で、苦手カードを自動抽出して優先出題してくれる。
- **カードを画面から直接編集**できる。学習中に「この解説わかりにくい」と思ったらその場で直して、正本JSONとbundleが自動再生成される。
- **高速○×モード**。1問10秒のタイマー付きで、反射的な知識の引き出しを訓練できる。
- **過去問原文での演習画面**もある。択一・多肢選択・記述式の3形式に対応。
- **コンテンツの品質が高い**。deepDive 100%、commonSenseChallenge 100%、relatedPastQuestions 100%。カード1枚あたりの情報密度が市販教材を上回っている。

### 足りないところ

率直に言って、**カード枚数が試験全体をカバーするには少ない**。

### コンテンツ面の課題

1. **行政法65枚は、112点分の得点源としてはまだ少ない。** 択一19問で16問取る目標なら、論点の網羅度を上げる必要がある。行政手続法・行政不服審査法・行政事件訴訟法の三法が主軸だが、地方自治法と国家賠償法もコンスタントに出る。**100〜120枚** が目安。

2. **民法30枚で6/9問は厳しい。** 民法は範囲が広く、総則・物権・債権総論・債権各論・親族相続から満遍なく出る。記述式2問（40点分）もここから出る。**60〜80枚** は欲しい。

3. **基礎知識39枚は足切り回避には十分な規模になりつつある。** 個人情報保護法、行政のデジタル化、情報通信が押さえてあれば、文章理解3問とあわせて11/14は視野に入る。**50枚** まで増やせれば安心。

4. **憲法24枚は悪くない。** 主要判例が入っていれば4/5問は狙える。あと10〜15枚、統治機構の基本と近年の重要判例を補強すれば十分。

5. **商法24枚、基礎法学12枚は配点比で十分。** これ以上増やすより他に投資すべき。

## 3. 機能面の提案

### 優先度: 高（合格に直結する）

#### 3.1 間隔反復（スペースドリペティション）の導入

**これが最大のリターンを生む機能追加。**

現状は弱点分析で復習推奨が出ているが、「今日どのカードを復習すべきか」の計算がない。194枚＋今後の追加分を残り100日で効率的に回すには、間隔反復が必須。

提案:
- フルのSMアルゴリズムは不要。シンプルなルールで十分:
  - 初回正解 → 1日後
  - 2回連続正解 → 3日後
  - 3回連続正解 → 7日後
  - 4回連続正解 → 14日後
  - 間違え → 翌日に戻す
- **「今日の復習」ビュー** を追加。復習期日の来たカードを優先表示する。
- 既存の `card_attempts` テーブルから算出できるので、追加テーブルは不要かもしれない。

#### 3.2 記述式対策の強化

**配点60点（全体の20%）。** 目標は20点だが、ここで30点取れると合格がかなり安定する。

現状:
- 記述式画面は実装済み（`written` タブ）。下書き保存と模範解答表示がある。
- 過去問30問が bundle に入っている。

提案:
- **キーワード穴埋め練習モード** — 模範解答の法律用語を空欄にして入力させる。40字の文を構成する訓練。
- **キーワード一致チェック** — 模範解答のキーワードと自分の解答を比較し、含まれているキーワード数を表示。完全な自動採点は不要。
- 記述式は行政法1問（取消訴訟系が多い）＋民法2問（請求の根拠条文を書かせる）。条文番号・要件・効果のセットを素早く書けるかが勝負。

#### 3.3 確信度ダッシュボードの実装

ARCHITECTURE.md のロードマップにもある。**データ記録は済んでいるのに表示がない**のはもったいない。

- 「理由まで言える / なんとなく / 勘」の3段階で、表面得点と確信得点を分けて表示する。
- 「勘で当たった170点」と「理由まで言える170点」は全く別物。後者が180点を超えているかが合否の分かれ目。

### 優先度: 中（学習効率の向上）

#### 3.4 「今日のノルマ」ダッシュボード

- 試験まで残り○日、未学習カード○枚、今日の新規○枚・復習○枚。
- 学習ペースが目標に対して足りているか一目でわかる。
- 間隔反復と組み合わせると効果が高い。

#### 3.5 模擬試験モード

- 科目混合、制限時間付き（択一は1問2分目安）。
- 終了後にスコアと科目別内訳を表示。
- 「本番のペースで解く」感覚を養う。高速○×とは別の訓練。

#### 3.6 間違い理由のタグ付け

- 間違えた時に「混同 / 知らなかった / ケアレスミス」を選ばせる。
- 弱点分析に「なぜ間違えるか」の次元が加わる。
- ARCHITECTURE.md のロードマップにも誤答理由タグ付けが載っている。

#### 3.7 条文逆引き

- `legalBasis` フィールドから逆引きインデックスを作り、「行政手続法8条に関連するカード」を一覧する。
- 条文素読 → 関連カードの復習、という動線。

### 優先度: 低（あれば便利）

#### 3.8 comparisonTable の拡充

- 現在15枚にしか付いていない。混同しやすい制度の比較は直前期に特に効く。
- 行政三法比較だけでなく、民法の担保物権の比較、相続の法定相続分の整理なども有用。

#### 3.9 モバイル対応の確認

- 電車や隙間時間での学習に重要。現状のUIがスマホで使えるか要確認。

### フェーズ1: 8月中（最優先）

|---|---|---|---|
| **行政法** | 65 → 100枚 | +35枚 | 112点の得点源。三法以外（地方自治法、国賠法）を補強 |
| **民法** | 30 → 60枚 | +30枚 | 76点、記述式2問。債権各論と担保物権が手薄 |

民法で特に補強すべきトピック:
- **債権各論**: 契約類型（売買・賃貸借・請負・委任）、不法行為、使用者責任、工作物責任、不当利得
- **担保物権**: 抵当権（物上代位、法定地上権、共同抵当）、質権、留置権、先取特権
- **親族・相続**: 法定相続分、遺留分、遺言の方式、特別受益、寄与分

行政法で補強すべきトピック:
- **地方自治法**: 直接請求、議会の権限、長の権限、監査委員
- **国家賠償法**: 1条責任と2条責任の要件、求償権
- **行政事件訴訟法**: 仮の救済（執行停止、仮の義務付け、仮の差止め）

| 科目 | 現在 → 目標 | 追加数 | 理由 |
|---|---|---|---|

基礎知識で押さえるべき:

- 統治機構の基本（衆参の権限差、内閣の権限、違憲審査制）

- comparisonTable を拡充して「似た制度の混同」を防ぐ。
- 記述式の答案練習を重点的に。

## 5. 率直な意見

**このツールは合格するための基盤として十分な設計がある。** 問題はツールの機能ではなく、コンテンツ量とそれに基づく反復の量。

行政書士試験の合格率は10〜12%だが、合格者の多くは:
- 過去問を最低3周
- 条文を繰り返し読む
- 記述式の答案練習を20〜30回
- 模試を2〜3回受ける

このツールがあれば「過去問の周回」と「弱点の可視化」は市販教材より効率的にできる。弱点分析+高速○×の組み合わせは反復効率が高い。

**足りないのは3つ:**
1. **民法・行政法のカード量**（記述式対策を含む）
2. **間隔反復**（今日何を復習すべきかの管理）
3. **記述式の答案練習**

**機能開発に時間を使いすぎないこと。** 残り100日で最も価値があるのは、新機能を作ることではなく、カードを増やして回すこと。間隔反復と記述式モードの2つだけ実装して、あとは民法と行政法のカードを増やす。それが合格への最短距離だと思う。
