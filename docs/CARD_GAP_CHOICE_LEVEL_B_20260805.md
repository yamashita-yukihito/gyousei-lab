# 作業B: 肢単位の棚卸し（2026-08-05）

`ARCHITECTURE.md` 12.1 の作業B。これまでの棚卸しは**問題単位**で「済／未参照」を見ていた。
カードが1肢でも⑤に貼っていれば、その問題は「済」になる。1問5肢なので、
済の問題にも未カード化の論点が残る。そこを肢の単位で洗った。

## 1,142肢の絞り込み方

**全部読むのではなく、語で束ねてカードのsubtopicと突き合わせた。**
行政法・民法・憲法・商法・基礎知識の主要な制度名と条文用語およそ260語について、
「⑤に貼っていない肢に何本出てくるか」を数え、**どのカードのsubtopicにも出てこない語**だけを残した。

6本以上残ったのは7語だけだった。

**1,142という数は穴の上限であって、実際の穴はごく少ない。**
ほとんどの肢は、その論点のカードが既にあって、別の肢が⑤に貼ってあるだけだった。
