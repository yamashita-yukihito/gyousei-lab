## このセッションの決め事

- 条文は e-Gov 法令API v2 の `asof=2026-04-01` で確かめる（`scripts/drill_d/law.py` と同じ取り方）。e-Gov の版情報では、民法は令和6年法律第33号（共同親権・財産分与の5年・法定養育費など）が **2026-04-01 施行**で、基準日の条文に入っている。刑法等の拘禁刑への一本化（令和4年法律第67号・第68号）は 2025-06-01 施行。
- 判例の結論は、判例名と年月日が確かなときだけ直す。裏が取れないものは直さず、要確認に書く（指示書 §3）。
- 進め方: 1バッチ（カード20枚）ごとに、点検役のエージェント2体（10枚ずつ）が全項目を条文と照らし、指摘だけを別の検証役に**理由と直し方を伏せて**判定させる。両者が誤りと判定し、e-Gov の条文で確かめたものだけを直す。
- 「修正の記録」のコミット欄は、コミットの件名の末尾に付けた点検番号（例: `T2-1`）。`git log --grep "T2-1"` で引ける。
