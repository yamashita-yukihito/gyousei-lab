# 回答：カードの穴の残り調べ（2026-10-21依頼・2026-10-22回答）

- 対象依頼: `docs/CARD_GAP_NEXT_REQUEST_20261021.md`
- 回答者: Mac側のClaude Code
- 状態: **完了（2026-10-22）。** 利用者の判断で、候補のうち20年で3問以上の31論点をカード化し（251→282枚）、多肢選択式で見つかった既存カードの出題を頻出度監査へ反映した。D案の `cardId` は54問ぶん足した（76→130問）。詳細は §10。

## 結論

1. **D案の未連携は108問あった**（依頼文の99問は、10月に足した144問のうちの数。初版40問の9問を数えていなかった）。
   - **40問は既存カードに答えが書いてあったので、`cardId` を足した**（D案の結びは76問→116問）。
   - **30論点**は、20年で2回以上出ていて⑤に出せる肢もあるので、カード候補になった。
   - 25論点は見送った（1回だけ・記述式と改題しか無い・法改正で使える出題が0）。
2. **旧10年の多肢選択式は読めた。** 作業A5と依頼文は「取得元データに本文が無く読めない」としていたが、抽出データの `passageText`・`wordBank`・正解に30問ともそろっている。誤りは、本文を `questionText` で探していたこと。**直近10年の多肢30問も、これまで論点の棚卸しをしていなかった**ので、あわせて60問を読んだ。
3. **多肢選択式と「却下・棄却」の肢からは、行政法の大きな穴が見つかった。** 20年で5〜14問出ているのに、カードが1枚も無い論点が11ある。訴訟の却下と棄却の区別（14問）、事情判決・事情裁決（9問）、争点訴訟（8問）、裁決の種類（7問）、裁量基準（7問）などである。
   それでも8月の棚卸しで見えなかったのは、2つの理由による。(1) 棚卸しが問題単位だったので、1肢でも⑤に貼ってある問題は「済」になった。(2) 多肢選択式は、⑤とAに使えないので棚卸しから外していた。
4. **却下・棄却は、1枚の論点にしないほうがよい。** 答えを決めているルールが別々なので、「訴訟の却下と棄却」「裁決の種類」「事情判決・事情裁決」などに分けて立てる（下の表に入れた）。

## 1. 調べた範囲と方法

| 対象 | 件数 | 方法 |
|---|---:|---|
| D案の `cardId` の無い問 | 108問 | 1問ずつ、既存251枚の全文（A・correction・解説・⑤）に答えがあるかを見た。無ければ論点ごとに20年分を数え直した |
| 多肢選択式 | 60問（旧10年30・直近10年30） | 本文と正解を読み、論点を特定した。既存カードの出題に当たるか、新しい論点かを判定した |
| 却下・棄却を含む直近10年の肢 | 24本（⑤に未貼付21本） | 肢ごとに、答えを決めるルールがカードにあるかを見た。無いものを論点に束ねて数えた |

- 13組に分けて調べた。どの組も、**分析した担当とは別の担当が独立に検証した**。検証担当は、結びをカード全文で確かめ直し、出題を言い換えの語で引き直して数え直した。
- 検証で判断が変わったのは3件。いずれも検証側を採った。
  - 被害者側の過失：1問→2問（平成24年問34肢アを追加）
  - 債権者代位権の転用：1問→2問（記述式の令和4年問46を追加）
  - 共同保証人の分別の利益：2問→0問（数えた2問は、共同保証人間の求償の問題だった）
- 数え方は `AGENTS.md` §5.3 による。
  - 問題単位で数える。同じ命題・逆向き・条件・例外・比較を数え、same_topic は数えない。
  - 記述式・多肢選択式も1問と数える。ただし⑤とAには使わない。
  - 法改正で結論が変わった出題は数えない（2017年債権法改正・2018年相続法改正など）。
- 作業データ（読み取り専用の調査結果）は、セッションの作業用フォルダにだけ置いた。リポジトリには入れていない。
