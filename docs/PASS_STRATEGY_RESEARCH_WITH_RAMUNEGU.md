# 最重要追加調査：ラムネグさんの13記事を学習アプリ設計へ落とし込む

## この章の位置づけ

この章では、ラムネグさんの行政書士試験カテゴリ全13記事を、単なる「昔の合格体験記」ではなく、**行政書士 過去問ラボの学習モデル・データモデル・復習アルゴリズムを設計するための主要参考資料**として分析する。

ラムネグさんの個別教材名や2015年度当時の法令知識をそのまま移植するのではない。現在も使える本質は、次の考え方にある。

> **科目・分野・知識の種類によって、覚える濃さ、問題演習の量、条文を読む量、理解と暗記の比率を変える。**

この思想は、すべての問題を同じ形式の○×カードに変換する学習アプリよりも、**知識ごとに異なる学習体験を出し分けるアプリ**と相性がよい。

### 参考にするときの注意

- 受験年度は2015年度であり、現在とは民法、会社法、個人情報保護法、基礎知識の範囲が異なる。
- 2024年度から旧「一般知識等」は「行政書士の業務に関し必要な基礎知識」へ変更された。
- 紹介されている教材・Webサイトには、絶版、旧法対応、更新停止のものがある。
- 「基本テキストは5割」「過去問と同じ論点はほとんど出ない」などは本人の体感・評価で、公式統計ではない。
- 合格経験は1回であり、予備校の多数受講生データではない。

よって、**内容の新しさではなく、学習設計の抽象モデルを採用する**。

## C. ラムネグ式の中心概念：「暗記の濃度」

### 1. 何を意味するか

ラムネグさんのいう「暗記の濃度」は、単純な重要度ではない。

同じAランク論点でも、必要な学習状態が異なる。

| 知識の種類 | 目標状態 |
|---|---|
| 行政手続法の法的義務・努力義務、期限、準用、適用除外 | 正確に再生し、似た条文と区別できる |
| 行政法・憲法判例 | 事件の背景と、なぜその結論になったかを大まかに説明できる |
| 民法 | 結論を暗記するだけでなく、本人保護・取引安全・帰責性等から推理できる |
| 商法・会社法 | 全条文暗記ではなく、広い論点に何度も触れ、誤肢を切れる |
| 基礎知識の一般知識 | 完全再生ではなく、明らかな誤りを排除できる |
| 文章理解 | 知識ではなく、制限時間内に処理できる |

現在の「○×カード」という単一形式だけでは、この違いを表現しきれない。

### 2. 推奨するデータ項目

各問題・肢・カードに、少なくとも次のメタデータを持たせる。

```yaml
subject: 行政法
subfield: 行政手続法
topic: 申請に対する処分
knowledge_type: statute_exact
required_depth: 5
exam_format:
  - five_choice
  - multi_select
source_type: official_past_exam
legal_basis:
  - 行政手続法5条
related_topics:
  - 審査基準
  - 標準処理期間
confusion_targets:
  - 処分基準
  - 理由提示
mastery:
  correctness: 0.82
  confidence: B
  explanation_possible: false
  last_reviewed: 2026-07-27
```

### 3. `knowledge_type` の候補

| 値 | 意味 | 適した画面 |
|---|---|---|
| `statute_exact` | 条文の主体・期限・義務・例外を正確に区別 | 条文比較、穴埋め、○× |
| `case_story` | 判例の背景・争点・理由・結論 | ストーリー表示、時系列、理由選択 |
| `legal_reasoning` | 未知事例を原理から推理 | 事例変形、理由記述、類似事例比較 |
| `term_relation` | 専門用語間の位置関係 | 概念図、比較表 |
| `broad_recognition` | 広く浅く触れ、誤肢を排除 | 高速○×、用語フラッシュ |
| `reading_skill` | 読解処理 | タイムアタック |
| `written_output` | 記述式の法的部品を組み立てる | 記述ビルダー |

### 4. `required_depth` の候補

| 深度 | 到達目標 |
|---:|---|
| 1 | 見たことがあり、明らかな誤肢を切れる |
| 2 | 用語と基本結論を選べる |
| 3 | 原則・例外、類似制度を区別できる |
| 4 | 理由・要件・効果を説明できる |
| 5 | 条文表現、期限、主体、準用、例外まで正確に再生できる |

例：

- 行政手続法、行政不服審査法、行政事件訴訟法の主要条文：4～5
- 民法の主要論点：4
- 行政法・憲法判例：3～4
- 地方自治法：2～3
- 商法・会社法：2～3
- 基礎法学：1～2
- 政治・経済・社会：1～2
- 行政書士法・個人情報保護法：3～5

これはラムネグさんの考え方を2026年度向けにアプリ仕様へ翻訳した提案であり、本人がこの数値分類を示したわけではない。

## D. 最重要機能：「確信のない170点」を見抜く

ラムネグさんの学習時間記事で、開発上最も重要なのは「200時間」「300時間」「500時間」という数字そのものではない。

本質は、

> **170点を取れていても、多くの問題が2択や推測なら、安定して170点の実力があるわけではない。**

という指摘である。

本人の体感では、基本テキスト・過去問・行政法条文・憲法判例までで、約200時間時点に170点程度取れるようになったが、ほとんどの肢を絞り切れない状態だった。そこから曖昧さを減らして10点を上げるのに、さらに約100時間必要だったと分析している。

### 回答後の自信度

正誤だけでなく、必ず次を記録する。

| 記号 | 状態 |
|---|---|
| A | 根拠を説明して正解した |
| B | 2択まで絞って正解した |
| C | 3択以上・勘で正解した |
| D | 不正解だが論点は分かっていた |
| E | 未学習・見当がつかなかった |

### ダッシュボードに表示すべき点数

- 表面得点：通常採点
- A得点：確信正解だけの点数
- A+B期待得点
- 推測で上振れした点数
- 2択で落とした点数
- 「正解したが説明不能」の問題数
- 初見問題だけの点数
- 過去に解いた問題だけの点数

例：

```text
模試換算：188点
確信正解換算：152点
2択から得た点：28点
3択以上の推測：8点
安定合格度：要改善
```

この機能は、単なる正答率より価値が高い。現在の過去問569問を何周もすると、問題文や正解番号を覚えて表面得点だけ上がるためである。

## E. 過去問ラボに対するラムネグ式の重要な警告

### 現在の強み

- 直近10年・全6科目569問を収録済み
- 行政法55枚、民法25枚の○×カード
- LAN内の自作環境なので、データ構造や出題ロジックを自由に変えられる

### 最大のリスク

サービス名が「過去問ラボ」であるため、無意識に、

> 過去問を完全に覚えれば試験範囲を覆える

という設計になりやすい。

ラムネグさんは、民法10年分なら択一約90問、商法・会社法なら約50問しかなく、広い条文・判例範囲の問題演習として不足すると指摘している。

この主張は「過去問は無価値」という意味に変換してはいけない。アプリでは役割を分ける。

| 問題群 | 役割 |
|---|---|
| 公式過去問 | 本試験の文体、難度、論点、5肢比較を学ぶ |
| 条文変形問題 | 主体、期間、例外、義務・努力義務の未出パターンを補う |
| 判例変形問題 | 結論と理由の入替え、他判例との混同を防ぐ |
| 他資格良問 | 民法・会社法の演習量と事例推理を補う |
| AI生成問題 | 未出組合せ・類似制度比較を増やす。ただし法令・判例根拠と人間確認が必要 |
| 初見模試 | 暗記した過去問では測れない実力を測る |

### 必要なカバレッジ表示

論点ごとに、問題数だけでなく次を表示する。

```text
無権代理
公式過去問：8肢
条文変形：12肢
事例変形：6問
記述候補：2問
最終初見日：18日前
カバレッジ：不足
```

過去問がない論点を「出ない論点」と判断しないための機能である。

## F. 科目別に変えるべき画面・出題方式

## F-1. 行政法

ラムネグさんは行政法を次のように分解した。

| 分野 | 学習の中心 |
|---|---|
| 行政法総論 | 専門用語＋判例 |
| 行政手続法 | 条文 |
| 行政不服審査法 | 条文＋一部判例 |
| 行政事件訴訟法 | 条文＋判例 |
| 国家賠償法 | 判例 |
| 地方自治法 | 条文を薄く広く |
| 国家行政組織法等 | 条文、低優先度 |
| 国家公務員法等 | 時間がなければ後回し |

### 実装

1. **三法比較表**
   - 主体
   - 対象
   - 期間・起算点
   - 執行停止
   - 教示
   - 理由提示
   - 審理員・行政不服審査会
   - 準用
   - 適用除外

2. **条文差分問題**
   - 「しなければならない」対「努めなければならない」
   - 公にする義務対努力義務
   - 期間の数字
   - 主体の置換え
   - 「処分」対「裁決」

3. **判例ストーリー**
   - 何が起きたか
   - 誰が何を争ったか
   - 処分性・原告適格等の判断理由
   - 結論
   - 似た判例との違い

4. **行政法内でも深度を変える**
   - 三法：深度5
   - 総論・国賠判例：深度3～4
   - 地方自治法：深度2～3
   - 周辺法：深度1～2

## F-2. 民法

ラムネグさんの民法論の核心は、過去問暗記ではなく、理由から未知事例を推理することである。

### 実装

1. 各解説に「なぜ」の欄を必須化
   - 本人保護
   - 取引安全
   - 帰責性
   - 信頼保護
   - 法律関係の早期確定
   - 不当利得の防止
   - 公示・外観への信頼

2. **事例の一要素だけ変更**
   - 善意→悪意
   - 無過失→過失あり
   - 本人→相手方
   - 追認前→追認後
   - 時効完成前→完成後
   - 登記前→登記後

3. **結論だけでなく理由を選択**
   - 正解肢を選んだ後、「最も近い理由」を選ばせる
   - 理由を誤った場合はB判定以下

4. **行政書士過去問外の良問**
   - 現行法対応の公務員、司法書士、宅建等から、難度・範囲を調整して取り込む
   - 出典・法令基準日・改題有無を必ず保持する

5. **記述への接続**
   - 制度名
   - 要件
   - 主体
   - 相手方
   - 効果
   を部品化する

## F-3. 憲法

### 実装

- 判例の長文をそのまま暗記させず、まず事件の物語を読む
- 「結論は正しいが理由が別判例」の誤肢を生成
- 判断枠組みカード
  - 厳格な審査
  - 合理性の基準
  - 目的・手段審査
  - 検閲
  - 事前抑制
- 条文は全文を短期間で回せる音読・高速表示モード
- 統治分野の数字だけを集めたカード

## F-4. 商法・会社法

現在の8点目標は妥当だが、ラムネグさんは広く浅い演習3周で4/5を取った。

### 実装

- 設立
- 株式・株主
- 株主総会
- 取締役・取締役会
- 監査役等
- 商人・商行為
- 商号
- 支配人・表見支配人
- 商事売買

について、各論点の深い講義よりも高速○×を多く用意する。

**カード枚数の目安を増やすより、同じ条文から複数の誤肢パターンを作る**。

例：

```text
会社法A条の原文
├─ 主体を変更
├─ 決議要件を変更
├─ 期間を変更
```

## M. この追加調査からの最終結論

ラムネグブログが開発の参考になる最大の理由は、教材のおすすめが優れているからではない。

> **行政書士試験の知識は、すべて同じ方法・同じ深さ・同じ問題数で学ぶべきではない**

ということを、科目別に具体化しているからである。

行政書士 過去問ラボの次の進化は、カードを80枚から数百枚へ増やすことだけではない。

1. 各知識に必要深度を付ける
2. 条文・判例・推理・広い認知を別形式で学ぶ
3. 過去問の外側を可視化する
4. 正解の中にある「2択・勘・丸暗記」を見抜く
5. 高速周回と初見実戦を分離する
6. 科目横断の混同をリンクで潰す

この6点を実装することが、ラムネグ式を現代の学習アプリに移植することになる。

- 勉強時間：<https://blog.dododori.com/shikaku/gyosei/g-hour/>

# 2. 現在の得点計画への指摘

## 2-1. そのままでよい点

### 行政法を最大の得点源にする

妥当です。令和7年度の小花さんは17/19、はまなすさんは16/19、2015年度のラムネグさんは18/19でした。行政手続法・行政不服審査法・行政事件訴訟法を深くし、地方自治法は完璧を狙わない方針も合理的です。

ただし、「行政法88点」は択一・多肢・記述を混ぜた数字なので、次のように形式別に管理した方がよいです。

- 行政法5肢択一：16/19＝64点を本命、17/19＝68点を上位目標
- 行政法多肢：8空欄中6～7個＝12～14点
- 行政法記述：8～12点を予定得点

これで合計84～94点程度になります。88点自体は現実的ですが、記述20点満点を前提にしないことが重要です。

### 民法40点

総点としては妥当です。典型的には、

- 択一6/9＝24点
- 記述2問合計16点

で40点です。

ただし、「頻出論点だけ」という表現は危険です。民法記述は、択一で軽視しがちな事務管理・請負・債権者代位・物上代位などからも出ます。頻出分野は深く、その他は用語と基本要件だけ薄く通す、という二段階にすべきです。

### 商法会社法8点・基礎法学4点

妥当です。5問中2問、2問中1問という目標は、投入時間とのバランスがよいです。完全放棄より8点を拾う方が、記述1問分近い保険になります。

## 2-2. 変更した方がよい点

### 基礎知識36点は低すぎる

一般受験生なら36点は標準的な目標ですが、依頼者は過去に56点満点を取っています。さらに、制度変更後の令和6・7年度は、行政書士法等2問・文章理解3問・個人情報保護1問が比較的対策しやすい構成でした。

最近の9事例でも基礎知識の中央値は44点で、9人中8人が40点以上です。したがって、

- **最低目標：40点（10/14）**
- **本命目標：44点（11/14）**
- 上振れ：48点（12/14）

に引き上げるのが合理的です。

広すぎる政治経済社会を大量暗記する必要はありません。行政書士法等、個人情報保護、情報通信の基本、文章理解を固め、一般知識で2～3問拾う形です。

### 192点ではなく、196～200点を安定目標にする

本試験では、普段2時間で解けていた山本さんでも、慎重になって3時間ぎりぎりになっています。記述採点も予想から10点以上ずれる例があります。

したがって、計画上の192点を「合格予定点」にするより、模試で複数回196～200点を出す状態を目標にした方が安全です。

## 2-3. 推奨する形式別の得点計画

| 形式・科目 | 最低ライン | 本命目標 | コメント |
|---|---:|---:|---|
| 基礎法学5択 | 4 | 4 | 1/2でよい |
| 憲法5択 | 12 | 16 | 3～4/5 |
| 行政法5択 | 60 | 64～68 | 15～17/19 |

# 3. 記述式の扱いの結論

## 3-1. 結論

**記述0点でも合格できる設計を理想としつつ、現実の学習計画では20～24点を取りに行く**のが最も合理的です。

記述抜き180点を取るには、基礎知識を含むマーク式240点中75％が必要です。達成者はいますが、今回の最近9例では3人だけでした。記述を完全放棄すると、マーク式で1～2問余計に落としただけで不合格になります。

残り3か月半なら、記述専用対策に全体の10～15％程度を使うのが目安です。これは統計ではなく、本調査からの提案です。具体的には、

- 平日：20～30分、1～2問を「論点→要件→効果→40字」にする
- 週1回：行政法1問＋民法2問を20～25分で書く
- 直前期：公式過去問・模試答案を、キーワード単位で自己採点する

程度です。択一学習と別の暗記科目にせず、択一論点を40字で出力する訓練として統合します。

## 3-2. 専用対策をした人・しなかった人

| 事例 | 対策 | 結果 |
|---|---|---:|
| 水越さん R6 | 模試記述0点後、約3週間毎日記述 | **48点** |
| 小花さん R7 | 記述問題集、問題サイト、模試、過去問。ただし本人は演習不足と評価 | **26点** |
| ゆうさん R6 | 記述専用対策なし | **10点** |
| 山本さん R6 | 直前1週間だけ専用問題集。本人は身につかなかったと評価 | **28点** |
| シンセイさん R7 | 択一を含め長期学習。自己採点20点、公式36点 | **36点** |
| kankoさん R7 | 詳細非公表 | **10点** |

一例だけで「3週間毎日やれば48点」と一般化はできません。しかし、専用対策なしの10点例が複数あり、最低限の答案作成練習には意味があると考えられます。

## 3-3. 部分点の実例

公式は、1問20点という配点と模範解答例は公開しますが、キーワードごとの配点は公表していません。したがって、「この語で必ず4点」と断定はできません。

令和7年度の小花さんは、次の自己分析を公開しています。

- 行政法：正答の中心を外し、「Y市を被告として」だけを書いた
- 民法問45：「日常の家事」「信ずるにつき正当な理由」を書いた
- 民法問46：「事務管理」だけを書いた
- 3問合計の公式得点：26点

出典：<https://note.com/writer_eri/n/nc2c7da0713db?magazine_key=me151c22ac568>

シンセイさんは、民法2問を本人は0点に近いと予想していましたが、3問合計36点でした。

出典：<https://www.pro.goukakudojyo.com/voice/r0753/>

これらから言えるのは、**法的構成を完全に外しても単語だけで必ず点が入る**ということではなく、正しい制度名・当事者・相手方・訴訟類型・要件・効果のうち、正答構成に沿う要素が複数含まれれば部分点が期待できる、という程度です。

学習アプリでは、記述答案を次の部品に分解して採点するのが実用的です。

1. 法律関係・制度名
2. 誰が
3. 誰に対して
4. どの要件で
5. 何を請求・提起できるか
6. 40字前後・問いに対応しているか

## 3-4. 行政法と民法のどちらが取りやすいか

年度横断の公式な科目別平均点は公開されていないため、断定できません。

構造上は、行政法記述は「訴訟類型・被告・理由」など定型部品に落とせる問題が多く、対策によって8～12点を安定させやすい傾向があります。ただし令和7年度のように「裁決固有の瑕疵」という狭い論点が出ると難しくなります。

民法は2問40点あるため得点余地が大きい一方、範囲が広く、事務管理・請負・物上代位など周辺論点が出る年もあります。

したがって、戦略は次のように置くのが安全です。

- 行政法1問：8～12点の土台
- 民法2問：合計12～16点
- 3問合計：20～24点

これは推奨目標であり、公式統計ではありません。

# 4. 民法の線引きの目安

## 4-1. 9問の大まかな構成

近年の標準的な説明では、民法択一9問はおおむね次の構成です。

- 総則：2問
- 物権：2問
- 債権：4問
- 家族法：1問

出典：

- 伊藤塾：<https://column.itojuku.co.jp/gyosei/method/minpou/>
- アガルート：<https://www.agaroot.jp/gyosei/column/minpou/>

年度によって物権・債権の境界や問数は動きますが、財産法が約8問、親族・相続が約1問という骨格は安定しています。

## 4-2. 5～6問を取るための優先順位

「5問分の論点だけ勉強する」のではなく、全体を薄く一巡したうえで、Aランクを深くする方が安全です。

### A：択一・記述の両方を考えて深くする

#### 総則
- 制限行為能力
- 意思表示：心裡留保、虚偽表示、錯誤、詐欺・強迫
- 代理：無権代理、追認、表見代理、日常家事代理との関係
- 時効：完成猶予・更新、援用、時効完成後の承認

#### 物権
- 物権変動と民法177条の第三者
- 即時取得
- 占有・取得時効
- 共有
- 抵当権、物上代位、法定地上権
- 留置権・先取特権の基本比較

#### 債権総論
- 債務不履行、履行不能、損害賠償
- 解除
- 債権者代位権・詐害行為取消権
- 保証、連帯債務
- 債権譲渡、債務引受
- 相殺

#### 債権各論
- 売買と契約不適合責任
- 賃貸借
- 請負
- 委任
- 不法行為・使用者責任
- 不当利得・事務管理

### B：択一1肢を切れる程度にする

- 条件・期限
- 失踪宣告
- 所有権以外の用益物権の細部
- 寄託、組合、終身定期金など低頻度契約
- 親族・相続の細かな身分法論点

### C：直前期に基本だけ確認

家族法は1問程度ですが、暗記型で短期に伸びやすいため、完全放棄は勧めません。

- 相続人の順位・法定相続分
- 代襲相続
- 相続放棄・限定承認
- 遺言の基本
- 遺留分
- 婚姻・離婚、親子関係の基本

## 4-3. 記述のために「完全放棄できない」論点

令和5～7年度だけでも、記述は次のように広がっています。

- R5：物上代位、請負契約の契約不適合責任
- R6：先取特権、債権者代位権
- R7：日常家事代理と表見代理、事務管理

したがって、択一で低頻度に見える論点でも、最低限、

> 制度名／発動要件／誰が誰に何を請求できるか

の3点はカード化しておく必要があります。

## 4-4. 民法の学習時間

民法だけの正確な時間を公開している合格体験記は、今回の範囲ではほとんど見つかりませんでした。山本さんは行政法・民法を合わせて全学習時間の6～7割、他の合格者も両科目を中心にしたと述べていますが、民法単独の時間は分離されていません。

残り3か月半に対する本報告の提案は、総学習時間の25～30％程度を民法に割くことです。ただし、記述練習で扱う民法時間もここに含めます。数百時間かけて全条文を深掘りするのではなく、A論点の精度と、B・C論点の用語認識を分けます。

# 7. 学習アプリに入れると効きそうな機能

現在、直近10年569問と行政法・民法80枚の○×カードがあるため、問題数を増やすより、**誤答の原因・再現性・時間を管理する機能**の方が伸びやすい段階です。

## 7-1. 「正解」ではなく説明可能性まで記録

TMさんは、正解していても理由を説明できなければ復習対象にしています。

回答後に次の3段階を付けます。

- A：正解し、誤肢の理由も説明できた
- B：正解したが、2択・勘・理由が曖昧
- C：不正解

Bを正解扱いで卒業させないことが重要です。山本さんも本番で約7割を「2択までは絞れたが自信なし」と記録していました。

## 7-2. 誤答理由タグ

問題ごとに次を1クリックで付けられるようにします。

- 原則と例外を逆にした
- 主体・相手方を混同
- 要件と効果を混同
- 義務・努力義務・裁量を混同
- 期間・起算点を混同
- 準用・適用除外を忘れた
- 判例の結論は知っていたが理由を誤った
- 類似制度と混同
- 問い方・否定語の読み落とし
- 完全な未学習
- 2択で推測

TMさんの「間違えた理由・思考のズレをまとめる」方法と、水越さん・kankoさんの反復誤答ノートをアプリ化する機能です。

## 7-3. 間隔反復

体験談で確認できた具体例は、

- インプット直後に演習し、1～2日後に再復習（ゆうさん）
- 就寝前に当日分を振り返る（TMさん）
- 何度も間違う問題だけを隙間時間に見る（kankoさん）

です。

実装案としては、C問題を当日・翌日・3日後・7日後、B問題を2日後・7日後・21日後に再出題します。この日数は研究結果ではなく、上記方法をアプリ向けに具体化した提案です。

## 7-4. 混同論点の比較カード

単独カードより、左右比較または三者比較にします。

例：

- 許可／認可／特許
- 取消し／無効／撤回
- 行政不服申立期間／取消訴訟の出訴期間／民法の消滅時効
- 無権代理／表見代理／日常家事代理
- 民法の表見代理／商法の表見支配人
- 債権者代位権／詐害行為取消権
- 留置権／先取特権／抵当権
- 行政上の強制執行／即時強制／行政罰
- 個人情報／個人データ／保有個人データ
- 審査請求／再調査の請求／再審査請求

各カードは、「主体・要件・効果・期間・第三者保護」の同じ列で比較します。

## 7-5. 一問一答と5肢択一の切替

合格者は隙間時間に一問一答を使い、まとまった時間には5肢択一を使っています。

- 一問一答：知識の穴を高速検出
- 5肢択一：肢を比較して切る訓練
- 本試験モード：途中で飛ばす判断と時間管理

同じ論点を両形式で呼び出せるようにすると効果的です。

## 7-6. 記述ビルダー

問題文を読み、次の欄を埋めてから40字に合成します。

- 論点・制度名
- 主体
- 相手方
- 要件
- 法的効果・請求内容
- 必須キーワード
- 文字数

模範解答との全文一致ではなく、部品ごとの一致で評価します。採点配分は非公式であることを明示し、「推定点」より「含められた法的要素数」を表示する方が誠実です。

## 7-7. 本試験時間モード

伊藤塾の2026年版目安は次のとおりです。

- 法令5肢択一：95分
- 基礎知識：40分
- 多肢選択：15分
- 記述：25分
- 見直し：5分以上

出典：<https://column.itojuku.co.jp/gyosei/detail/jikanhaibun/>

法令5肢択一40問を95分で解くと、単純平均は1問142.5秒です。ただし行政法の即答問題と民法事例問題では必要時間が違います。

アプリでは、次を表示します。

- 問題ごとの解答秒数
- 科目別中央値
- 120秒・180秒超過の警告
- 1周目に飛ばした問題
- 正解だが時間超過した問題
- 自信度A/B/Cと時間の関係

練習上は、行政法などの基本問題を60～90秒で処理し、その貯金を民法・文章理解・記述に回せる状態が理想です。これは一律の合格基準ではなく、時間配分から逆算した目安です。

## 7-8. 模試・初見問題の管理

山本さんは過去問5年分を回したうえで模試7回、別の合格者は模試9回、水越さんは早期に会場模試を受けて3時間を体得しています。

一方、TMさんは過去問10年を「1周＋重要・誤答反復」で使っています。

したがって、現在の10年569問は量として不足していません。今後は、

- 既知問題だけの点数
- 初見模試の点数
- 2択で当たった点数
- 制限時間内の点数

を分けて表示するべきです。過去問を暗記して得た200点と、初見模試の190点は意味が違います。

## 7-9. 優先して追加するカード

現在の行政法55枚・民法25枚に次ぐ優先順位は、

1. 基礎知識の諸法令・個人情報保護
2. 憲法の主要判例
3. 商法会社法の設立・株式・機関・商業使用人
4. 基礎法学の頻出基本語
5. 民法記述に出やすい周辺制度

です。

基礎知識は得点効率がよく、商法会社法は少数の比較カードで2問狙いの土台を作れるため、行政法カードを無限に増やすより先に最低限のデッキを完成させる価値があります。

# 8. 本番の時間配分

3時間を単純に60問で割ると1問3分ですが、記述・多肢・文章理解に時間が必要です。法令5択は平均2分強で処理する必要があります。

一例として、次のチェックポイントをアプリに設定します。

| 経過 | 目標 |
|---:|---|
| 0～95分 | 法令5肢択一40問 |
| 95～135分 | 基礎知識14問 |
| 135～150分 | 多肢選択3問 |
| 150～175分 | 記述3問 |
| 175～180分 | マーク・設問・記述の見直し |

解く順番は個人差があります。文章理解を最初に解く合格者もいるため、順番は固定せず、時間枠だけ保存できる設計がよいです。

山本さんは、過去問・予想問題では2時間以内だったのに、本番では慎重になってほぼ3時間を使いました。したがって、練習で5～10分余る程度では不十分で、通常の模試で20～30分余る処理速度を作る方が安全です。

---

# 9. 最終的な学習方針

残り3か月半では、次の順番が再現性の高い戦略です。

1. **行政法を16/19以上へ固定する。** 手続法・不服審査法・事件訴訟法の条文比較、総論・国家賠償の判例理由を中心にする。
2. **民法は6/9を本命にする。** A論点は理由まで、その他は制度名・要件・効果だけ通す。
3. **基礎知識を40～44点の得点源にする。** 得意分野を足切り対策だけに使うのはもったいない。
4. **多肢を16～18点にする。** 空欄ごとに2点なので、完全正解を狙わず確実な語から埋める。
5. **記述を20～24点取りに行く。** 0点前提にはしないが、40点以上にも依存しない。
6. **商法会社法2問、基礎法学1問を最低限拾う。**
7. **過去問の追加より、B判定・誤答理由・時間超過の潰し込みを優先する。**

得点設計を一言でまとめると、

> **行政法64～68、民法24、憲法16、商法会社法8、基礎法学4、多肢16～18、基礎知識40～44、記述20～24**

です。

この範囲の中間を取れば、196点前後になります。

# 10. 情報の確度

## A：高い確度

- 試験日、試験時間、出題数、配点、合格基準
- 令和8年度の法令基準日
- 合否通知に掲載された形式別得点
- 公式問題・公式正解

主な出典：行政書士試験研究センター。

## B：比較的高いが、予備校分析

- 年度別の分野分類
- 問題別正答率
- 標準的な時間配分
- 「得点すべき問題」の評価

TAC・伊藤塾・アガルート等の分析です。宣伝目的を含むため、教材購入の推奨部分ではなく、問題分類・正答率・配点分析を主に使用しました。

## C：個人の体験談

- 学習時間
- 何周したか
- 捨て科目
- 記述答案の自己分析
- 効果があった復習方法

本人にとっての事実ですが、他人にも再現する保証はありません。特に200～300時間の短期高得点者には、既存知識、学習速度、公開されていない背景、年度難易度の影響があります。

## 調査上の限界

1. 9例は無作為標本ではなく、合格道場利用者が多い。
2. 科目別得点は合否通知に載らないため、公開例が少ない。
3. 記述のキーワード別配点は公式非公表。
4. 令和6年度からの基礎知識制度はまだ2年分しかなく、令和8年度の問数配分は確定できない。
5. 2015～2023年度の体験談は、旧民法・旧一般知識など制度差がある。
