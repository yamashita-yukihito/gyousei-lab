### 1.2 絞り込みテクニック（`static/technique/`）

- **語の表**：旧10年と新10年の割合を各カードに出すようにした。
  - 両方の10年で平均より5ポイント以上同じ向きに傾き、10肢以上ある語だけを本表に出す。
  - それ以外は「参考：決め手にしない語」として薄く出し、理由（「新10年では平均を下回る」など）を添える。
  - 見出しの横に「平均より+◯ポイント」を出す。
  - 今の JSON には期間ごとの平均が無いので、画面は**全体の平均で代わりに比べている**。この方法で38語中13語が参考に回った。
    `ke-unconst`・`ch-may`・`mi-norescind`・`gy-effort`・`gy-fiction`・`ke-mandate` は片方の10年で傾かない。
    `ke-noviolate`・`ke-case`・`ke-strict`・`sh-offering`・`sh-court`・`ki-may`・`ki-can` は肢数が足りない。
- 「語は補助です」の箱に、語の手がかりがある問題の割合（`withSignal`）を出した。
  2択の当たり方（`simulation.pairs`）は、JSON にあれば出る（今は隠れている）。
- 「効かない手」の割合は、JSON に `noEffect` があればその値で置き換える。今は手で書いた39%・41%のまま出る。
- 「実際の肢で確かめる」表の「ただし」の行は、測っている語ではなかったので、「に限られる」の例（令和7年問13）に替えた。
- 解き方：次の3つを書いた。
  - 5肢から1つ選ぶ問題では、確実に判定できる肢が1つ増えるごとに、当たる確率がちょうど20%上がる（(k+1)/5）。
  - 組合せは、1肢判定したら残った選択肢の違いの字だけ読む。
  - 個数問題は最後に回す。
- 点の取り方：次を直した。
  - 確率表の5割・6割を 70%→69%、79%→78% に直した（式は p＋(1−p⁵)/5）。
  - 個数問題の行を足した（20・23・26・30・35・41%）。
  - A〜D の振り返りに、少ない問題数では偶然で5割を切ると書いた。
  - 180点の例に、法令等と基礎知識の内訳（145点・37点）を書いた。
- 両ページとも、タブを `#word` `#ng` のように URL の # で直接開けるようにした。
- `word-signals.json` は、`ke-strict` と `sh-all` の見方（note）の文だけを `measure.py` に合わせて書き換えた。
  **割合は古い正規表現のままである。**

### 1.3 `scripts/simple_rules/measure.py`

- 正規表現を直した（`tests/test_simple_rules_measure.py` が作り物の肢で固定している）。
  - `ke-allow`「を認める」：「を認めない」「を認められない」「を認めることはできない」なども数えていた。否定の形を除いた。
  - `ke-unconst`（違憲の側）：「違反するものではない」「反するとはいえない」（＝合憲）を違憲の側で数えていた。除いた。
  - `ke-noviolate`（合憲の側）：上の言い方を拾えていなかった（だから7肢しかなかった可能性がある）。拾うようにした。
  - `all-reason`：「3分の2以上、」（数の下限）と「確保するため、」（目的）を、理屈を足す形として数えていた。
    「〜である以上、」「〜したため、」の形だけにした。
  - `ki-can`：文末の「。」が無い肢も拾う。
- 旧10年・新10年を、それぞれの期間の同じ問題の平均と比べる（`earlyBase`・`lateBase`）。
  本表の条件を `stable`・`unstableReason` に、基準を `criteria` に書き出す。
- 正答率の試算（`simulate`）を次のように直した。
  - 同じ向きの語は1点に数える。今まで、全科目の語と科目の語で同じ語（「ことがある」「問わず」など）を二重に数えていた。
  - 新10年だけの正答率（`lateAccuracy`）と、2択の当たり方（`pairs`）を足した。
- 「効かなかった手」も `NO_EFFECT` で数え、`noEffect` に書き出す。
  「必ず」は「必ずしも」を除いた。「必ずしも」は正しい寄りの語なので、混ぜると断定の語が効かないように見える。
  「だけ」は「できるだけ」「だけでなく」を除いた。
- 過去問の置き場所を `GYOUSEI_DATA_ROOT` で変えられるようにした（authoring と同じ環境変数）。

**A4. 「いつでも分割」の出典を確かめる。** 「みんなの財産」の考え方は、過去問に令和6年問33肢3×と平成29年問27肢ウ×を挙げている。
この2肢が何の制度だったかを原文で確かめる。

- 組合財産なら、組合員は清算前に分割を求められない（676条3項）。不分割特約なら、5年以内の特約は有効（256条1項ただし書）。遺産なら、遺言による分割の禁止がある（908条）。
- 中身に合わせて、使い方の文を足すか、その肢を過去問の欄から外す。
- **共有物の分割請求そのものは原則いつでもできる（256条1項）**ので、「いつでも分割を請求できる」を誤りの目印に戻さない。
