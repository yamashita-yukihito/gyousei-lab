## 1. このセッションで直したこと

### 1-1. B・CがAの答えを割っていた問題（最重要）

**利用者からの指摘で発覚した、教材の根幹に関わる不具合。**

`static/index.html` を見ると、A・B1・B2・Cは4つとも `.study-variants` の中にあり、
`.study-answer-buttons` より**前**にある。つまり回答前に全部読める。
それなのに、Aが誤りの命題のとき、B・Cが**正しいルールのほう**を書いていた。

> A: 破産手続開始の決定を受けた者は、復権をした後であっても、行政書士となる資格を有しない。（×）
> B: …行政書士になれないのは復権を得ていない間だけで、**復権すればまた資格を持てます**。

これでは、Bを読んだ時点で×だと分かる。全98枚を1枚ずつ読んで数えたところ、
**44枚（行政法32・基礎知識12）**が同じ状態だった。

**直し方**: 断定型で統一。Aの主張を、そのまま平易な断定文にする。
Aが誤りの命題なら、B・Cも同じ誤りの命題を平易にしただけの文にする。
正解は回答後に出る `correction`・`explanations`・`memoryPoint` へ書く。

**民法8枚は別の割れ方**をしていた。B が「この命題は〜と言っています」で終わる引用型で、
これを使っているのが `correct=False` の8枚だけ、`correct=True` の13枚は1枚も使っていなかった。
**言い回しを見つけたら×**と分かる状態だったので、こちらも断定型へそろえた。

合計52枚を書き直し済み。

### 1-2. 赤（`!!`）の意味を変えた

「ひっかけ・失うもの」→ **「判定の分かれ目」**。本試験がここの数字・主体・期間を
書き換えてくる、という印にした。この意味なら**○のカードにも付けられる**ので、
赤の有無だけで答えは割れない。利用者は「ひっかけポイントは知りたい」という希望なので、
赤自体は残す方針。

### 1-3. Cから場面が落ちていた

> 悪い例: `形式不備 → 補正を求めるほかなく、拒否できない`
> 良い例: `申請 → 形式上の要件に不備 → 補正を求めるほかなく、拒否できない`

「申請なのか審査請求なのか」「申請に対する処分なのか不利益処分なのか」で結論が変わる論点が多い。
`gyo-aps-formal-defect-001` と `gyo-aps-review-criteria-001` の2枚を修正した。

### 1-4. correctionが薄かった（45枚）

`correction`（画面では「正しい形で覚えると」）に**条文番号がないカードが45枚**あった。
また、Aが複数のことを言っている肢なのに片方にしか答えていないものがあった。

全45枚へ条文・判例番号を入れ、Aの主張全体へ答える形へ書き直した。
**条文はすべて e-Gov 法令API で原文を取得して確認している。**

```bash
curl -fsS "https://laws.e-gov.go.jp/api/1/articles;lawNum=;lawId=<lawId>;article=<条>"
# 例: 行政手続法=405AC0000000088 / 行政不服審査法=426AC0000000068
#     行政事件訴訟法=337AC0000000139 / 民事訴訟法=408AC0000000109
#     地方自治法=322AC0000000067 / 国家賠償法=322AC0000000125
#     行政代執行法=323AC0000000043 / 戸籍法=322AC0000000224
#     住民基本台帳法=342AC0000000081 / 個人情報保護法=415AC0000000057
# 「49条の2」のような枝番は article=49_2
```

### 1-5. 「1文に黄が2か所」はルール側を直した

29件見つかったが、**すべて「対になった2つの結論」**だった。
「明渡しは単独で==請求できる==が、賠償は==請求できない==」のように、対比そのものが論点。
片方だけ黄にすると読み違いを生むので、**カードではなくルールを直した**。
原則1か所、対の2つだけ2か所まで、3か所以上は不可。

## 4. 回答履歴への影響

`card_answer_revision` は `a` / `c` / `correct` / `lawAsOf` のhash。
**Cを書き換えたカードは revision が変わる**ので、そのカードの過去の回答は
現在の習得判定から外れる（履歴自体は残る）。

- 作業前: `staleRevisionAttempts` 0
- 作業後: **5**（`gk-gyosei-law-disqualification-001` 2件、`gk-gyosei-law-qualification-001` 1件、
  `gk-pip-identifier-code-001` 1件、`gyo-aps-formal-defect-001` 2件のうち一部）

回答総数54件のうち5件なので影響は小さい。
**B・解説・⑥・⑦だけの変更では revision は変わらない。**
