# 民法ドリル A案・B案・C案のレビューとD案の設計

更新日: 2026-08-02
対象: `static/minpo-a/`（Claude Opus 5）、`static/minpo-b/`（agy cli Claude 4.6）、`static/minpo-c/`（ChatGPT 5.6 sol）
観点: **行政書士試験の民法学習として役に立つか**。実装の善し悪しやセキュリティは見ていない。
法令の照合: e-Gov法令API（民法、`asof=2026-04-01`）の原文と機械照合した。

## 0. 結論を先に

| | 評価 |
|---|---|
| **学習設計として一番強いのはC案** | 「共通事例から1事実だけ変える」が、民法の得点源である**要件の切り分け**をそのまま訓練になる。本番変換モードもある |
| **素材として一番使えるのはB案** | 5場面31肢と量があり、A・Cにない**相続**を持つ。ただし**条文・事案の誤りが5件**あり、そのままでは使えない |
| **A案は土台としては一番きれい** | ○×が5:5、既存の学習カードとID連携、事実の図と答え入りの図の出し分け。ただし1問1事例なので、いちばんの目的だった「事例把握の削減」がほとんど効いていない |
| **D案を作る価値はある** | C案の骨格に、A案の図の出し分け・カード連携・○×バランス、B案の一場面複数肢の画面と挿絵を寄せる |

いちばん重い指摘を1つだけ挙げるなら、**B案の `scene-001-s3` は問題として成立していない**（3.2参照）。

## 1. 3案は何を解こうとしたか

もともとの課題はこれだった。

> 問題によって、A、B、Cなどの人物が出てきて、毎回違う役割を演じている。まずその問題の人物設定などを把握するのに数分、その問題で問われている法律知識を勉強して理解するのに数分でいちいち余計な時間がかかる。

3案は、同じ「配役を固定する」から出発して、**事例の使い回し方**で分かれた。

| | 事例の単位 | 1事例あたりの問数 | 事例を読む回数 |
|---|---|---|---|
| A案 | 1問1事例 | 1.0問 | **16回**（問題数と同じ） |
| B案 | 1場面に複数肢 | 6.2問 | **5回** |
| C案 | 1章に共通事例、1事実ずつ変える | 9.0問 | **3回** |

**この表がレビューの中心**である。A案は配役を固定しただけで、事例を読み直す回数は減っていない。B案とC案は、事例の使い回しまで踏み込んだ。

### 2.2 ○×の偏り

本試験の肢は正誤がおおむね半々なので、偏った教材で回すと「迷ったら×」「迷ったら○」の癖がつく。

- **A案 50%** — 意図的に8:8へ調整済み。
- **B案 65%が○** — 5場面のうち4場面が○4/×2。
- **C案 33%が○** — とくに第2章（即時取得）が**○1/×8**。「192条の要件を1つずつ外していく」という章の作り方の必然だが、9問中8問が×では、章を通すと×を選ぶ癖がつく。

C案の第2章は、要件を外した肢だけでなく**要件を満たして即時取得できる肢**（占有改定でない現実の引渡し、平穏公然の充足、盗品でない場合の確定）を足せば直る。

## 3. B案のレビュー

### 3.1 良いところ

- **1場面6〜7肢を縦に並べて連続で解く画面**は、テンポがよく、周回に向いている。場面把握が1回で済むという狙いがそのまま形になっている。
- **場面のイラストにキャラクターが描かれている**。A案・C案のSVGは枠と矢印なので、記憶のフックとしてはB案の絵のほうが強い。事例を思い出すときの手がかりになる。
- **事例文の中でキャラ名が色分けされている**。配役表を見に戻らなくても、誰がどの色かが本文で分かる。3案の中でこれをやっているのはB案だけ。
- **相続を持っている唯一の案**。法定相続分・遺留分・遺留分侵害額請求・代襲相続と、出るところを押さえている。A案・C案には相続が1問もない。
- 解説が「3ステップ＋条文＋覚えどころ」で統一されていて読みやすい。

### 3.2 直さないと使えないところ

#### ① `scene-001-s3` は問題として成立していない（最重要）

> しずかとのび太の間の売買契約が、**しずかの錯誤**を理由に取り消された。その取消しの「後」に、しずかが甲土地をスネ夫に売却してスネ夫が登記を備えた場合、**のび太は**登記がなくてもスネ夫に所有権（復帰）を主張できる。

取消しによって所有権は**しずか**に復帰するので、のび太は所有権を失っている。**のび太がスネ夫に所有権を主張する場面が存在しない**。「取消し後の第三者は対抗関係」という典型論点を、この事案へ無理に押し込んだ結果、当事者関係が壊れている。

判定（×）と解説の中身は正しいので気づきにくいが、**この肢で覚えると論点の構造そのものを誤解する**。当事者を「しずか対スネ夫」に直すか、事案ごと差し替える必要がある。

#### ② `scene-003-s4` は要件を確定していない（法定地上権）

場面は「甲土地に抵当権を設定し登記した。**その後**、しずかは甲土地をのび太に賃貸」。肢は「もし、しずかが甲土地の上に自己所有の建物を建てていた場合」とだけ書き、**いつ建てたのかを書いていない**。

解説のstep2が `（土地の上に建物を建てて所有していた場合で、抵当権設定時に建物があったと仮定すれば）` と、**自分で前提を補って**成立させている。

**更地に抵当権を設定した後に建物を建てた場合は法定地上権が成立しない**というのは、この論点の最頻出のひっかけそのものである。それを設問が確定せず、解説の括弧書きで回避しているので、○×問題として機能していない。

#### ③ 条文番号の誤り

| 場所 | 書いてある条文 | 正しい条文 |
|---|---|---|
| `scene-005-s5` | 民法**1043条**1項・2項（遺留分の放棄） | **民法1049条**1項・2項。1043条は「遺留分を算定するための財産の価額」 |
| `scene-003-s5` | 民法**395条**（土地の賃貸借の事案） | 395条は「抵当**建物**使用者の引渡しの猶予」で建物限定。土地の事案には使えない |
| `scene-003-s7` | 民事執行法**93条** | 担保不動産収益執行は**民事執行法180条2号**。93条は強制管理の開始 |

いずれも○×の判定自体は正しいので、解くぶんには害が出にくい。ただし**記述式では条文番号ごと問われる**ので、このまま覚えると失点する。とくに遺留分の放棄（1049条）は記述の射程に入る。

`scene-003-s5` は、step3が「建物賃貸借などの場合」と正しく限定しているのに条文欄が395条のままなので、**条文だけ拾い読みすると土地にも395条が使えると誤解する**。

### 3.3 設計上の弱点

- **イラストが場面固定なので、肢で事実が変わるとついていけない。** `scene-001` の図は「スネ夫が登記を備えた」場面だが、肢3は錯誤取消し後の話、肢2は背信的悪意者、肢6は損害賠償で、図に描かれていない。6肢中3肢は図と噛み合わない。C案の`diagramPatch`（問題ごとに図を更新）と比べると差が大きい。
- **絞り込み・シャッフル・進捗表示がない。** 場面一覧と「記録を消す」だけ。まちがえた肢だけを回す運用ができない。
- **どの肢がどういう理由で難しいのかが示されない。** C案の「素直／ひっかけ」ラベルにあたるものがない。

## 4. C案のレビュー

### 4.1 良いところ

- **「共通事例から1事実だけ変える」が、この3案でいちばん学習効果が高い作り**。第1章の無権代理は、相手方が善意無過失 → 悪意 → 善意有過失 → さらに無権代理人の認識まで動かして、催告・取消し・117条責任の**それぞれで保護範囲が違う**ことを体で覚えさせる。「相手方が悪意になったら権利が全部消える」という雑な覚え方をつぶしにいっている。これは条文を読むだけでは身につかない。
- **前問との差分が明示される。** 「前：のび太は代理権なしを知っていた → 今回：知らなかったが確認しない過失があった」「同じ：ジャイアン自身は無権限を知っています」。**何が変わって何が変わっていないか**を毎回言語化するので、事例把握のやり直しがほぼゼロになる。
- **素直／ひっかけのラベル**がある。ひっかけには「117条2項2号の本文だけで止まり、ただし書を落とすひっかけです」と、どこで転ぶかまで書いてある。
- **本番変換モード**。人物をA・B・Cへ戻し、差分表示とラベルを隠す。「最終的には本試験でABCの状況把握もしないといけない」という当初の懸念に、3案の中で唯一こたえている。
- **図が問題ごとに更新される**（`diagramPatch`）。ノードのラベル差し替え、線の差し替え、人物の追加（転得者・差押債権者）、人物の非表示まである。図と事案が最後までずれない。
- 回答後の解説が厚い。「事実→ルール→結論」の3枡、「誰をなぜ守る？」「反対の結論だと何が困る？」「最小暗記」「次は」。**制度趣旨から結論を復元できる形**になっている。
- **章末の比較表**。無権代理なら「相手方の状態 × 催告／取消し／117条責任」の4×4。行政書士試験でいちばん問われる形にそろっている。
- 条文の引用に誤りが見つからなかった（113・114・115・117・176・177・192・193・194を照合）。判例URLも実在するトップページで、でっち上げの深いリンクがない。

### 4.2 直したほうがよいところ

#### ① 「本人」を術語でない意味で使っている

`minpo-c-ua-008` と `ua-009` の図のラベル。

- `ua-008`: 「代理権なし／**本人は**そのことを知っている」
- `ua-009`: 「代理権なし／**本人も**無権限だと気付いていない」

ここでの「本人」はジャイアン自身のことだが、**無権代理では「本人」はしずかを指す術語**である。この章はまさに本人・無権代理人・相手方の3者を切り分ける章なので、いちばん混ぜてはいけない語を混ぜている。「ジャイアン自身は」「ジャイアン自身も」へ直せば済む。

#### ② 第2章の○×が1:8

3.1で書いたとおり。要件を満たす側の肢を足して5:4程度にしたい。

#### ③ 範囲が狭い

3章27問で、総則1・物権2。深さは十分だが、担保物権・債権・親族相続がまるごと無い。C案の作りは1章あたりの手間が大きいので、この形で民法全体を覆うにはかなりの章数が要る。

#### ④ 学習カードとつながっていない

A案は13/16問に`cardId`を持ち、対応する学習カードを表示する。C案・B案にはこれがないので、ドリルで間違えた論点を既存の187枚へ戻せない。

## 5. A案（自分の案）の反省

比較して初めて見えた弱点を、はっきり書いておく。

- **いちばんの目的をほとんど達成していない。** 16問で16事例なので、事例を読む回数は問題数と同じ。「毎回の設定把握をなくす」という出発点に対して、やったのは「配役を固定した」だけだった。B案・C案は事例の使い回しまで踏み込んでいる。
- **1問1論点なので、要件の切り分けが訓練にならない。** 「法定地上権は設定時に同一所有者か」を1問出して終わりで、C案のように「じゃあ設定後に建てたら」「持ち主が入れ替わったら」と続かない。本試験で問われるのはその境目である。
- **相続と債権譲渡が無い。** 相続は毎年出る。
- 一方で、**残しておきたい要素**は3つある。
  - ○×を5:5に調整してあること。
  - 回答前は事実だけの図、回答後に答え入りの図、という出し分け。
  - `cardId`で既存の学習カードへ戻れること。

## 7. D案の設計

3案を1つに寄せるなら、**C案の骨格に、A案の規律とB案の画面・挿絵を足す**。

### 7.1 骨格はC案

- **章（連続事例）を単位にする。** 章に共通事例を1つ置き、そこから1事実ずつ変えて8〜10問続ける。
- **前問との差分（前／今回／同じ）を必ず持つ。**
- **素直／ひっかけのラベルを持つ。**
- **読む／解く／本番変換の3モード**をそのまま採る。本番変換は11月に向けて必ず要る。
- **図は問題ごとに差分更新する**（`diagramPatch`）。人物の追加・非表示まで含めて、C案の仕組みが一番できている。
- **章末に比較表**を置く。

### 7.2 A案から持ってくるもの

- **回答前の図は事実だけ、答え入りの図は回答後**（`answerDiagram`）。C案は回答前の図を事実だけに保っているが、答え入りの図は持っていない。回答後に結論を線に書いた図をもう1枚出したほうが定着する。
- **`cardId`で既存の学習カード187枚へ戻す。** ドリルで落とした論点を苦手ビューへつなげられる。これが無いとドリルが孤立する。
- **○×は章ごとに5:5へ寄せる**という運用ルール。
- **場面画像の出し分け**（`placement: setup | explanation`）。事案そのものの絵は回答前、ルールや結論が絵に入っているものは回答後。

### 7.3 B案から持ってくるもの

- **章まとめて縦に解く画面**を、1問ずつ送る画面と選べるようにする。初回はC案の1問ずつ、周回はB案の縦積みが速い。
- **キャラクター入りの挿絵**を章の入口に1枚。SVGは関係を、挿絵は場面の空気を担当する。**挿絵は章の共通事例だけを描き、肢ごとの事実変更は描かない**（描くとB案と同じずれが起きる）。SVGが差分を受け持つので役割が分かれる。
- **事例文の中でキャラ名を色分けする。** 配役表へ戻らずに読める。

### 7.4 D案で最初から決めておくルール

3案の失敗がそのまま教訓になっている。

1. **事案は「いつ・だれが・どの順で」を必ず確定して書く。** 解説の括弧書きで前提を補わない（B案の法定地上権）。
2. **条文番号は e-Gov（`asof=2026-04-01`）の原文と機械照合してからでないと入れない。** 目視で書かない（B案の1043条／395条）。
3. **術語を日常語の意味で使わない。** 「本人」「善意」「第三者」「悪意」は民法の術語なので、別の意味で使わない（C案の「本人はそのことを知っている」）。
4. **当事者関係が成立しているか、肢ごとに確かめる。** 誰が誰に何を主張する場面かを1行で書けないなら、その肢は作り直す（B案の`scene-001-s3`）。
5. **○×は章ごとに5:5へ寄せる。** 要件を外す肢だけを並べない。
6. **回答ボタンより上に結論を書かない。** 図・ラベル・差分表示のどれにも。
7. **章の中では配役を動かさない。** 役割が移るとき（無権代理人が本人を相続など）は、配役を入れ替えず図の中で「相続」と書く。

### 7.5 章立ての案

民法は択一9問36点＋記述2問40点で**76点**。出題頻度の順に章を積む。1章8〜10問なので、11章で90〜110問になる。

| 章 | 内容 | 素材 |
|---|---|---|
| 1 | 意思表示と第三者（詐欺・強迫・錯誤・虚偽表示） | B案scene-002、A案002 |
| 2 | 代理（無権代理・表見代理・日常家事） | **C案第1章をそのまま**、A案003・004 |
| 3 | 不動産の対抗要件（177条の第三者） | **C案第3章をそのまま**、B案scene-001、A案001 |
| 4 | 即時取得と盗品・遺失物 | **C案第2章**（○×を足す） |

### 7.6 進め方

1. **まず3案を実際に使ってみる。** この文書は中身を読んで比べただけで、解いた感触は入っていない。C案の差分表示が本当に楽か、B案の縦積みが本当にテンポいいかは、解いてみないと分からない。
2. 使ってみて骨格を決めてから、D案のデータ形式を1つに決める。
3. **B案の5件は、D案を作らない場合でも直しておく。** とくに`scene-001-s3`と法定地上権は、そのまま覚えると害になる。
4. A案・B案・C案は、D案ができたら畳んで素材扱いにする。3つ並べたまま回すと、同じ論点を別の書き方で3回覚えることになって効率が悪い。
