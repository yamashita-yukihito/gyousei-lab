## 2. 方針

- 1日**約5時間**（通常日）。19日で合計**約85時間**。休みの日が続くので無理なく続けられ、
  そのうえ一巡と2周目まで届く量として決めた。これ以上詰めると後半で崩れるおそれがある。
- **行政法を毎日やる。** 法令の配点のうち最大（択一76＋多肢16＋記述20点）で、カードも83枚ある。午前の90分は全日程で行政法にする。
- 午後は第2科目を日替わりにする。民法を厚くし、憲法2日、商法1日、基礎知識を法令系と文章理解に充てる。
- **ラボのカード（①）は毎日、最初にやる。** 246枚は「しっかり」（新しいカード25枚）で約10日、10/30ごろに一巡が終わる。その後は期日が来た復習だけが出る。
- 記述は1日30分までにする。キーワード3つを書けたら止める。**記述を厚くする提案をしない**（AGENTS.md §5.4）。
- 本試験形式の通し演習は2回（10/25・11/1の日曜、本番と同じ13:00〜16:00）。
  過去問の周回は主な使い方ではないので、通しで解くのはこの2回だけにする。
- 11/2以降は新しい範囲に手を広げない。肢別過去問集で**間違えた肢だけ**を回す2周目にする。
- **ラボの開発は気分転換として続ける**（2026-10-20に利用者が希望）。ただし次を守る。
  - 開発は①②を終えた後の時間に置き、①〜⑤の勉強時間を削らない。
  - 新しいカードを大量に足さない。足したカードは「はじめて」の枠に入り、一巡が後ろへずれる。
  - bundleの差し替えやserver.pyの変更は、テストを通してから行う。11/7・11/8は本番の画面を触らない。

## 3. ラボの設定（10/20に1回だけ）

学習カードの画面で次のように設定する。

| 項目 | 値 |
|---|---|
| 出題範囲 | 今日の学習（間隔反復） |
| 1日の量 | しっかり（60分）はじめて25枚＋期日の復習 |
| カードの種類 | **すべて**（8月の「暗記ものだけ」のままにしない） |
| 頻出度 | すべて |
| 科目 | すべて |

- 本試験形式の日（10/25・11/1）だけは「復習だけ」を30分にする。
- 「出題範囲」は記憶されず、開くたびに「おまかせ」へ戻る。毎回「今日の学習」を選ぶ。「1日の量」と「カードの種類」はブラウザのlocalStorageに残るので、端末ごとに1回設定する。
- ①の60分は目安で、**その日のキューを空にしたら終わり**にする。一巡中（〜10/30）は、はじめてのカード25枚の解説を読むため60〜90分かかってよい。足りない分は④から取る。
- 頻出度は「すべて」のままにする。基礎知識42枚のうち37枚が「重要論点」なので、絞ると足切り科目のカードが抜ける。
- 11/2からは、①のあとに学習ビュー「苦手・要観察」を15分足す。

## 4. 通常日の型（約5時間）

| 枠 | 時間 | 内容 |
|---|---|---|
| ① | 60分 | ラボ「今日の学習」 |
| ② | 90分 | 行政法の肢別過去問集（その日の範囲） |
| ③ | 75分 | 第2科目の肢別過去問集（その日の範囲） |
| ④ | 30分 | 日替わり（参考書・動画で②③の誤答を確認／記述／文章理解など） |
| ⑤ | 15分 | 寝る前に、その日間違えた肢とカードを見直す |

時間が足りない日は**④→③の順に削る。①と②は削らない。**
肢別過去問集では、間違えた肢と迷った肢に印を付ける。2周目（11/2以降）はその印だけを回す。

## 6. 通し演習のあとに記録すること

通し演習はラボの「通し演習」ページ（`static/mock-exam/`、2026-10-21に追加）で解く。下の3つと「結果を見て直すルール」への当てはまりは、採点結果の画面に自動で出る。
文章理解（問58〜60）はラボに入っていないので、試験研究センターの問題PDFで解き、採点のときに正解数を入れる。
採点のあと、間違えた問題ごとに理由（知らなかった／覚え違い／2択で外した／読み違い／時間不足）を選び、「間違えた問題のカードをまとめて解く」で関連カードを解いておく（翌日以降の①のあとでもよい）。

- 科目別の点数（行政法・民法・憲法・商法・基礎法学・基礎知識）と、記述を除いた合計。
- 基礎知識が24点（6問）を超えたかどうか。
- 時間切れで解けなかった問題の数と、どの科目で時間を使ったか。

### 結果を見て直すルール（通し演習1のあと）

- 基礎知識が28点を下回った → 11/3の基礎知識を10/29へ前倒しし、④に文章理解を増やす。
- 民法の択一が3問以下 → 民法の日の④を「民法演習D」（`static/minpo-d/`「答えから読む」）にする。
- 時間切れが出た → 2回目は解く順番を決めてから臨む（例：基礎知識→行政法→民法→その他）。
- 記述を除いた合計が130点以下 → 11/2の商法を半日に減らし、行政法の2周目へ回す。

## 7. 変えてはいけないもの

- ラボのカードを毎日やること。カードを減らす、または飛ばす提案をしない（`static/score-plan.html`「切るもの」）。
- 記述と商法を厚くしない。基礎知識の余裕を削らない（AGENTS.md §5.4）。
- この期間に `production.sqlite3` とカードIDを触らない。bundleの差し替えは、全テストを通し、差分が直したカードだけであることを確かめてから行う。

## 8. 次のAIへ

- 利用者から「実際はこうだった」と申告があれば、§5の表と `static/schedule.html` の `DAYS` を両方直す。
- 通し演習の結果は、利用者のブラウザのlocalStorage（`gyouseiMock:v1`）と、`answer_attempts` の `mode='mock_exam'`（`session_id` が `mock-` で始まる）に残る。記述の自己採点と文章理解の正解数はlocalStorageだけにあるので、点数は利用者に「結果を文字でコピー」の文を貼ってもらう。
- 進み具合を確かめるときは、`card_attempts` を読み取り専用で日別に集計する（`created_at_server`）。肢別過去問集とほかの教材はラボの外なので、記録は無い。利用者に聞く。
