# 商法総則・商行為 | 商人と、民法との違い [捨て候補]
> 民法の原則を、商人の取引向けに「速く・確実に」変えたのが商法。どこが民法と違うかだけを覚える。
> 優先度：商法・会社法は2問（8点）取れれば満足する設計。商行為の特則は時間が余ったら。
- 適用の順番 :: 商事については、商法 → 商慣習 → 民法の順に適用する {com-gen-application-order-001}
- 商人 :: 自分の名で商行為をすることを業とする者。店舗で物品を販売する者、鉱業を営む者は擬制商人 {com-gen-merchant-definition-001}
- 商行為の種類 [重要]
  - 絶対的商行為 :: 1回だけでも商行為になる（利益を得て売るための買入れ、取引所での取引、手形に関する行為など） {com-gen-absolute-act-001}
  - 営業的商行為 :: 営業としてするときに商行為になる（貸すための買入れ、運送、仲立ちなど） {com-gen-absolute-act-001}
  - 附属的商行為 :: 商人が営業のためにする行為。商人の行為は営業のためにするものと推定される {com-gen-attached-act-001}
- 商業使用人・営業譲渡
  - 支配人 :: 営業に関する一切の裁判上・裁判外の行為をする権限がある。権限の制限は善意の第三者に対抗できない。本店・支店の営業の主任者らしい名称を付けた使用人は表見支配人 {com-gen-manager-authority-001}
  - 営業譲渡と商号の続用 :: 譲受人が譲渡人の商号を使い続けると、譲受人も譲渡人の営業上の債務を弁済する責任を負う（登記か通知で免れる） {com-gen-business-transfer-001}
- 商行為の特則（民法との違い） [重要]
  - 代理の非顕名 :: 代理人が本人のためにすることを示さなくても、本人に効力が生じる。相手方が知らなかったときは、相手方は代理人に対しても履行を請求できる {com-act-agency-nondisclosure-001}
  - 多数債務者の連帯 :: 数人が、1人または全員にとって商行為となる行為で債務を負ったときは、連帯債務になる {com-act-joint-liability-001}
  - 報酬請求と寄託 :: 商人が営業の範囲内で他人のために行為をすれば、相当な報酬を請求できる。報酬を受けずに寄託を受けた商人も、善良な管理者の注意で保管する {com-act-reward-custody-001}
  - 諾否通知義務 :: 平常取引をしている者から営業の部類に属する契約の申込みを受けた商人は、遅滞なく諾否を通知する。通知を怠ると承諾したとみなす。送られてきた物品は保管する {com-act-offer-duty-001}
  - 高価品 :: 荷送人が種類と価額を通知しなければ、運送人は損害賠償責任を負わない（運送人が高価品だと知っていたとき、故意・重過失のときは負う） {com-act-valuable-goods-001}
  - 匿名組合 :: 匿名組合員の出資は営業者の財産になる。匿名組合員は第三者に対して権利義務を持たない（自分の氏名を営業者の商号に使わせたら連帯責任） {com-act-silent-partnership-001}

# 株式会社の設立 | 定款・出資・発起人の責任 [重点]
> 20年で最も多く出る範囲。発起設立と募集設立で「誰が決めるか」が変わる点と、発起人の責任が頻出。
> 優先度：会社法で最も多く出る範囲。2問を取りに行くならまずここ。
- 定款 [重要] @shoho-d/incorporation
  - 絶対的記載事項 [抑えめ] :: 目的・商号・本店の所在地・設立に際して出資される財産の価額かその最低額・発起人の氏名（名称）と住所。発行可能株式総数は設立登記までに定める {com-inc-articles-required-001}
  - 変態設立事項 :: 現物出資・財産引受け・発起人の報酬や特別利益・設立費用。定款に書かないと効力がない。原則として検査役の調査が要る（500万円以下・市場価格のある有価証券・弁護士などの証明があれば不要） {com-inc-special-items-001}
- 発起設立と募集設立 [重要] :: 発起設立では発起人が、募集設立では創立総会が、設立時取締役の選任などを決める {com-inc-founder-vs-meeting-001} @shoho-d/incorporation
- 出資の履行 [重要] :: 金銭の払込みは銀行などの払込取扱機関でする。仮装払込みをした発起人・設立時募集株式の引受人は、会社に対して仮装した額を支払う義務を負う {com-inc-payment-001} @shoho-d/incorporation
- 発起人の責任 [重要] :: 会社に対しては任務を怠ったときに責任を負い、総株主の同意で免除できる。第三者に対しては、職務について悪意・重過失があったときだけ責任を負う。現物出資などの価額が著しく不足すれば不足額も支払う {com-inc-founder-liability-001} @shoho-d/incorporation

# 株式・機関・計算 | 株主総会・取締役会・監査 [抑えめ]
> 優先度：2問目の候補。剰余金の配当（頻出）と取締役会を中心に1周する。
- 株式
  - 全部無議決権の種類株式 :: 発行できる。公開会社では、議決権制限株式は発行済株式総数の2分の1まで {com-inc-nonvoting-class-share-001}
  - 譲渡制限株式の譲渡承認 [捨て候補] :: 取締役会設置会社では取締役会、それ以外の会社では株主総会が承認する（定款で別に定められる） {com-inc-restricted-share-approval-body-001}
- 株主総会
  - 少数株主権 :: 総株主の議決権の100分の1以上を持つ株主（公開会社は6か月の保有も要る）は、総会検査役の選任を裁判所に申し立てられる（取締役に請求するのではない） {com-inc-shareholder-minority-rights-001}
  - 決議の内容が法令違反 :: 決議は無効（決議無効確認の訴えに提訴期間の制限はない）。内容が定款違反なら、決議の日から3か月以内に取消しの訴え {com-inc-shareholders-resolution-illegal-content-001}
- 取締役会 [重要] @shoho-d/organs
  - 特別利害関係のある取締役 [捨て候補] :: その決議に加わることができない {com-inc-board-special-interest-001}
  - 議事録 :: 決議に参加して議事録に異議をとどめなかった取締役は、決議に賛成したと推定される {com-inc-board-minutes-presumption-001}
- 監査役・監査役会 @shoho-d/organs
  - 選任と解任 [捨て候補] :: 選任は普通決議、解任は特別決議 {com-inc-auditor-appointment-dismissal-001}
  - 監査役会 [捨て候補] :: 監査役3人以上で、半数以上は社外監査役。常勤の監査役を選定する {com-inc-auditor-board-structure-001}
- 監査等委員会 :: 監査等委員である取締役は3人以上で、過半数は社外取締役 {com-inc-audit-supervisory-committee-structure-001}
- 会計参与と会計監査人 :: 会計参与は取締役と共同で計算書類を作る（公認会計士・税理士）。会計監査人は計算書類を監査する（公認会計士・監査法人） {com-inc-accounting-advisor-001}
- 剰余金の配当 [重点] :: 分配可能額の範囲でだけできる。超えて配当すると、受け取った株主と業務執行者が会社に支払義務を負う {com-inc-distributable-amount-001}
