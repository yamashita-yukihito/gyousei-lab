BY QUESTION NUMBER

問番号ごとの出題傾向

行政書士試験は、問番号ごとに出る科目と分野がほぼ決まっています。「問37は会社の設立」のように、問1〜60のそれぞれでよく出るテーマを、平成18〜令和7年度の20年分の過去問から調べて一覧にします。

下書きです。まだ過去問を調べていません。このページは、できあがりの形を見てもらうための骨組みです。下の表の「見込み」は一般によく言われる割り当てを置いただけで、確かめていません。過去問を調べたら、この列を実際の出題テーマと回数に置き換えます。

確かめたのは問番号と科目の対応だけです。20年分の1,139問すべてで、問1〜57の科目は毎年同じでした（問1〜2が基礎法学、問3〜7が憲法、問8〜26が行政法、問27〜35が民法、問36〜40が商法・会社法、問41が憲法の多肢選択、問42〜43が行政法の多肢選択、問44が行政法の記述、問45〜46が民法の記述、問47〜57が基礎知識）。平成29年度の問39だけはデータにありません。問58〜60（文章理解）はラボに収録していません。

HOW TO USE

何に使うか

本番で問題用紙を開いたとき、問番号を見ただけで「何が出るか」「取りに行くか流すか」が分かる状態にします。

本番の時間配分

問37（設立）は取りに行き、問38〜40は1問1分で流す、というように、番号ごとの方針を先に決めておけます（得点設計の「商法は5問中1問」とつながります）。

直前の見直し

毎年ほぼ同じ番号に出るテーマは、毎年1問ぶんの点になります。直前の数日で、毎年出る番号のテーマから先に見直せます。

出題の型を知る

テーマだけでなく、「個数問題が多い」「判例の文章の穴埋め」など、その番号でよく使われる問い方も書きます。

ラボの他の教材へ戻る

各番号から、そのテーマの学習カード、演習D案の章、科目別マップへ移れるようにします。

これから調べること

  • 平成18〜令和7年度の問1〜57（約1,140問）を、問番号ごとに読んでテーマを付ける。
  • 番号ごとに、テーマ別の回数、直近5年の流れ、よく使われる問い方を数える。
  • 年度によって並びがずれる番号（行政法の後半、民法、基礎知識など）は、ずれ方も書く。基礎知識は令和6年度に科目の中身が変わったので、前後を分けて数える。
  • テーマに当たる学習カード、演習D案の章、科目別マップへのリンクを付ける。
