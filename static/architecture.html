LIVING ARCHITECTURE

3か月かけて育てる
行政書士の学習環境

問題を解くたびに履歴がたまり、その履歴から苦手教材を作り、また解く。過去問も○×カードも全6科目がそろいました。ここからは、解いた履歴をもとに中身を厚くしていきます。主役は○×学習カード229枚で、過去問569問はおまけです。過去問は本番での聞かれ方を確かめ、カードの根拠（実際の肢）を示すために置いています。

得点目標通常190〜200点・最低180点

ONE PAGE VIEW

ラボ全体は、2つの循環で動きます

上が教材を安全に増やす流れ、下が回答履歴を学習へ返す流れです。

① 教材を増やす流れ

取得過去問・解説非公開で保存
→
構造化問題・肢・正答形式を崩さない
→
候補化○×にできる肢没問等は除外
→
編集A・B二案・C解説・常識力も作る
→
検証根拠・類似関係小分けに確認
→
本番学習カード画面へ反映

どのカードにも「⑤ 実際の肢・本番での聞かれ方」を必ず付けます。組合せ問題から採った肢は、その旨を明示したうえで表示します。カードごとのIDも画面に出すので、直したい箇所をIDで指定できます。IDの隣には元問題へのリンクを置き、そのカードがどの年度のどの肢から作られたかをその場で確かめられます。

同じ場面なのに法律ごとに結論が変わるものは、「⑦ 法律ごとの結論くらべ」として一枚の表に並べます。行政手続法・行政不服審査法・行政事件訴訟法の三法だけでなく、民法と商法、民法と国家賠償法のように科目をまたぐ比較も置いています。1対1で比べる「⑥ 似た制度・他分野との違い」とは別枠で、どちらもデータのあるカードだけに出します。

カードにするのは、過去20年に実際に出題された論点だけです。法改正があっても、その条文が一度も問われていなければ独立したカードは作らず、既存カードの中身を現行法へそろえます。

② 解いた結果を次の学習へ返す流れ

1問題を解く科目別・全分野・弱点
→
2サーバーへ保存正誤・問題・時刻・所要時間
→
3集計してAI分析同じカードIDの直近5回答・連続正誤
→
4弱点教材を更新不得意ページ・比較解説

↖　更新した教材を、また解く　↙

出題から外す仕組みは2層あります。「習得済み」は正解が不正解より3回多くなると自動で付き、「絶対覚えた」は自分で押したときだけ付きます。どちらも普段の「おまかせ」と「苦手・要観察」から外れますが、「全問題を出す」と「卒業済みだけ」には含めます。「絶対覚えた」は全リセットの対象外です。解除しても、過去の回答と卒業した回数は消えません。回答ごとの手ごたえも記録しますが、これは後で分析するためのもので、出題には影響しません。

弱点分析は同じカードIDの全回答を使い、教材を直した前後も履歴を引き継ぎます。1回の誤答だけでは苦手と決めず、「要観察」「苦手」「回復中」「習得復帰」を根拠付きで分けます。「回復中」は直近2回連続正解なので苦手ビューから外し、回答保存後に分析も自動更新します。

STANDALONE PAGES

engineに載せない、独立した5ページ

共通エンジンに載せるほうが原則ですが、次の5つは目的が違うので別ページにしています。記録はいずれもブラウザのlocalStorageで、○×学習の回答履歴とは混ぜません。民法D案を実際の学習用とし、A・B・C案は比較素材として残します。

民法・固定配役ドリル（A案）1問1事例。役割で配役を固定し、事実だけの関係図を先に、答え入りの関係図を回答後に出す。16問
民法・固定配役ドリル（B案）1場面につき6〜7肢を続けて解く。場面はキャラクター入りのイラスト1枚。5場面31肢
民法・連続事例ドリル（C案）章の共通事例から1事実ずつ変えて要件を切り分ける。読む・解く・本番変換の3モード。3章27問
民法・法律家の常識ドリル（D案）最初の2周は答えから縦に読み、3周目から解く。素直／ひっかけ、前問との差分、救済理由、答え入り図を一体化。5章40問
行政事件訴訟法の暗記ドリル処分性・原告適格・狭義の訴えの利益。ここは理解ではなく、どの事案が○でどの事案が×かを判例ごとに覚える方針

年60問なのに、20年で1,139問なのはなぜ？

行政法440問とは？

行政法は毎年22問です。通常5肢択一19問、多肢選択2問、記述1問なので、20年で22×20＝440問です。全試験の問題数ではありません。

「○×候補」は何を数える？

通常5肢のうち、元の正解番号だけから1肢ずつ真偽を決められるものです。組合せ・個数・没問などを除きます。古い年度は、現行法でそのまま使える保証ではなく、頻出度の資料として扱います。

THREE-MONTH ROADMAP

11月までの育て方

大量生成を一度に行わず、20〜30論点ずつ、実際に解いて確かめながら進めます。

  1. 今〜8月初旬多科目化と弱点学習の土台

    全6科目569問、弱点snapshot、「苦手・要観察」ビューまで完了。

  2. 8月9月から学習を回す機能を作る

    全6科目229カードを掲載済みです。カードの大量追加より、押せば今日解く20〜30枚が出る「今日の学習」、90分の試験セッション、記述式の再回答を優先します。初見問題の取り置きは作りません。

  3. 9月229カードを一巡し、出力する

    間隔を空けて復習し、五肢択一・多肢選択・記述を毎週混ぜます。90分の半模試で誤答理由を貯めます。

  4. 10月前半3時間の本試験へ合わせる

    180分・60問を中心にし、最低点、足切り、記述抜き得点、時間超過を分けて確認します。

  5. 試験前3週復習へ集中

    新規大量追加を止め、混合演習・記述・苦手回復を中心にする。
