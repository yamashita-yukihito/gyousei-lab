ダウンロード（.md） 開いて中身を見る
  1. ダウンロードしたファイルをChatGPT（Web版・検索が使えるもの）へ添付する。
  2. 返ってきた回答を PASS_STRATEGY_RESEARCH_RESPONSE.md という名前で保存する。
  3. そのファイルをMac側の static/docs/ へ置くか、内容をそのまま貼って渡す。

依頼文の正本はこのディレクトリ（static/docs/）です。採用した判断は AGENTS.md・HANDOFF.md・ARCHITECTURE.md へ反映します。APIキーや個人情報は依頼文へ書きません。
