## 章 `lease` 賃貸借――建物の持ち主が替わっても、又貸ししても、住む人を守る

配役（固定）: しずか＝本人・所有者・普通の当事者、のび太＝守られる側・事情を知らない側、出木杉＝確認を尽くす側・転得者、スネ夫＝後から取引へ入る側

- `lead`（章のねらい）: しずかがのび太に甲建物を貸している場面から、建物の売却・敷金・費用の償還・又貸し（転貸）・賃貸借の解除まで、一事実ずつ動かします。
- `goal`（到達目標）: 住む人（賃借人・転借人）の生活の基盤を守りつつ、貸す人が賃料と建物を確実に回収できるようにする。
- `baseScenario`（章の共通事例）: しずかは、自分の甲建物をのび太に貸し、のび太は引渡しを受けて住んでいます。のび太は、契約のときに敷金20万円をしずかに預けました。
- `remedyGuide`（負ける側に残る救済）: 建物を明け渡すことになった賃借人・転借人も、貸主や又貸しした人へ、敷金の返還や債務不履行による損害賠償を求める道が残ります。明渡しの問題と、お金の清算の問題は分けて考えます。
- `summaryTable.note`（比較表の注）: 賃借人や転借人を守る規定は、「自分の知らないところで決まったことで追い出されない」ことを軸にしています。ただし、借主自身に賃料不払いがあれば、その結果は転借人にも及びます。

### 問 `minpo-d-ls-001`　賃貸人の地位の移転（素直・正解○）

- `delta`（前問から変えた1点）: 前「章の共通事例」→ 今回「しずかが甲建物を出木杉に売った（賃貸人の地位について特別な合意はない）」（変えないもの「のび太が引渡しを受けて住んでいること」）
- `currentScenario`（今回の事実）: しずかは、のび太に貸している甲建物を出木杉に売りました。賃貸人の地位をしずかに残すような合意はしていません。のび太には、売却について何も聞かれていません。
- `statement`（○×を判断する文）: のび太の承諾がなくても、甲建物の賃貸人の地位は、しずかから出木杉に移る。
- `explanation.summary`（答えの説明）: ○。対抗要件を備えた賃貸不動産が譲渡されると、賃貸人の地位は譲受人に移ります（605条の2第1項）。賃借人の承諾は要りません。
- `explanation.fact`（決め手の事実）: のび太は引渡しを受けており、賃借権の対抗要件がある
- `explanation.rule`（正確なルール）: 民法605条の2第1項・借地借家法31条
- `explanation.conclusion`（この事例の結論）: 出木杉が新しい賃貸人になる
- `explanation.protectWho`（誰を守る？）: 住み続けたいのび太
- `explanation.why`（誰を守る？（理由））: 建物を貸す義務は、だれが持ち主でも同じように果たせます。のび太にとって大事なのは住み続けられることで、貸主がだれかではありません。
- `explanation.ifOpposite`（反対の結論だと何が困る？）: 持ち主が替わるたびに賃借人の承諾が要るとすると、賃貸中の建物は売れなくなります。
- `explanation.legalSense`（法律家の常識へ補正）: 建物の引渡しが、建物の賃借権の対抗要件になる（借地借家法31条）。
- `explanation.minimum`（最小限の覚え方）: 対抗要件のある賃貸不動産の譲渡→賃貸人の地位は当然に移る
- `explanation.next`（次の問へのつなぎ）: 出木杉が登記をしないまま、のび太に賃料を請求したら。

- `explanation.minimum`（最小限の覚え方）: 承諾ある転貸＝賃貸人は転借人に直接請求できる（元の賃料の範囲で）

### 問 `minpo-d-ls-008`　賃料不払いによる解除と転借人（ひっかけ・正解○）

- `delta`（前問から変えた1点）: 前「話し合いによる合意解除」→ 今回「のび太が賃料を払わず、しずかが催告したうえで賃貸借を解除した（スネ夫には何も知らせていない）」（変えないもの「しずかの承諾を得た転貸があること」）

- `statement`（○×を判断する文）: のび太の賃料不払いを理由に賃貸借が解除されたので、スネ夫に支払の機会を与えていなくても、しずかはスネ夫に甲建物の明渡しを求めることができる。
- `explanation.summary`（答えの説明）: ○。賃借人の債務不履行で賃貸借が解除されたときは、賃貸人はそれを転借人に対抗でき、転借人に支払の機会を与える必要もありません（613条3項ただし書、最判昭和37年3月29日）。
- `explanation.fact`（決め手の事実）: 解除の理由はのび太の賃料不払い
- `explanation.rule`（正確なルール）: 民法613条3項ただし書（最判昭和37年3月29日）
- `explanation.conclusion`（この事例の結論）: しずかはスネ夫に明渡しを求められる

- `explanation.legalSense`（法律家の常識へ補正）: 合意解除（対抗できない）と債務不履行解除（対抗できる）の区別が、繰り返し出題される。
- `explanation.minimum`（最小限の覚え方）: 賃料不払いによる解除は転借人に対抗でき、転借人への催告も要らない
