# 演習D案 文章の読みやすさ点検 結果報告（minpo-1.md）

### minpo-d-lc-008
- 項目: statement
- 今: のび太が出木杉の同意を得ないでした遺産分割は、取り消すことができる。
- 案: のび太が出木杉の同意を得ずにした遺産分割は、取り消すことができる。
- 理由: 「得ないでした」は過去の助動詞「でした」と見誤りやすく引っかかりやすいため、「得ずにした」とすると一度でスムーズに読める。

### minpo-d-pr-007
- 項目: explanation.summary
- 今: 後順位抵当権者が順位が上がって受ける利益は、反射的な利益にすぎず、先順位抵当権の被担保債権の消滅時効を援用できません（最判平成11年10月21日）。
- 案: 後順位抵当権者は、順位が上がることによる利益が反射的な利益にすぎず、先順位抵当権の被担保債権の消滅時効を援用できません（最判平成11年10月21日）。
- 理由: 「利益は、…にすぎず、…援用できません」と主語が途中で利益から抵当権者へすり替わっており、「が」も連続して読みにくいため。

### minpo-d-reg-005
- 項目: explanation.why
- 今: 前主ではなく出木杉自身も、登記制度を害する目的で使っているからです。
- 案: 前主だけでなく出木杉自身も、登記制度を害する目的で使っているからです。
- 理由: 「前主ではなく」と「出木杉自身も」で係り受けがねじれているため、「前主だけでなく」にすると自然に理解できる。

### minpo-d-ua-007
- 項目: explanation.ifOpposite
- 今: 確認できた側が調査せず契約し、知らなかった代理人だけへ損失を押し付けられます。
- 案: 確認できた側が調査せず契約し、知らなかった代理人だけに損失を押し付けることになります。
- 理由: 「代理人だけへ損失を押し付けられます」は受身の構図が曖昧で引っかかるため、「代理人だけに損失を押し付けることになります」とすると不都合な帰結がすんなり頭に入る。
