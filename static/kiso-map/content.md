# 法の効力と形 | いつから・どれが優先・どう読む [抑えめ]
> 優先度：基礎法学は1問取れればよい。出やすいのは法の効力と優先関係。
- 公布と施行 [重要] :: 法律は官報で公布する。施行日は法律（附則）で定め、公布の日に即日施行することもできる。定めがなければ、公布の日から起算して20日を経過した日から施行（補充の規定） {leg-law-enforcement-date-001} @kiso-d/law-effect-terms
- 有効期間 :: 限時法は定めた期間が過ぎると効力を失う。期間の定めがなければ、廃止されるまで効力が続く {leg-law-effect-001} @kiso-d/law-effect-terms
- 優先関係 [重要] :: 特別法は一般法に優先する。同じ形式の法どうしなら後の法が前の法に優先する。ただし後からできた一般法は、前からある特別法に優先しない {leg-general-special-001} @kiso-d/law-effect-terms
- 条・項・号 [捨て候補] :: 条の中の段落が項、項の中の列挙が号。あとから間に足した条は「第◯条の2」（枝番号） {leg-law-form-structure-001}

# 法律の用語 | 要件・効果・事実 [捨て候補]
> 優先度：出題が少ない。
- 法律要件と法律効果 :: 法律要件がそろうと法律効果が生じる。法律要件は客観的な事実に限られず、意思表示も含む。要件に当たる具体的な事実が要件事実 {leg-terms-requirement-001}
- 立法事実 :: 法律が必要で合理的だと支える社会的・経済的な事実。訴訟で個別に認定する要件事実とは別 {leg-terms-legislative-fact-001}

# 裁判のしくみ | 三審制と簡易裁判所 [抑えめ]
> 優先度：審級と簡易裁判所の数字だけ押さえる。
- 審級 [捨て候補] :: 三審制。控訴審は民事が続審、刑事が事後審。上告審は法律審（原判決が確定した事実に拘束される） {leg-appeal-structure-001}
- 簡易裁判所が第1審のとき [捨て候補] :: 民事は地方裁判所へ控訴し高等裁判所へ上告。刑事は高等裁判所へ控訴し最高裁判所へ上告 {leg-appeal-court-001}
- 簡易裁判所の民事手続 [捨て候補] :: 訴額140万円以下。口頭でも訴えを起こせる。60万円以下の金銭の支払請求は少額訴訟を使える {leg-summary-court-001}
- 裁判員制度 :: 原則として裁判官3人と裁判員6人。評決は過半数で、裁判官と裁判員のそれぞれ1人以上が賛成していること {leg-lay-judge-001}
- 訴訟と非訟 [捨て候補] :: 訴訟は公開・対審・当事者が主張立証。非訟事件は非公開で、裁判所が職権で事実を調べるのが基本 {leg-procedure-principle-001}

# 法人 | 法人の種類 [捨て候補]
> 優先度：出題が少ない。
- 法人の分類 :: 一般社団法人・一般財団法人は登記だけで成立する。公益認定を受けると公益社団法人・公益財団法人。NPO法人は所轄庁の認証を受けて登記する {leg-corporation-type-001}
