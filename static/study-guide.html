HOW TO USE

やることは3つだけ

  1. ラボを開いて「○×学習」のタブへ行く LANのアドレスは http://192.168.10.102:8080/services/gyousei-lab/ です。
  2. 「出題範囲」を 今日の学習（間隔反復） に変える 切り替えた瞬間にサーバーが期日を計算し、その日に解くべき順で並びます。何も設定することはありません。
  3. 「カードの種類」を選ぶ（8月は暗記もの） 暗記もの158枚／理解もの88枚に分けてあります。暗記ものは、覚えていないと絶対に解けないものだけです。数字・期間・割合、どこへ出すか、列挙、分類、義務か努力義務か、判例の結論。8月はここだけを回します。
  4. 「1日の量」を選ぶ（初回だけ） 軽め（15分）／ふつう（30分）／しっかり（60分）／復習だけ、から選びます。選んだ内容はこの端末に覚えさせるので、毎回選び直す必要はありません。絞れるのは「はじめて」の枚数だけです。期日が来た復習は、絞っても溜まるだけなので全部出ます。
  5. 出てきた順に解いて、答えたあと「手ごたえ」を押す 確信あり／たぶん／あてずっぽうの3つです。これが次にいつ出すかを決めます。押さなかった場合は「たぶん」と同じ扱いになります。

終わりの合図はありません。並んでいるカードを解き切れば、それが今日の分です。途中でやめても、残りは次に開いたときに出てきます。

1日の量はじめて合計の上限目安の時間
軽め（8月向け）6枚20枚約15分
ふつう12枚40枚約30分
しっかり（9月以降向け）25枚80枚約60分
復習だけ0枚60枚期日が来た分だけ

時間の目安は、実際の回答記録（はじめて18秒・2回目以降8秒）に解説を読む時間を足して見積もったものです。

TWO KINDS

暗記ものと理解もの

246枚を2つに分けてあります。8月は「暗記もの」だけを回してください。15分しかない時期に、考える必要のあるカードを混ぜると終わりません。

暗記もの　158枚

覚えていないと絶対に解けない。考えても導けないもの。

  • 数字 — 審査請求は3か月・1年、取消訴訟は6か月・1年、監査役の解任は3分の2、出生の届出は14日
  • どこへ・誰に — 総会検査役は裁判所へ、行政書士の懲戒は知事、秩序罰は国の法律なら裁判所
  • 列挙 — 適用除外の4類型、定款の絶対的記載事項5つ、代襲の3原因
  • 分類・区別 — 保佐人と補助人の代理権、特別区と指定都市の区、絶対的商行為と営業的商行為
  • 義務か努力義務か — 審査基準は義務、処分基準は努力義務
  • 判例の結論そのもの — 用途地域は処分性なし、保育所廃止条例は処分性あり

科目別: 行政法65・基礎知識35・民法24・商法19・基礎法学8・憲法7

理解もの　88枚

趣旨や判断枠組みから考えれば導けるもの。9月から回します。

  • 行政裁量に対する司法審査のしかた
  • 信義則、公法と私法の適用関係
  • 人権規定の私人間効力、政教分離の目的効果基準
  • 即時取得と占有改定、法定地上権の趣旨
  • 国家賠償法1条の「公権力の行使」の広さ

科目別: 民法30・憲法20・行政法18・商法9・基礎知識7・基礎法学4

どちらも同じカードで、履歴はひとつです

別のアプリに分けたわけではありません。絞り込みを切り替えるだけで、回答履歴も期日も共通です。9月に「すべて」へ戻せば、8月に解いた分の期日はそのまま引き継がれます。

HOW IT DECIDES

正誤と手ごたえで、次の日が決まります

○×は2択なので、それだけでは「たまたま当たった」と「理由まで分かって当たった」を区別できません。そこで回答ごとの手ごたえを組み合わせて、4段階として扱っています。

あなたの答え手ごたえ内部の評価次に出るまでの目安（この評価が続いた場合）
間違えた—Again 1分後。つまり、その日のうちにもう一度出ます。伸びません。
正解したあてずっぽうHard 5分後のまま伸びません。理由が言えていないので、覚えたとは数えない扱いです。
正解したたぶん
（押さなかった場合も同じ）		Good 10分 → 2日 → 11日 → 46日 → 163日
正解した確信ありEasy 8日 → 66日 → 397日 → 5年

実際は「間違えた → 次は確信ありで正解」のように混ざるので、その場合は 1分 → 1日 → 5日 → 34日 → 217日 のように伸びていきます。上の表は、同じ評価がずっと続いたときの目安です。

CAUTIONS

先に知っておくとよいこと

「あてずっぽう」を押すと、そのカードは伸びません

これは不具合ではなく、そういう設計です。当たってはいるが理由が言えていないカードを、覚えたことにして遠ざけないためです。逆に言うと、あてずっぽうを押し続けたカードは永遠に出続けます。理由が言えるようになった回で「たぶん」か「確信あり」を押せば、そこから間隔が伸びはじめます。

間違えたカードは、その日のうちにまた出ます

1分後に期日が来る扱いなので、同じ日に開き直せばもう一度出てきます。間違えたまま翌日まで放置されることはありません。

「絶対覚えた」は今日の学習から外れます。ただし消えません

押したカードはこのキューに出てきません。ですが回答履歴も期日もそのまま残っています。解除すれば、押す前の続きからそのまま戻ってきます。「全問題を出す」と「卒業済みだけ」には、これまでどおり含まれます。

リセットを押すと、そのカードは「はじめて」に戻ります

リセットは「ここより前を数えない」という区切りです。次にいつ出すかの計算もそこから始め直しますが、過去の回答そのものは消えません。正答率や卒業した回数はこれまでどおり残ります。

受験日より先の期日は作りません

間隔の上限を受験日（2026年11月8日）までの残り日数にしてあります。これがないと、8月に「確信あり」で2回正解しただけで次が397日後になり、本番までに二度と出てこないカードができてしまいます。上限があるので、どのカードも必ず試験前にもう一度戻ってきます。残り日数が減るほど上限も縮むので、直前期は自然に総ざらいになります。

期日は保存していません。開くたびに計算しています

回答履歴だけを正本にして、そこから毎回組み立てています。だから、カードの文章を直しても、リセットを押しても、ずれた状態が残ることがありません。同じ履歴なら必ず同じ期日になります。

上の「はじめて」の枚数が、まだ一度も解いていないカードです。1日30枚なので、はじめて解く分だけなら1週間強で一巡します。

8月（1日15分）

  • 「暗記もの」＋「軽め」にします。はじめて6枚＋復習で、15分に収まります。
  • 暗記もの158枚を6枚ずつなら、約27日で一巡します。8月いっぱいでちょうど終わる計算です。
  • FP2級（8月末の実技・9月の学科）と重なる時期です。検索欄に FP と入れると、かぶり分野のカードだけを回せます（いまは21枚）。8月はここを優先しても構いません。

9月〜10月（1日2時間）

  • 「すべて」へ戻し、「しっかり」へ上げます。理解もの88枚を25枚ずつなら4日ほどで一巡できます。
  • 8月に解いた暗記ものは、期日が来たものだけが混ざってきます。やり直しにはなりません。
  • 一巡が終わると、今日出る枚数が自然に減っていきます。覚えたものの間隔が伸びるからです。
  • 減った分の時間を、90分の試験セッションと記述式に回します。2時間のうちカードに使うのは30〜60分で足りるようになります。
  • 「あてずっぽう」が残っているカードは伸びないので、そこが弱点そのものになります。

試験前3週

  • 「復習だけ」に切り替え、新しいカードを止めます。
  • 上限が残り日数まで縮むので、全カードが自然に総ざらいになります。自分で調整する必要はありません。

やらなくてよいこと

  • 期日を自分で調整する必要はありません。触るのは「1日の量」だけです。
  • 出た枚数を必ず解き切る必要もありません。残りは翌日へ回ります。
  • 過去問569問を周回する必要はありません。主役はカードで、過去問は聞かれ方を確かめるための参照用です。

ANKI

スマホのAnkiで回したいとき

ラボはLAN内でしか開けないので、外出先で回したいときはAnkiへ書き出します。回答履歴は同期しません。Ankiで解いた分はラボの期日に反映されないので、持ち出し用と割り切ってください。

書き出す

cd ~/dev/yuki-services/apps/gyousei-lab
python3.12 authoring/tools/anki_export.py \
  --evidence ~/.local/share/yuki-services/gyousei-lab/authoring/canonical/related_question_source.json \
  --output ~/Desktop/gyousei-cards.txt

科目で絞るときは --subject civil-law のように足します（administrative-law / civil-law / constitutional-law / commercial-law / general-knowledge / legal-foundations）。複数指定できます。

Ankiへ取り込む

  • Ankiのメニューから「ファイル」→「読み込む」で、書き出したテキストを選びます。
  • 区切り文字・HTML・ノートタイプ・タグ列は、ファイルの1行目に書いてあるので自動で設定されます。触る必要はありません。
  • 表にはA・B1・B2・Cが入り、裏に答えと解説が入ります。ラボと同じで、表を見ている間は答えが見えません。
  • タグに科目・分野・頻出度・カードIDが入るので、Anki側でも絞り込めます。
  • 図と比較表は出しません。テキストでは崩れるので、そこはラボの画面で見てください。

WHY FSRS

SM-2ではなくFSRSを使っている理由

SM-2（1987年・Ankiの旧方式）

  • カードごとに「難易度係数」を持ち、次の間隔＝いまの間隔 × 係数で伸ばします。
  • 係数は正解のたび少し上げ、不正解のたび下げるだけの単純な調整です。
  • 間違えが続くと係数が下限に張りついて、間隔が伸びなくなったまま戻らないという詰まり方をします（ease hellと呼ばれます）。
  • 掛け算の倍率は経験則で決めた固定値で、実際の記憶データに合わせたものではありません。

FSRS（2022年〜・いまのAnkiの標準）

  • カードごとに記憶の定着度・難しさ・思い出しやすさの3つを持ち、「◯日後に思い出せる確率」を予測します。
  • その確率が90%まで落ちる日を次の期日にします。掛け算ではなく予測です。
  • 予測式の係数は、実際のAnki利用者の膨大な復習記録に合わせて決められています。
  • 同じ正答率を保つのに必要な復習回数が、SM-2より少なくて済むと報告されています。

ただし、差はそれほど大きくありません

どちらを使っても「間違えたものは早く、覚えたものは遅く」という骨格は同じです。実際の点数を決めるのは、algorithmではなく毎日続けたかどうかです。FSRSを選んだのは、Ankiの標準でもあり、外部ライブラリをそのまま使えて自前の計算を書かずに済むからで、これで大きく変わると期待しているわけではありません。

仕組みの詳しいところ

スケジューラは py-fsrs（FSRSの公式Python実装）で、独自の計算はしていません。パラメータはライブラリの既定値をそのまま使っています。自分の記録に合わせて調整する機能もありますが、目安として1000件ほどの回答が要るので、いまの回答数では合わせすぎになるだけです。必要になれば10月ごろに検討します。

状態は card_attempts と card_marks から毎回導出していて、保存用のテーブルは作っていません。設計の理由は 全体構成図 と、リポジトリの study_queue.py の冒頭に書いてあります。
