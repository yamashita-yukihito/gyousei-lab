# 行政書士法 | 資格・業務・懲戒と2026年改正 [重点]
> 2026年1月1日施行の改正（令和7年法律第65号）は、改正後最初の試験で狙われやすい。改正点は「未出題」でもカードにしてある。
> 優先度：毎年のように出るうえ、2026年改正の直後。足切り（24点）対策の柱。
- 2026年改正 [重要] @chishiki-d/gyoseishoshi-law
  - 1条は「使命」 :: 業務を通じて行政手続の円滑な実施に寄与し、国民の利便に資し、国民の権利利益の実現に資することを使命とする（「この法律の目的」ではない） {gk-gyosei-law-mission-001}
  - 職責（1条の2第1項） :: 常に品位を保持し、法令と実務に精通して、公正かつ誠実に業務を行う。義務 {gk-gyosei-law-duty-001}
  - デジタル社会への対応（1条の2第2項） :: 情報通信技術の活用などで国民の利便の向上と業務の改善進歩を図るよう努める。努力義務 {gk-gyosei-law-digital-effort-001}
  - 業務の制限（19条1項） :: 行政書士でない者は「いかなる名目によるかを問わず」報酬を得て業務をしてはならない {gk-gyosei-law-unlicensed-fee-name-001}
  - 両罰規定（23条の3） :: 業務の制限の違反も対象。行為者のほか法人にも罰金刑 {gk-gyosei-law-dual-penalty-001}
- 資格 @chishiki-d/gyoseishoshi-law
  - 公務員の経験 :: 行政事務を通算20年以上（高校卒業者などは17年以上）担当した公務員は行政書士となる資格がある {gk-gyosei-law-qualification-001}
  - 欠格事由 :: 破産者は復権を得るまで。懲戒免職は処分の日から3年。業務の禁止を受けた者は処分の日から3年 {gk-gyosei-law-disqualification-001}
- 業務 @chishiki-d/gyoseishoshi-law
  - 報酬額の掲示 :: 事務所に掲示する義務がある。金額そのものは法定されていない {gk-gyosei-law-fee-display-001}
  - 特定行政書士 :: 行政書士が作成できる書類に関する許認可等について、不服申立ての代理ができる。その書類を誰が作成したかは問わない {gk-gyosei-law-specified-appeal-001}
- 懲戒 [重要] @chishiki-d/gyoseishoshi-law
  - 処分権者 :: 主たる事務所の所在地の都道府県知事（総務大臣ではない） {gk-gyosei-law-discipline-001}
  - 種類 :: 個人は戒告・2年以内の業務の停止・業務の禁止。行政書士法人は戒告・2年以内の業務の停止・解散 {gk-gyosei-law-discipline-001}
  - 業務の禁止と登録の抹消 :: 業務の禁止を受けると3年は欠格事由になるので、日本行政書士会連合会は登録を抹消しなければならない {gk-gyosei-law-registration-erasure-001}

# 情報公開と公文書管理 | 国の文書を作る・残す・見せる [抑えめ]
> 優先度：「何人も」と不開示情報の型を1周。
- 情報公開法 [重要] @chishiki-d/records-registers
  - 開示請求できる人 :: 何人も（国籍・住所・年齢・個人か法人かを問わない） {gk-joho-kokai-requester-001}
  - 不開示情報：個人に関する情報 :: 特定の個人を識別できるもの（個人識別型）。知られたくない内容かどうかは問わない {gk-joho-kokai-personal-identification-001}
    - モザイク・アプローチ :: 単独では識別できなくても、他の情報と照合すれば識別できるなら不開示 {gk-pip-mosaic-approach-001}
  - 不開示情報：事務・事業情報 :: 公にすると監査・検査・取締り・試験などの適正な遂行に支障を及ぼすおそれがある情報 {gk-joho-kokai-affairs-001}
- 公文書管理法 @chishiki-d/records-registers
  - 作成義務 :: 意思決定の過程や事務の実績を後から検証できるよう、行政機関の職員は文書を作成する {gk-kobunsho-duties-001}
  - 縛り方 :: 行政文書管理規則・廃棄には内閣総理大臣の同意。違法に廃棄した職員への罰則はない [ひっかけ] {gk-kobunsho-no-penalty-001}

# 個人情報保護 | 民間の義務と、行政機関等の義務 [重点]
> 令和3年改正で行政機関・独立行政法人等の法律が個人情報保護法へ一本化された。器は1つ、中身（章）は民間と行政で別。
> 優先度：毎年1〜2問。事業者の義務と委員会の権限は覚えればそのまま点になる。
- 制度の形 @chishiki-d/personal-information
  - 一元化 :: 法律は1つになったが、民間の事業者の義務（第4章）と行政機関等の義務（第5章）は別の章で、規律の中身は同じではない {gk-pip-public-private-001}
  - 個人識別符号 :: 政令で定めるものだけ。指紋データ・マイナンバー・旅券番号などは当たる。携帯電話番号・メールアドレス・クレジットカード番号は当たらない {gk-pip-identifier-code-001}
- 事業者の義務 [重要] @chishiki-d/personal-information
  - 不適正な利用の禁止 :: 違法・不当な行為を助長するおそれがある方法で利用しない。利用目的の変更は、関連性がある範囲まで {gk-pip-improper-use-001}
  - 第三者提供 :: 原則は本人の同意が要る。委託・事業の承継・共同利用の提供先は「第三者」に当たらないので同意は要らない {gk-pip-third-party-exception-001}
  - 提供の記録 :: 提供した側（29条）にも受け取った側（30条）にも記録の義務がある {gk-pip-provision-record-001}
  - 漏えい等の報告 :: 権利利益を害するおそれが大きい漏えい等は、原則として個人情報保護委員会へ報告し、本人へ通知する {gk-pip-leak-report-001}
  - 適用除外（57条1項） :: 報道・著述・宗教・政治の4類型だけ。学術研究機関は一律の適用除外ではなく、義務ごとの例外 {gk-pip-exemption-types-001} {gk-pip-academic-exception-001}
- 個人情報保護委員会 @chishiki-d/personal-information
  - 組織 :: 内閣府の外局。民間には立入検査、行政機関等には実地調査 {gk-pip-commission-power-001}
  - 行政機関等・地方公共団体への権限 :: 資料の提出の要求・実地調査・指導・助言・勧告まで。命令はできない {gk-pip-local-government-001}
  - マイナンバーカード :: 交付するのは市町村長。委員会は交付しない {gk-pip-commission-scope-001}

# 住民と戸籍・税 | 住民基本台帳・戸籍・住民税 [抑えめ]
> 優先度：条文の数字（14日など）を1周。
- 住民基本台帳 @chishiki-d/records-registers
  - 住民票の記載事項 :: 世帯を単位に作る。世帯主でない人は、世帯主の氏名と世帯主との続柄も載る {gk-juki-record-items-001}
  - 外国人住民 :: 中長期在留者・特別永住者なども、住所があれば住民基本台帳に記録される（外国人登録制度は廃止） {gk-juki-foreign-resident-001}
- 戸籍
  - 出生の届出 :: 国内で生まれたら14日以内、国外なら3か月以内 {gk-koseki-birth-notification-001}
- 住民税 :: 市町村民税は、住所のある個人だけでなく、事務所・事業所のある法人も納める {gk-local-tax-corporate-001}

# 情報通信 | 用語と制度 [抑えめ]
> 優先度：用語は知っていれば解ける。深追いしない。
- 通信の秘密 :: 通信の内容だけでなく、当事者・日時・回数など通信の存在そのものも守られる {gk-comm-secrecy-scope-001}
- 通信傍受 :: 対象犯罪が限られ、さらに裁判官が発する傍受令状が要る {gk-comm-interception-warrant-001}
- 行政のデジタル化
  - デジタル庁 :: 内閣に置かれる。重点計画・官民データ活用推進基本計画・マイナンバーも所掌 {gk-digital-agency-001}
  - LGWAN :: 地方公共団体どうしを結ぶ行政専用の閉域ネットワーク（インターネットから分離） {gk-gov-digital-001}
- 用語
  - ファームウェア :: 機器に組み込まれた制御用のソフトウェア。マルウェア（悪意のあるプログラム）ではない {gk-info-malware-001}
  - ハルシネーション :: 生成AIがもっともらしい誤りを出すこと。アノテーションは学習用データにラベルを付ける作業 {gk-info-hallucination-001}
- EUの制度 [捨て候補]
  - DSAとDMA :: DSAは利用者保護・違法コンテンツ対策、DMAは巨大プラットフォーム（ゲートキーパー）の競争ルール {gk-info-eu-law-001}
  - GDPR :: データポータビリティの権利、プロファイリングに異議を述べる権利などを個人に与える {gk-info-gdpr-001}
