GYOUSEI LAB / MOCK EXAM

本試験形式の通し演習

行政書士過去問ラボへ戻る

1年度分を180分で解き、科目別の点数・足切り・時間切れを本番と同じ数え方で出します。間違えた問題からは、対応する学習カードと民法演習Dの章へ戻れます。

このブラウザでは途中経過を保存できません。ページを閉じると解答が消えます。

SETUP

解く年度を選ぶ

  • タイマーは開始した時刻から数えます。ページを閉じたり再読み込みしたりしても、解答と経過時間は残ります。
  • 時間が来ても解答は続けられますが、時間を過ぎてから選んだ問題は「時間外」として別に数えます。
  • 記述式は答案を入力し、終了後に答案例と見比べて自分で点を付けます。
  • 終了すると回答を過去問の回答履歴へ保存し、採点結果（記述の自己採点・間違えた理由を含む）もサーバーに残します。学習カードの記録とは別です。

SELF GRADING

記述式を採点する

答案例と見比べて、1問20点のうち何点取れたかを選びます。キーワードが2つ合っていれば8〜12点、3つそろって文章が通れば16〜20点が目安です。

RESULT

採点結果

過去問の年度は、肢別過去問集やラボのカードで同じ肢をすでに解いていることがあります。その分、本番より点が少し高めに出ることがあります。
