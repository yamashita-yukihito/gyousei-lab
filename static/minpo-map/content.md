# 総則 | 人・意思表示・代理・時効 [重点]
> 民法の入口。だまされた人・未成年者など「守られる人」と、取引の相手方のどちらを守るかを先に決めると結論が出る。
> 優先度：毎年2〜3問。制限行為能力・意思表示・代理・時効は記述にも出る。
- 制限行為能力者 [重要] @minpo-d/limited-capacity
  - 4つの類型
    - 未成年者 :: 法定代理人の同意のない行為は取り消せる。単に権利を得る・義務を免れる行為と、処分を許された財産は単独でできる
    - 成年被後見人 :: 日用品の購入など日常生活に関する行為以外は取り消せる。後見人の同意があっても取り消せる
    - 被保佐人 :: 13条1項の重要な行為（借金・保証・不動産の売買など）に保佐人の同意が要る
    - 被補助人 :: 審判で選んだ特定の行為だけ、補助人の同意が要る
  - 同意権・代理権を付け足す審判 :: 保佐は同意権が法定＋審判で追加、代理権は審判で。補助は同意権も代理権も審判で。本人以外が請求するなら本人の同意が要る {min-general-assistance-consent-agency-001}
  - 成年後見人の代理権 [抑えめ] :: 財産に関する法律行為について包括的。特定の行為だけに限られるのは補助人（審判で付けたとき） {min-general-voluntary-guardianship-001}
  - 相手方からの催告 :: 一人で追認できる人に催告して返事がなければ追認とみなす。被保佐人・被補助人本人に催告して返事がなければ取消しとみなす {min-general-capacity-demand-001}
  - 詐術 :: 能力者だと信じさせる詐術を使った制限行為能力者は取り消せない。黙っていただけなら詐術ではない（黙秘＋ほかの言動で誤信させたら詐術） {min-general-capacity-fraud-001}
- 失踪の宣告 [捨て候補] :: 普通失踪は生死不明7年で、期間満了時に死亡とみなす。危難失踪は危難が去って1年で、危難が去った時に死亡とみなす {min-general-disappearance-declaration-001}
- 意思表示 [重要] @minpo-d/declaration-third-party
  - 心裡留保 :: 原則有効。相手方が真意でないと知っていたか、知ることができたときは無効
  - 虚偽表示 :: 無効。ただし善意の第三者には無効を対抗できない（第三者の無過失は要らない）
    - 第三者に当たらない例 [ひっかけ] :: 仮装譲渡された土地の上の建物を借りた人（土地については利害関係がない） {min-general-false-representation-third-party-001}
  - 錯誤 :: 重要な錯誤なら取り消せる。動機の錯誤は、その事情が表示されていたときだけ。表意者に重過失があれば原則取り消せない（相手方が悪意・重過失のとき、共通錯誤のときは取り消せる） {min-general-mistake-gross-negligence-001}
  - 詐欺 :: 取り消せる。善意無過失の第三者には取消しを対抗できない
  - 強迫 :: 取り消せる。善意無過失の第三者にも取消しを対抗できる
  - 第三者がだました・脅した場合 :: 詐欺は、相手方が詐欺を知っていたか知ることができたときだけ取り消せる。強迫は相手方が知らなくても取り消せる {min-general-third-party-fraud-duress-001}
- 代理 [重要] @minpo-d/unauthorized-agency
  - 無権代理
    - 本人の追認 :: 追認すると、契約の時にさかのぼって本人に効力が生じる。追認を拒絶することもできる
    - 相手方の催告 [捨て候補] :: 相手方は本人に対して、相当の期間を定めて追認するかを催告できる。返事がなければ追認拒絶とみなす {min-general-unauthorized-agency-demand-001}
    - 相手方の取消権 :: 契約時に無権代理だと知らなかった相手方は（過失があっても）、本人が追認するまで契約を取り消せる {min-general-unauthorized-agency-rescission-001}
    - 無権代理人の責任（117条） :: 相手方は無権代理人に対して、履行か損害賠償を請求できる。相手方に過失があっても、無権代理人が自分の無権限を知っていれば、相手方は無権代理人の責任を追及できる {min-general-unauthorized-agency-liability-001}
    - 無権代理と相続 [ひっかけ] :: 無権代理人が本人を単独で相続すると、無権代理人は追認を拒絶できない。本人が無権代理人を相続したときは、本人は追認を拒絶できるが、117条の責任は相続する {min-general-unauthorized-agency-succession-001}
  - 表見代理 :: 代理権を与えたと表示した（109条）・権限の外の行為（110条）・代理権が消えた後（112条）。相手方は善意無過失であることが必要
- 時効 [重要] @minpo-d/prescription
  - 援用 :: 時効は援用しないと効果が出ない。援用できるのは保証人・物上保証人・第三取得者など。後順位抵当権者は援用できない {min-general-prescription-invoker-001}
  - 債権の消滅時効 :: 権利を行使できることを知った時から5年、または権利を行使できる時から10年
  - 生命・身体の侵害による損害賠償 [捨て候補] :: 知った時から5年、権利を行使できる時（不法行為なら不法行為の時）から20年。債務不履行でも不法行為でも同じ {min-general-prescription-life-body-five-years-001}
  - 取得時効 :: 所有の意思をもって平穏・公然に占有を続ける。占有を始めた時に善意無過失なら10年、そうでなければ20年
  - 完成猶予と更新 :: 裁判上の請求などで完成が猶予され、確定判決や承認で更新される（新たに一から進む）

# 物権 | 物の支配と、登記・占有 [重点]
> 不動産は登記、動産は引渡し（占有）で第三者に対抗する。「誰が誰に対して何を主張できるか」を図にして読む。
> 優先度：177条の第三者と即時取得は頻出。登記の場面ごとの結論、物権的請求権の相手方、共有の決め方まで。占有の訴えと盗品は今年は飛ばす。
- 不動産の物権変動と登記 [重要] @minpo-d/registration
  - 177条の「第三者」 :: 登記がないことを主張する正当な利益がある者。単に先の譲渡を知っていただけの悪意者は第三者に当たる。背信的悪意者は当たらない {min-property-registration-bad-faith-001}
  - 取得時効と登記 :: 時効が完成する前に所有者から買った人には、時効取得者は登記なしで対抗できる。完成した後に買った人とは対抗関係になり、登記が要る {min-property-prescription-registration-001}
  - 相続と登記 :: 相続放棄は登記なしで対抗できる。遺産分割・遺贈、法定相続分を超える部分の取得は登記が要る {min-inheritance-renunciation-registration-001}
  - 建物収去・土地明渡しの相手方 :: 建物を実際に所有する人。ただし自分の意思で建物の登記を得た人は、建物を譲渡しても登記名義を持っている限り、土地所有者に対して収去義務を免れない {min-property-removal-claim-registrant-001}
- 即時取得 [重要] @minpo-d/good-faith-acquisition
  - 要件 :: 動産を、取引によって、平穏・公然・善意無過失で占有を始めた
  - 占有改定 [ひっかけ] :: 外から見て占有が変わらないので、即時取得できない {min-property-good-faith-acquisition-001}
  - 盗品・遺失物 [捨て候補] :: 盗まれた人は2年間、取得した人に対して返還を請求できる。取得者が商人から買っていたら代価を弁償する。弁償を受けるまでは、取得者は物を使ってよい {min-property-stolen-goods-recovery-001}
- 占有の訴え [捨て候補] @minpo-d/possession-easement
  - 占有回収の訴え :: 占有を奪われたとき、1年以内に、物の返還と損害賠償を請求できる。預かっている人・借りている人も起こせる {min-property-possession-recovery-001}
- 共有 [重点] @minpo-d/co-ownership
  - 決め方 :: 保存行為は各共有者が単独で、管理は持分の価格の過半数で、変更は全員の同意で（軽微な変更は過半数）
  - 不法占拠者への請求 :: 明渡しは保存行為として、各共有者が単独で全部を請求できる。損害賠償は持分の割合の分だけ {min-property-co-ownership-claims-001}

# 担保物権 | 貸したお金の回収を確保する [抑えめ]
> 留置権・先取特権は法律が当然に与える担保、質権・抵当権は契約で作る担保。抵当権は物上代位と賃貸との関係がよく出る。
> 優先度：毎年1問程度で、制度が多い。抵当権・動産の担保（譲渡担保と動産売買の先取特権）に絞る。根抵当権と法定地上権は時間が余れば。留置権と質権は今年は飛ばす。
- 留置権 [捨て候補] @minpo-d/lien-pledge
  - 成立 :: その物に関して生じた債権があること。占有が不法行為によって始まったときは成立しない {min-security-retention-lien-001}
  - 第三者への主張 :: 売主は代金を受け取るまで、買主から目的物を買った第三者に対しても留置権を主張できる {min-security-retention-lien-transferee-001}
- 先取特権
  - 動産売買の先取特権 [重点] :: 買主が目的物を第三取得者に引き渡すと、売主はその物に先取特権を行使できない（333条） {min-security-movables-sale-preference-third-party-001}
- 質権 [捨て候補] :: 動産質・不動産質・権利質。目的物の引渡しで成立する。不動産質権者は設定者の承諾なしで使用収益できるが、その代わり利息を請求できない {min-security-pledge-001}
- 抵当権 [重点] [重要] @minpo-d/mortgage
  - 物上代位 :: 賃料・保険金・売買代金にも及ぶ。抵当権者は、払渡しの前に自分で差し押さえる必要がある {min-security-subrogation-attachment-001}
  - 妨害排除 :: 占有者のせいで抵当不動産の価値の実現が妨げられるとき、抵当権者は占有者に対して妨害排除を請求できる {min-security-mortgage-interference-001}
  - 建物の賃借人の明渡猶予（395条） :: 抵当権に対抗できない建物の賃借人は、競売の買受けから6か月は明渡しを猶予される。ただしその間の使用の対価は払う {min-security-mortgage-lessee-grace-001}
  - 根抵当権 [抑えめ] :: 元本の確定前なら、被担保債権の範囲を変えるのに後順位抵当権者の承諾は要らない（確定前に登記は必要） {min-security-revolving-mortgage-001}
    - 元本確定後 :: 設定者は極度額を「今ある債務＋以後2年分の利息・損害金」まで減らすよう請求できる {min-security-revolving-reduction-001}
- 法定地上権 [抑えめ] @minpo-d/statutory-superficies
  - 要件 :: 抵当権を設定した時に土地の上に建物があり、土地と建物が同じ所有者。競売で別々の所有者になった {min-security-statutory-superficies-same-owner-001}
- 譲渡担保 [重点] @minpo-d/transfer-security
  - 集合動産 :: 種類・所在場所・量的範囲で特定できれば、倉庫の在庫全体のような集合動産にも設定できる {min-security-collective-movables-001}

# 債権総論 | 債権の効力・保証・債権譲渡・弁済 [重点]
> 2020年の改正で連帯債務の絶対効が大きく減った。改正前の結論で覚えていないかを確かめる。
> 優先度：連帯債務・保証・相殺が頻出。2020年改正後の結論で覚える。
- 責任財産の保全 [抑えめ] @minpo-d/creditor-protection
  - 債権者代位権 [抑えめ] :: 債務者が権利を行使しないとき、債権者が代わりに行使する。代位行使が始まっても、債務者は自分で取り立てたり処分したりできる {min-obligation-creditor-subrogation-001}
  - 詐害行為取消権 [捨て候補] :: 債務者が債権者を害すると知ってした行為を、債権者が裁判で取り消す。相続放棄は対象にならない {min-inheritance-renunciation-effect-001}
- 多数当事者 [重要] @minpo-d/guarantee-joint
  - 連帯債務 :: 弁済・相殺・更改・混同は他の連帯債務者にも効く（絶対効）。請求・免除・時効の完成は効かない（相対効） {min-obligation-joint-liability-effects-001}
  - 連帯債務者の求償と通知 [抑えめ] :: 弁済する前と後に他の連帯債務者へ通知しないと、求償が制限されることがある {min-obligation-joint-notice-001}
  - 保証 :: 保証債務は主たる債務に従う（付従性）。主たる債務者について時効の完成猶予・更新があると保証人にも及ぶ。保証人について生じた事由は、原則として主たる債務者に及ばない {min-obligation-guarantee-prescription-001}
- 債権譲渡 @minpo-d/assignment-setoff
  - 譲渡制限の特約 :: 特約があっても譲渡は有効。債務者は、特約を知っていたか重過失で知らなかった譲受人に対しては履行を拒める {min-obligation-assignment-restriction-001}
  - 対抗要件 :: 債務者に対しては通知か承諾。債務者以外の第三者に対しては、確定日付のある証書による通知か承諾
- 相殺 @minpo-d/assignment-setoff
  - 差押えと相殺 :: 第三債務者は、差押えの前に取得した債権なら、差押えの後でも相殺を差押債権者に対抗できる（511条） {min-obligation-setoff-attachment-001}
- 弁済 [抑えめ] @minpo-d/payment
  - 口頭の提供 :: 債権者があらかじめ受領を拒んでいるときは、弁済の準備をしたことを通知して受領を催告すれば足りる {min-obligation-oral-tender-001}
  - 代物弁済 [捨て候補] :: 所有権は合意で移る。債務が消えるのは、代わりの給付をしたとき（不動産なら登記を済ませたとき） {min-obligation-substitute-performance-001}

# 契約 | 売買・貸し借り・仕事を頼む [重点]
> 賃貸借は「建物の持ち主が替わる」「又貸しする」の2つの場面で、借りている人をどう守るかを見る。
> 優先度：解除と賃貸借が頻出。誰が誰に何を請求できるかで覚える。
- 解除 @minpo-d/sale-rescission
  - 催告解除 :: 相当の期間を定めて催告し、期間内に履行がなければ解除できる。不履行が軽微なら解除できない。債務者の帰責事由は要らない {min-contract-termination-minor-breach-001}
- 売買 @minpo-d/sale-rescission
  - 契約不適合 :: 買主はまず追完（修補・代替物）を請求できる。催告しても追完がなければ代金の減額を請求できる。損害賠償・解除もできる {min-contract-nonconformity-remedy-001}
  - 通知の期間 :: 種類・品質の不適合は、買主が知った時から1年以内に売主へ通知する
- 贈与・使用貸借 [抑えめ] @minpo-d/gift-loan
  - 使用貸借の解除 :: 借主はいつでも解除できる。貸主は期間も目的も定めなかったときに限っていつでも解除できる {min-contract-loan-for-use-rescission-001}
- 賃貸借 [重要] @minpo-d/lease
  - 賃貸人の地位の移転 :: 対抗要件を備えた賃借人がいる不動産を譲渡すると、賃貸人の地位も新しい所有者へ移る（賃料を請求するには登記が要る）。敷金を返す債務も新しい所有者が引き継ぐ {min-contract-lessor-transfer-deposit-001}
  - 承諾を得た転貸 :: 転借人は賃貸人に対して直接、賃料を払う義務を負う（元の賃料の範囲で） {min-contract-sublease-direct-rent-001}
  - 元の賃貸借の合意解除 :: 賃貸人は、合意解除を転借人に対抗できない。賃借人の債務不履行による解除なら対抗できる {min-contract-sublease-mutual-termination-001}
  - 費用の償還 :: 賃借人は、必要費は直ちに、有益費は賃貸借が終わったときに、賃貸人に請求できる {min-contract-lease-necessary-expenses-001}
  - 借地借家法 [捨て候補] :: 建物所有目的の土地の賃貸借と、建物の賃貸借に適用される。公営住宅の使用関係にも、特別の定めがない限り適用される {min-contract-leased-land-act-scope-001}
- 請負・委任・寄託 [抑えめ] @minpo-d/work-mandate-deposit
  - 請負の報酬 :: 注文者は、目的物の引渡しと同時に報酬を払う。仕事の完成は報酬より先（完成しただけでは、請負人は先払いを求められない） {min-contract-work-remuneration-timing-001}

# 事務管理・不当利得・不法行為 | 契約がないのに生じる債権 [抑えめ]
> 優先度：不法行為（使用者責任など）だけは頻出。事務管理・不当利得は条文の結論だけ。
- 事務管理 @minpo-d/management-unjust
  - 有益費 :: 本人のために有益な費用を払った管理者は、本人に償還を請求できる。報酬は請求できない {min-contract-negotiorum-gestio-useful-expenses-001}
- 不当利得 @minpo-d/management-unjust
  - 不法原因給付 :: 不法な原因で給付した人は返還を請求できない。不法な原因が受け取った側だけにあるときは請求できる {min-contract-illegal-cause-performance-001}
- 不法行為 [重点] [重要] @minpo-d/tort
  - 使用者責任 :: 被用者が事業の執行について与えた損害は、使用者も賠償する。賠償した使用者は、被用者に対して信義則上相当な範囲でだけ求償できる {min-tort-employer-liability-recourse-001}
  - 工作物責任 :: まず占有者が責任を負う（必要な注意をしていれば免責）。占有者が免責されると所有者が責任を負う（所有者は無過失責任） {min-tort-structure-owner-001}
  - 医療水準 [抑えめ] :: 医師の注意義務の基準は、診療当時の臨床医学の実践における医療水準 {min-tort-medical-standard-001}
  - 名誉毀損 [抑えめ] :: 名誉とは社会から受ける客観的な評価。自分で持つ名誉感情は含まない {min-tort-defamation-honor-001}
  - 消滅時効 :: 被害者が損害と加害者を知った時から3年（生命・身体の侵害は5年）、不法行為の時から20年

# 親族 | 家族をつくる手続 [捨て候補]
> 優先度：配点が少ないのでかなり飛ばす。普通養子と特別養子の違いと、財産分与だけ。
- 離婚 @minpo-d/family
  - 財産分与と慰謝料 [抑えめ] :: 財産分与には清算・扶養・慰謝料の要素がありうる。財産分与で精神的苦痛が償われないなら、別に慰謝料を請求できる {min-family-divorce-property-001}
- 親子 @minpo-d/family
  - 認知 [捨て候補] :: 出生の時にさかのぼって効力が生じる。認知をした父や母は、認知を取り消せない {min-family-acknowledgement-effect-001}
  - 普通養子と特別養子 [重点] [重要] :: 特別養子は家庭裁判所の審判で成立し、実方との親族関係が終わる。普通養子は実方との関係が残り、実親と養親の両方を相続できる {min-family-adoption-types-001}

# 相続 | 誰がどれだけ受け継ぐか、遺言の形 [捨て候補]
> 優先度：配点が少ないのでかなり飛ばす。法定相続分、預貯金の遺産分割、相続させる遺言と登記だけ。
- 相続人と相続分 @minpo-d/inheritance
  - 法定相続分 [抑えめ] :: 配偶者と子は1/2ずつ、配偶者と直系尊属は2/3と1/3、配偶者と兄弟姉妹は3/4と1/4。養子も実子と同じ割合 {min-inheritance-statutory-share-001}
  - 代襲相続 [捨て候補] :: 相続人の死亡・欠格・廃除で起きる。相続放棄では起きない {min-inheritance-substitution-cause-001}
  - 相続放棄 [捨て候補] :: 初めから相続人でなかったことになる。詐害行為取消権の対象にならない {min-inheritance-renunciation-effect-001}
  - 遺産分割の対象 [抑えめ] :: 預貯金債権も遺産分割の対象（相続開始と同時に当然には分割されない） {min-inheritance-deposit-division-001}
  - 遺留分 :: 兄弟姉妹にはない。侵害された人は、受遺者などに対して遺留分侵害額に相当する金銭を請求する
- 遺言 [重要] @minpo-d/will
  - 自筆証書遺言 :: 全文・日付・氏名を自書して押印する。財産目録だけは自書でなくてよい（各ページに署名押印） {min-inheritance-holograph-will-001}
  - 共同遺言 [捨て候補] :: 2人以上が同じ証書でする遺言はできない {min-inheritance-joint-will-001}
  - 撤回 [捨て候補] :: いつでも遺言の方式で撤回できる。前の遺言と食い違う遺言や生前の処分は、撤回したとみなされる {min-inheritance-will-revocation-001}
  - 成年被後見人の遺言 :: 判断能力を一時回復したとき、医師2人以上の立会いがあればできる {min-inheritance-ward-will-001}
  - 受遺者が先に死亡 [捨て候補] :: 遺贈は効力を生じない（受遺者の相続人が代わりに受けることはない） {min-inheritance-legatee-predecease-001}
  - 相続させる遺言と登記 [抑えめ] :: 遺言で受け継いだ部分でも、法定相続分を超える部分は登記がないと第三者に対抗できない {min-inheritance-specific-succession-registration-001}
