  目安 :: 法律の問題は、ほとんどが「誰が、誰に、何を言えるか」です
  理由 :: 法律は、ぶつかった2人のどちらを勝たせるかを決める道具です。争っている2人が決まらないと、どの条文を使うかも決まりません。
  使い方 :: 肢を読む前に、主語と相手に印を付けます。「原告か被告か」「賃貸人か転借人か」が入れ替わっていないかを確かめます。

- 概念 :: 法律は「原則と例外」でできている
  目安 :: 原則を例外に、例外を原則にひっくり返した肢が定番です
  理由 :: 条文はまず原則を書き、特別な理由があるときだけ例外を置きます。原則さえ覚えていれば、例外の細部を忘れても、肢の向きは判定できます。
  使い方 :: 「それは原則か、例外か」と問います。処分の執行は止まらないのが原則で、止まるのが原則と書いた肢は誤りです。黙秘は詐術でないのが原則で、他の言動が加わると例外的に詐術になります。

- 概念 :: 両方の言い分を天秤にかける

  使い方 :: 登場人物ごとに、落ち度と信頼を比べます。自分で嘘の外形を作った人は負けやすく、脅された人は勝ちやすいと判定します。
