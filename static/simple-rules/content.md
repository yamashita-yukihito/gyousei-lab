## 行政法

- 概念 :: 訴えても、処分は止まらない
  解説 :: 審査請求も取消訴訟も、起こしただけでは処分の効力は止まりません（行政不服審査法25条1項、行政事件訴訟法25条1項）。止めたい人は、別に執行停止を申し立てます。無効確認訴訟でも同じです。
  具体例 :: 営業停止処分を受けた店主が取消訴訟を起こしても、店主は判決まで営業を再開できません。店主が営業を続けたいなら、裁判所に執行停止を申し立てます。
  過去問 :: 平成24年問16肢3× 平成19年問18肢3×
  カード :: gyo-litigation-stay-001

- 概念 :: 被害者は、公務員個人に賠償を請求できない
  解説 :: 国家賠償法1条の責任を負うのは国や自治体です。公務員に故意や重大な過失があっても、被害者が公務員に直接請求できるようにはなりません。「故意・重過失」は、国や自治体が公務員に求償するときの条件です。
  具体例 :: 警察官に違法に殴られた被害者は、警察官本人ではなく県に賠償を請求します。県が被害者に払ったあと、警察官に故意や重過失があれば、県が警察官に求償します。
  過去問 :: 令和6年問21肢2× 平成26年問19肢ア○
  カード :: gyo-state-comp-public-official-liability-001

- 概念 :: 申請の拒否に、聴聞も弁明も要らない
  解説 :: 申請の拒否は不利益処分ではないので（行政手続法2条4号ロ）、行政庁は聴聞も弁明の機会の付与も執りません。ただし、理由は示します（8条）。
  具体例 :: 飲食店の許可を申請した人に行政庁が不許可を出すときは、聴聞を開きません。すでに持っている許可を行政庁が取り消すときは、聴聞を開きます。
  過去問 :: 令和2年問12肢2× 平成30年問11肢3×
  カード :: gyo-aps-refusal-hearing-001

- 概念 :: 審査基準は義務、処分基準は努力義務
  解説 :: 申請を審査する物差し（審査基準）は、行政庁が定めなければなりません（5条）。不利益処分の物差し（処分基準）は、定めることも公にすることも努力義務です（12条）。
  具体例 :: 許可を出すかどうかの基準は、行政庁が必ず作ります。許可を取り消すかどうかの基準は、行政庁が作るよう努めるだけで足ります。
  過去問 :: 平成19年問12肢イ○ 平成23年問12肢4○
  カード :: gyo-aps-review-criteria-001 gyo-aps-disposition-standard-001

- 概念 :: 標準処理期間を過ぎても、拒否とはみなされない
  解説 :: 標準処理期間は目安です。過ぎても、法律が結論を決めてくれることはありません。申請者が争うなら、不作為として争います。
  具体例 :: 標準処理期間が30日の申請を行政庁が60日放置しても、申請が拒否されたことにはなりません。申請者は、不作為の審査請求や不作為の違法確認訴訟を使います。
  過去問 :: 平成20年問12肢4× 令和2年問13肢オ×
  カード :: gyo-aps-standard-period-001

- 概念 :: 行政指導に従わない人を、不利益に扱ってはいけない
  解説 :: 行政指導に携わる者は、相手方が従わなかったことを理由に不利益な取扱いをしてはなりません（32条2項）。行政指導の根拠が法律にあるかどうかで、この結論は変わりません。
  具体例 :: 役所が業者に価格の引下げを指導し、業者が断ったとします。役所は、断ったことを理由に業者を取引から外すことはできません。
  過去問 :: 令和3年問13肢ア×

- 概念 :: 入口で失格なら却下、中身で負けたら棄却
  解説 :: 処分性・原告適格・訴えの利益・出訴期間などの要件を欠けば、裁判所は訴えを却下します。審理した結果、原告の主張に理由がなければ、裁判所は請求を棄却します。

  カード :: gyo-litigation-dismissal-rejection-001

- 概念 :: 通達は内部の命令で、国民を拘束せず、処分でもない
  解説 :: 通達は、上級行政機関が下級行政機関に出す命令です。内容が国民の権利に大きく関わっていても、外に向けた行為ではないので、取消訴訟の対象になりません。
  具体例 :: 国税庁長官が全国の税務署長に法律の解釈を通達で示しても、納税者はその通達の取消訴訟を起こせません。納税者は、通達に沿って出された個別の課税処分を争います。

- 概念 :: 委任の範囲を超えた命令は、無効
  解説 :: 委任命令は、法律から借りた権限で作るルールです。委任の範囲を超えた部分は、誰かが取り消すまでもなく無効です。行政処分の公定力と混ぜた肢が誤りになります。
  具体例 :: 法律が委任していない制限を省令が国民に課しても、その部分は初めから無効です。役所が「取り消すまでは有効」と扱うことはできません。

## 民法

- 概念 :: 動機は、黙示の表示でもよい
  解説 :: 動機の錯誤で取り消すには、その動機が法律行為の基礎として表示されている必要があります（95条2項）。表示は黙示でもかまいません（最判平元.9.14）。「黙示」の語が民法の肢に出たのは20年でこの2肢だけで、どちらも黙示でよいという結論です。ただし、動機をまったく表示していないときは取り消せません。
  具体例 :: 離婚の財産分与で夫が「自分に税金はかからない」と思って不動産を渡し、その前提が態度から妻に伝わっていれば、夫は錯誤を主張できます。
  過去問 :: 平成29年問28肢5○ 平成25年問27肢ウ× 平成29年問28肢4○
  カード :: min-general-mistake-gross-negligence-001

- 概念 :: 相続放棄だけは、代襲相続が起きない
  解説 :: 代襲の原因は、死亡・欠格・廃除の3つです。放棄した人は初めから相続人でなかったことになるので、放棄した人の子は代襲しません。
  具体例 :: 長男が相続を放棄すると、長男の子は祖父を代襲相続できません。長男が廃除された場合や、祖父より先に死亡した場合は、長男の子が代襲相続します。
  過去問 :: 平成19年問35肢エ× 平成19年問35肢オ× 平成21年問35肢エ×
  カード :: min-inheritance-substitution-cause-001

- 概念 :: 工作物の所有者は、過失がなくても責任を負う
  解説 :: 土地の工作物責任は、まず占有者が負い、占有者が必要な注意をしていたときは所有者が負います（717条）。所有者に免責の道はありません。瑕疵が前の所有者の時代にできたものでも同じです。
  具体例 :: 中古の宅地を買ったAさんが、擁壁の欠陥を知らないまま住んでいて、擁壁が崩れて隣人にけがをさせたとき、Aさんは「知らなかった」と主張しても責任を負います。
  過去問 :: 令和元年問34肢3○
  カード :: min-tort-structure-owner-001

- 概念 :: 使用者は、被用者に全額を求償できるとは限らない
  解説 :: 被害者に賠償した使用者が被用者に求償できるのは、信義則上相当と認められる限度までです（最判昭51.7.8）。使用者は被用者の働きで利益を得ているからです。
  具体例 :: 運送会社が、運転手の事故の被害者に1000万円を払っても、運送会社は運転手に1000万円全額を当然には請求できません。
  過去問 :: 平成28年問34肢ア×
  カード :: min-tort-employer-liability-recourse-001

- 概念 :: 請負の報酬は、引渡しと同時に払う
  解説 :: 物の引渡しが要る請負では、注文者は、完成時ではなく引渡しと同時に報酬を払います（633条）。仕事の完成は報酬より先です。
  具体例 :: 大工が家を完成させても、引き渡す前なら、施主は大工からの報酬の請求を拒めます。
  過去問 :: 令和2年問32肢4× 平成18年問32肢ア×
  カード :: min-contract-work-remuneration-timing-001

- 概念 :: 必要費は直ちに、有益費は賃貸借の終了時に
  解説 :: 賃借人は、必要費は支出後すぐに、有益費は賃貸借が終わったときに、賃貸人へ償還を請求します（608条）。
  具体例 :: 借家の壊れた屋根を直した賃借人は、すぐに修理代を家主に請求できます。賃借人が好みで床を張り替えて家の価値が上がった分は、退去時に家主に請求します。
  過去問 :: 平成29年問33肢1× 平成24年問33肢1×
  カード :: min-contract-lease-necessary-expenses-001

## 憲法

- 概念 :: 検閲は絶対に禁止。裁判所の差止めは検閲ではない
  解説 :: 検閲は、行政権が発表前に網羅的に審査して発表を禁止することで、例外がありません。裁判所の事前差止めは検閲に当たらず、厳格な要件のもとで許されることがあります。
  具体例 :: 役所が出版前に全書籍を審査して発禁にする仕組みは、例外なく違憲です。名誉を傷つけられた人の申立てで裁判所が雑誌の販売を差し止めるのは、検閲ではありません。
  過去問 :: 令和2年問4肢4○ 平成22年問3肢エ○ 令和元年問6肢2×
  カード :: con-exp-censorship-prior-restraint-001

- 概念 :: 法律の代わりになる政令は作れない
  解説 :: 政令は、法律を実施するものと、法律の委任を受けたものだけです。国会が閉会中で緊急でも、内閣は「事後に承認をもらう」という形で法律に代わる政令を作れません。
  具体例 :: 大災害で国会が開けないときでも、内閣は法律の委任なしに、国民に義務を課す政令を作れません。
  過去問 :: 平成26年問7肢3× 令和4年問6肢2×
  カード :: con-gov-cabinet-order-limits-001

- 概念 :: 決算は、会計検査院が先で、国会が後
  解説 :: 会計検査院が検査し、内閣が検査報告と一緒に国会へ提出します（憲法90条）。順番を逆にした肢と、歳入を検査の対象から外した肢が誤りです。
  具体例 :: 内閣は、まず会計検査院に決算を検査してもらいます。そのあと、内閣は検査報告を付けて決算を国会に出します。
  過去問 :: 令和5年問7肢5× 平成27年問7肢5× 平成24年問5肢3○
  カード :: con-finance-settlement-001

## 行政法

- 概念 :: 「計画は処分ではない」
  解説 :: 計画でも、特定の人の法的な地位が直接変わるなら処分です。土地区画整理事業計画の決定は、宅地の所有者が換地処分を受ける地位に立たされるので処分です。用途地域の指定は、法律ができたのと同じ一般的な制限なので処分ではありません。
  具体例 :: 市が決めた区画整理事業の計画は、区域内の地主が取消訴訟で争えます（最大判平20.9.10）。工業地域の指定は、地域内の地主が取消訴訟で争えません（最判昭57.4.22）。
  過去問 :: 令和4年問18肢3○ 平成28年問19肢4○ 令和4年問18肢2○ 令和7年問17肢5× 令和5年問19肢5× 平成24年問18肢3×
  カード :: gyo-litigation-zoning-001

- 概念 :: 「条例は処分ではない」
  解説 :: 条例は原則として処分ではありません。ただし、ほかの処分を待たずに、限られた特定の人の地位を直接奪う条例は処分です。
  具体例 :: 特定の保育所を廃止する条例は、入所中の児童と保護者が取消訴訟で争えます。水道料金を一律に改定する条例は、利用者が取消訴訟で争えません。
  過去問 :: 平成28年問19肢1○ 平成24年問18肢5○ 平成24年問18肢2×

  解説 :: 情報公開法の開示請求は何人でもできます。戸籍と住民票は、身分や居住関係を証明するものですが、何人でも理由を問わず見られるわけではありません。閲覧や交付の請求は制限されています。
  具体例 :: 外国に住む人でも、国の行政文書の開示を請求できます。他人の戸籍謄本は、正当な理由がなければ請求できません。

## 基礎法学

- 概念 :: 「新しい法律が、常に勝つ」
  解説 :: 同じ強さの法律の間では「後法は前法に優先する」のが原則ですが、一般法と特別法の間では特別法が優先します。古い特別法は、新しい一般法に原則として負けません。
  具体例 :: 民法（一般法）が改正されて新しくなっても、古くからある商法（特別法）の特則は、原則としてそのまま優先します。
