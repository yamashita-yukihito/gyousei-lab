# 総論 | 憲法とは何か [捨て候補]
> 優先度：憲法総論は20年で数問。人権と統治を先に仕上げる。
- 憲法の意味 :: 実質的意味の憲法は国家の統治の基本を定めた法（形式を問わない）。形式的意味の憲法は「憲法」という名の成文法典 {con-gen-substantive-meaning-001}
- 硬性憲法 :: 通常の法律より改正の手続が難しい憲法。日本国憲法は硬性憲法 {con-gen-rigid-constitution-001}
- 改正の手続 [抑えめ] :: 各議院の総議員の3分の2以上の賛成で国会が発議し、国民投票で過半数の賛成 @kenpo-d/finance-amendment
- 最高法規 :: 98条1項の「国務に関するその他の行為」に、国が私人と対等に結ぶ私法上の契約は含まれない（百里基地事件） {con-supreme-law-private-act-001}
- 憲法尊重擁護義務 :: 天皇・摂政・国務大臣・国会議員・裁判官その他の公務員が負う。国民は名宛人に入っていない {con-gen-respect-duty-001}

# 人権総論 | 誰に、どこまで保障されるか [重点]
> 判例の結論をそのまま問う。「合憲か違憲か」と「どの基準で判断したか」をセットで覚える。
> 優先度：享有主体・私人間効力・平等は毎年のように判例で問われる。
- 享有主体 [重要] @kenpo-d/rights-holders
  - 外国人・法人 :: 権利の性質上、日本国民だけを対象とするものを除き保障される（外国人はマクリーン事件、法人は八幡製鉄事件） {con-hr-holder-001}
  - 公務員の政治的行為 :: 猿払事件は一律の禁止を合憲とした。堀越事件は、政治的中立性を損なうおそれが実質的に認められる行為だけが処罰の対象とした {con-civil-servant-political-act-001}
- 私人間効力 [捨て候補] :: 人権規定は私人どうしには直接は及ばない。民法90条などの一般条項を通じて間接的に及ぶ（三菱樹脂事件） {con-gen-private-effect-001}
- 法の下の平等 [重要] @kenpo-d/equality
  - 判断の枠組み :: 事柄の性質に応じた合理的な根拠のない区別を禁止する（相対的平等） {con-eq-framework-001}
  - 違憲とされた例 :: 尊属殺重罰規定・非嫡出子の相続分・国籍法の準正要件・再婚禁止期間のうち100日を超える部分
  - 夫婦同氏制 [捨て候補] :: 合憲。「婚姻の際に氏の変更を強制されない自由」は憲法上の権利として保障されていない（最大判平27.12.16） {con-eq-family-name-001}
- プライバシー [抑えめ] :: 私生活をみだりに公開されない利益、個人に関する情報をみだりに第三者へ開示・公表されない自由（住基ネットは合憲）。自分の情報の開示などを求める積極的な請求権までは認めていない {con-priv-self-info-001} @kenpo-d/expression

# 精神的自由 | 心と表現と信仰と学問 [重点]
> 優先度：表現の自由と政教分離は頻出。判例の結論と基準をセットで。
- 信教の自由と政教分離 @kenpo-d/conscience-religion
  - 政教分離 :: 目的効果基準。津地鎮祭は合憲、愛媛玉串料は違憲。空知太神社・孔子廟は総合的に判断して違憲 {con-rel-purpose-effect-001}
  - 宗教法人の解散命令 [捨て候補] :: 世俗的な目的によるもので、信者の宗教上の行為への支障は間接的・事実上のものなので合憲（オウム真理教解散命令事件） {con-rel-separation-001}
- 表現の自由 [重要] @kenpo-d/expression
  - 検閲 :: 行政権が、発表前に、網羅的一般的に審査して不適当なものの発表を禁止すること。絶対に禁止。税関検査・教科書検定は検閲に当たらない {con-exp-censorship-prior-restraint-001}
  - 事前抑制 :: 原則として許されない。裁判所による出版の事前差止めは、厳格な要件のもとで例外的に許される（北方ジャーナル事件） {con-exp-censorship-prior-restraint-001}
  - 明確性 [捨て候補] :: 規制の文言が不明確なら違憲になりうる。限定して解釈できれば合憲（徳島市公安条例事件・広島市暴走族追放条例事件） {con-exp-vagueness-001}
  - 取材の自由 :: 報道の自由は21条で保障され、取材の自由は21条の精神に照らし十分尊重に値する。公正な刑事裁判のためなら、比較衡量で制約されうる（博多駅事件） {con-exp-news-source-001}
- 学問の自由 :: 大学の自治は教員の人事と施設・学生の管理に及ぶ。学生の集会が実社会の政治的社会的活動なら大学の自治は及ばない（東大ポポロ事件） {con-academic-freedom-001} @kenpo-d/academic-economic

# 経済的自由・社会権・参政権 | 規制の目的と、国会の裁量 [抑えめ]
> 優先度：判例の結論を1周。選挙権だけは頻出。
- 職業選択の自由 [重要] @kenpo-d/academic-economic
  - 規制目的二分論 :: 消極目的（国民の生命・健康を守る）は厳しめに審査し、薬事法距離制限は違憲。積極目的（経済政策）は緩やかに審査し、小売市場距離制限は合憲 {con-econ-occupation-001}
- 財産権 [捨て候補] :: 危険なため池の堤とうの使用は、そもそも財産権の保障の外。条例で禁止でき、補償も要らない（奈良県ため池条例事件） {con-prop-ordinance-001}
- 適正手続 :: 所有者である第三者に告知・弁解・防御の機会を与えずに没収するのは違憲（第三者所有物没収事件） {con-due-process-standing-001} @kenpo-d/social-procedure-vote
- 生存権 :: 具体的にどう実現するかは立法府の広い裁量に委ねられる。著しく合理性を欠き明らかに裁量の逸脱・濫用といえる場合だけ違憲（堀木訴訟） {con-soc-livelihood-001} @kenpo-d/social-procedure-vote
- 教育を受ける権利 :: 教育内容は、国も教師も一定の範囲で決められる（旭川学テ事件）。義務教育の無償は授業料を取らないこと {con-edu-content-001}
- 選挙権 [重点] [重要] :: 制限は、やむを得ない事由がなければ許されない（在外日本人選挙権事件） {con-vote-right-001} @kenpo-d/social-procedure-vote

# 統治 | 国会・内閣・裁判所・財政 [重点]
> 「衆議院の優越」「内閣の総辞職」「司法権の限界」が三大論点。数字（3分の2・10日・30日）を正確に。
> 優先度：毎年2問前後。数字（3分の2・10日）と手続は覚えればそのまま点になる。
- 国会 [重要] @kenpo-d/diet
  - 議員の特権 :: 不逮捕特権（会期中は、院の許諾がなければ逮捕されない）と免責特権（院内での発言・表決について院外で責任を問われない） {con-diet-member-privilege-001}
  - 国政調査権 :: 国会の権能を助ける補助的な権能。裁判中の事件の判決の当否を調べることは、司法権の独立を害するので許されない {con-diet-investigation-001}
  - 議院の自律権 :: 議員の資格争訟と懲罰は議院が決め、裁判所は審査できない（地方議会の議員への懲罰とは違う） {con-diet-autonomy-discipline-001}
  - 衆議院の優越 :: 予算・条約・内閣総理大臣の指名は衆議院の議決が優先。法律案は衆議院で出席議員の3分の2以上で再可決すれば成立
- 内閣 [重要] @kenpo-d/cabinet
  - 総辞職 :: 衆議院で不信任が可決されたら、10日以内に衆議院が解散されない限り総辞職。首相が欠けたとき、総選挙の後に初めて国会が召集されたときも総辞職 {con-cabinet-power-001}
  - 内閣総理大臣 :: 国会議員の中から国会が指名する。国務大臣を任命し、任意に罷免できる。国務大臣の過半数は国会議員 {con-pm-status-001}
  - 衆議院の解散 :: 69条の場合に限られない（7条による解散）。解散が有効かどうかは統治行為で、裁判所は審査しない（苫米地事件） {con-dissolution-001}
  - 政令 :: 憲法・法律を実施するための執行命令と、法律の委任による委任命令だけ。罰則は法律の委任があるときだけ置ける {con-gov-cabinet-order-limits-001}
- 司法 [重要] @kenpo-d/judiciary
  - 司法権の限界（団体の内部紛争） :: 大学の単位認定は原則として審査しない。政党の除名も原則として審査しない。地方議会の議員の出席停止は審査の対象（令和2年に判例変更） {con-court-internal-dispute-001}
  - 裁判の公開 :: 対審と判決は公開。証人の遮へいやビデオリンクを使っても公開に反しない。非訟事件は82条の「裁判」に当たらない {con-court-open-001}
  - 裁判官の懲戒 :: 分限裁判で行い、戒告か1万円以下の過料だけ。罷免は弾劾裁判か、心身の故障で職務を執れないとき {con-court-judge-discipline-001}
- 財政 @kenpo-d/finance-amendment
  - 決算 :: 会計検査院が毎年検査し、内閣が検査報告とともに国会へ提出する {con-finance-settlement-001}
  - 租税法律主義 [抑えめ] :: 新たに租税を課したり変更したりするには、法律か法律の定める条件による
