# 行政組織法 | 誰が行政をするのか [抑えめ]
> 主体（国・自治体）→ 機関（行政庁など）→ 権限の動かし方（委任・代理・専決）の順に見る。
> 優先度：組織法は毎年1問出るかどうか。権限の委任・代理と行政機関の種類だけ押さえ、国の組織図は追わない。
- 行政主体 [捨て候補] :: 権利義務が帰属する法人（国・地方公共団体・独立行政法人など）
- 行政機関の種類 [重要] {gyo-act-administrative-organ-001}
  - 行政庁 :: 意思を決定し外部へ表示する（大臣・知事・市町村長）
  - 補助機関 :: 行政庁を内部で補助する（副大臣・事務次官・局長など）
  - 諮問機関 :: 意見を述べる。答申に拘束力なし（各種の審議会）
  - 参与機関 :: 議決が行政庁を拘束する（電波監理審議会など）
  - 監査機関 :: 事務や会計を検査する（会計検査院・監査委員）
  - 執行機関 :: 実力を行使する（警察官・消防職員・徴税職員）
    - [ひっかけ] 地方自治法の「執行機関」は長・委員会のこと。言葉は同じでも中身が違う
  - 独任制と合議制 :: 大臣は1人で決める（独任制）、委員会は合議で決める（合議制）
- 上下関係（指揮監督権） :: 監視権・許認可権・訓令権・取消停止権・権限争議の裁定権
  - 訓令・通達 [重点] :: 下級機関を縛るだけで、国民も裁判所も縛らない {gyo-legislation-circular-nature-001}
  - 各省大臣の権限 [捨て候補] :: 閣議を求める・省令を出す・所管の機関へ訓令通達 {gyo-act-minister-authority-001}
- 権限行使の3つの型 [重要]
  - 権限の委任 :: 権限が受任者へ移る。法律の根拠が必要。受任者の名で行う
  - 授権代理 :: 権限は移らない。法律の根拠は不要。代理であることを示して行う
  - 法定代理 :: 法律が定める事実（欠けた・事故）で当然に代理が生じる
  - 専決・代決 :: 内部の事務処理。外部へは本来の行政庁の名で表示する
- 国の行政組織 [捨て候補]
  - 内閣 :: 合議制の最高行政機関。下に内閣府・省
  - 省・委員会・庁 :: 委員会と庁は省の外局（国家行政組織法3条）
  - 地方支分部局 :: 法務局・国税局など、国の出先
- 地方の行政組織 [捨て候補] :: → 地方自治法の枝へ

# 行政作用法 | 行政は何をするのか [重点]
> 中心は行政行為（処分）。その前後に、ルール作り（行政立法）、お願い（行政指導）、強制（義務履行確保）が並ぶ。
> 優先度：行政行為・裁量・行政立法・義務履行確保は毎年のように出る中心分野。
- 基本原理 [抑えめ]
  - 法律による行政の原理 :: 法律の優位・法律の留保・法律の法規創造力
  - 行政上の法律関係にも民法が及ぶか :: 一律ではない。行政法規が民法の特則になる場面もある（建築基準法65条と民法234条） {gyo-act-public-private-law-001}
  - 信義則 :: 租税関係では、公的見解の表示と信頼など特別の事情があるときだけ {gyo-act-good-faith-tax-001}
  - 信頼保護 :: 施策を変えるのは自由。ただし密接な交渉で生じた損害を補償しないと違法（宜野座村） {gyo-act-policy-change-trust-001}
- 行政行為（処分） [重要] @gyosei-d/act-effect
  - 効力 [重要]
    - 公定力 :: 違法でも、取り消されるまで有効として扱われる（取消訴訟の排他的管轄）
    - 不可争力 :: 出訴期間・不服申立期間を過ぎると、私人から争えない
    - 執行力 :: 行政が自力で実現できる。ただし法律の根拠が必要
    - 不可変更力 :: 裁決など争いを裁く行為は、行政庁自身も変えられない
    - 実質的確定力 :: 争訟を裁断した効果。一部の裁決などに認められる
    - 国家賠償との関係 :: 取消判決を先にもらわなくても国家賠償は請求できる {gyo-state-comp-no-prior-cancel-001}
  - 分類 [抑えめ]
    - 命令的行為 :: 下命・禁止／許可（自由の回復）／免除（義務の解除）
    - 形成的行為 :: 特許（権利の設定）／認可（私人の行為を補充して完成）／代理
    - 準法律行為的行政行為 :: 確認・公証・通知・受理
  - 瑕疵 [重要]
    - 無効になる場合 :: 重大かつ明白な瑕疵（重大明白説） {gyo-act-defect-001}
    - 違法性の承継 :: 原則として認めない。安全認定→建築確認のように例外あり
    - 瑕疵の治癒 :: 後から要件を満たせば有効と扱う（理由提示の不備は治癒されない）
    - 違法行為の転換 :: 別の行為として見れば適法なら、その行為として維持する
    - 理由の差替え :: 取消訴訟で処分理由を差し替える。一定の範囲で認められる
  - 効力を失わせる
    - 職権取消し :: 成立時の瑕疵を理由に、さかのぼって失わせる。処分庁・上級庁ができる
    - 撤回 [抑えめ] :: 後の事情を理由に、将来に向かって失わせる。処分庁だけ。法律の根拠は不要 {gyo-act-withdrawal-001}
    - 授益的処分の取消し・撤回 :: 相手の利益を奪うので制限される（公益上の必要と比べる）
  - 附款 [抑えめ] {gyo-act-incidental-terms-001}
    - 条件 :: 発生が不確実な事実にかからせる
    - 期限 :: 発生が確実な事実にかからせる（到来時期が不確定でも期限）
    - 負担 :: 義務を付け加える。守らなくても処分は当然には失効しない
    - 撤回権の留保 :: 撤回できると書いておく。書いても自由に撤回できるわけではない
- 行政裁量 [重要] @gyosei-d/discretion-legislation
  - 羈束行為と裁量行為 :: 法律が一つに決めているか、行政庁に判断の幅があるか
  - 裁量が問題になる段階 :: 事実認定・要件の認定・手続・効果（するか、どれにするか）・時
  - 司法審査の限界 [重要] {gyo-discretion-judicial-review-001}
    - 裁判所が取り消せるのは :: 裁量権の逸脱・濫用があったときだけ（行訴法30条）
    - 典型 :: 事実誤認・目的違反・動機違反・平等原則違反・比例原則違反
    - 判断過程審査 :: 考慮すべきことを考慮せず、考慮すべきでないことを考慮した
    - 学校の処分 [抑えめ] :: 結果が社会観念上著しく妥当を欠くかで見る（裁判所が代わりに判断しない） {gyo-act-school-discipline-review-001}
  - 裁量基準に反した処分 :: 基準自体は国民を縛らないが、平等原則などを通じて違法になりうる {gyo-act-discretion-standard-001}
- 行政立法 @gyosei-d/discretion-legislation
  - 法規命令（国民を縛る）
    - 委任命令 :: 法律の委任が必要。委任の範囲を超えると無効 {gyo-legislation-delegation-limit-001}
    - 執行命令 :: 法律を実施する細目。個別の委任は不要
    - 独立命令 :: 法律の根拠なしに国民を縛る命令は作れない（憲法41条）
    - 出す主体 :: 政令＝内閣、内閣府令＝内閣総理大臣、省令＝各省大臣、外局規則＝庁の長官など
  - 行政規則（国民を縛らない） :: 通達・解釈基準・裁量基準・行政指導指針・給付基準。法律の根拠不要
    - 通達の処分性 :: 原則なし（墓地埋葬法の通達） {gyo-legislation-circular-nature-001}
- 行政計画 [捨て候補] :: 法律の根拠は必ずしも要らない。処分性は計画ごとに判断 → 行政事件訴訟法の処分性へ
- 行政契約 [捨て候補] :: 公害防止協定も契約として拘束力あり。随意契約が違法でも当然には無効にならない {gyo-act-administrative-contract-001}
- 行政指導 [抑えめ] :: 規制的・助成的・調整的。相手の任意の協力が前提 → 行政手続法の枝へ
- 行政調査 [捨て候補]
  - 任意調査 :: 相手の同意で行う（職務質問・所持品検査など）
  - 強制調査 :: 法律の根拠が必要。拒むと罰則で間接的に強制するもの（税務調査）も含む
- 義務を守らせる手段 [重要] @gyosei-d/enforcement
  - 行政代執行 [抑えめ] :: 一般法は行政代執行法。代替的作為義務だけが対象 {gyo-enforcement-ordinance-substitution-001}
    - 条例で課した義務 :: 法律の委任に基づく条例なら代執行できる（自主条例は見解が分かれる）
  - 強制徴収 :: 金銭債務を国税滞納処分の例で取り立てる（個別法の根拠が要る）
  - 執行罰 [抑えめ] :: 過料を予告して促す。刑罰ではないので繰り返し科せる。今は砂防法だけ {gyo-enforcement-periodic-penalty-001}
  - 直接強制 :: 義務者の身体・財産に直接力を加える。個別法がなければできない
  - 即時強制 :: 義務を課す暇がないときに、いきなり実力を使う（義務を前提にしない点が上と違う） {gyo-enforcement-immediate-compulsion-001}
  - 行政罰
    - 行政刑罰 :: 刑法上の刑罰を科す。刑事訴訟法で裁く
    - 秩序罰（過料） :: 法律違反は非訟事件手続法で裁判所、条例・規則違反は長が科す {gyo-enforcement-order-fine-001}
- 情報公開・個人情報保護 [抑えめ] :: 試験では基礎知識の科目で出る @chishiki-d/records-registers @chishiki-d/personal-information

# 行政手続法 | 処分をする前の決まり [重点]
> 申請に対する処分と不利益処分を、「義務か努力義務か」で並べて覚える。地方公共団体への適用除外は最頻出。
> 優先度：毎年3問。義務か努力義務か・聴聞か弁明かは覚えればそのまま点になる、いちばん効率のよい範囲。
- 総則
  - 目的 [捨て候補] :: 行政運営の公正の確保と透明性の向上 → 国民の権利利益の保護
  - 行政手続と憲法31条 [抑えめ] :: 行政手続にも及びうるが、告知・聴聞の要否は総合較量（成田新法事件） {gyo-aps-due-process-narita-001}
  - 地方公共団体への適用除外 [重要] {gyo-aps-scope-001}
    - 条例・規則に基づく処分・届出 :: 適用除外
    - 法律に基づく処分・届出 :: 適用される
    - 行政指導・命令等制定 :: 根拠を問わず適用除外
- 申請に対する処分 [重要] @gyosei-d/application
  - 審査基準 :: 定める義務・公にしておく義務 {gyo-aps-review-criteria-001}
  - 標準処理期間 :: 定めるのは努力義務、定めたら公にする義務 {gyo-aps-standard-period-001}
  - 審査・応答 :: 到達したら遅滞なく審査を始める義務。形式不備は補正を求めるか拒否 {gyo-aps-formal-defect-001}
  - 理由の提示 :: 拒否するときは同時に示す義務 {gyo-aps-refusal-reason-001}
    - 程度 [抑えめ] :: 根拠条文を示すだけでは足りない。どの事実がどの基準に当たるか {gyo-aps-reason-degree-001}
  - 情報の提供 :: 審査の進行状況と見通し。努力義務 {gyo-aps-progress-info-001}
  - 公聴会の開催 :: 申請者以外の利害を考慮する処分で。努力義務 {gyo-aps-third-party-hearing-001}
  - 拒否処分と聴聞 [ひっかけ] :: 申請の拒否は不利益処分ではないので、聴聞・弁明は要らない {gyo-aps-refusal-hearing-001}
  - 複数の行政庁が関与する処分 [捨て候補] :: 審査の促進に努める（努力義務）
- 不利益処分 [重要] @gyosei-d/adverse-disposition
  - 処分基準 :: 定めるのも公にするのも努力義務 {gyo-aps-disposition-standard-001}
  - 理由の提示 [抑えめ] :: 処分と同時に。差し迫った必要があれば後で {gyo-aps-adverse-reason-timing-001}
  - 意見陳述の振り分け [重要] {gyo-aps-hearing-classification-001}
    - 聴聞 :: 許認可の取消し・資格や地位の剝奪・役員の解任命令など重いもの
    - 弁明の機会 :: それ以外。原則は書面（行政庁が認めれば口頭）
    - 例外 [捨て候補] :: 緊急・金銭の納付命令など、どちらも要らない場合 {gyo-aps-hearing-exception-001}
  - 聴聞の手続
    - 主宰者 [抑えめ] :: 行政庁が指名する職員など。当事者・その親族などは主宰できない {gyo-aps-hearing-presider-001}
    - 代理人 [捨て候補] :: 聴聞・弁明とも選任できる {gyo-aps-hearing-001}
    - 資料の閲覧 :: 聴聞では請求できる。弁明の機会には閲覧の規定がない {gyo-aps-hearing-file-access-001} {gyo-aps-hearing-002}
    - 欠席したとき [抑えめ] :: 正当な理由なく出頭しなければ、聴聞を終結できる {gyo-aps-hearing-absence-001}
    - 調書・報告書 [抑えめ] :: 主宰者が作る。行政庁は報告書の意見を十分に参酌する {gyo-aps-hearing-report-001}
- 届出 :: 形式上の要件を満たして提出先に到達したときに、義務を果たしたことになる {gyo-aps-notification-arrival-001} @gyosei-d/guidance-notification
- 行政指導 [重要] @gyosei-d/guidance-notification
  - 定義 :: 特定の者に、任務・所掌事務の範囲内で、処分に当たらないお願い {gyo-aps-guidance-definition-001}
  - 一般原則 :: 任意の協力によってのみ実現。従わないことを理由に不利益な取扱いをしない
  - 申請に関連する行政指導 [抑えめ] :: 従わない意思を明らかにしたら続けて権利行使を妨げない（品川マンション） {gyo-aps-guidance-application-001}
  - 方式 :: 趣旨・内容・責任者を明確に示す。求められたら原則書面を交付 {gyo-aps-guidance-writing-001}
  - 行政指導指針 :: 複数の者に行うときは定めて公表する（原則） {gyo-aps-guidance-guideline-001}
  - 中止等の求め :: 法律に根拠がある行政指導の相手方が、違法だと思えば求められる（36条の2） {gyo-aps-guidance-stop-001}
- 処分等の求め [抑えめ] :: 法令違反を見つけた何人も、処分・行政指導を求められる（36条の3）
- 命令等を定める手続（意見公募） [重要]
  - 対象の命令等 :: 法律に基づく命令・規則、審査基準、処分基準、行政指導指針 {gyo-aps-public-comment-scope-001}
  - 手続 :: 案と関連資料を公示し、原則30日以上意見を募る {gyo-aps-public-comment-draft-001}
  - 結果の公示 [抑えめ] :: 意見がなくても、定めなかったときも公示する {gyo-aps-public-comment-result-001}

# 行政不服審査法 | 行政に見直しを求める [重点]
> 2014年に全面改正。「異議申立て」はなくなり、審査請求に一本化された。審理員と行政不服審査会の二段構えで中立性を確保する。
> 優先度：毎年3問。期間・審査庁・審理員・裁決の種類は数字と言葉の暗記で取れる。
- 目的 [捨て候補] :: 国民の権利利益の救済と、行政の適正な運営の確保
- 申立ての種類 [重要]
  - 審査請求 :: 原則はこれ一本
  - 再調査の請求 [抑えめ] :: 個別法に定めがあるときだけ。処分庁が見直す。審査請求との選択 {gyo-aia-reinvestigation-choice-001}
    - 再調査の請求中の執行停止 [捨て候補] :: できる {gyo-aia-reinvestigation-stay-001}
    - 不作為には使えない [捨て候補] {gyo-aia-inaction-no-reinvestigation-001}
  - 再審査請求 [抑えめ] :: 個別法に定めがあるときだけ。裁決にさらに不服があるとき
- 審査請求の要件 [重要] @gyosei-d/appeal-entry
  - 対象 :: 処分（事実上の行為を含む）と不作為
    - 不作為 [抑えめ] :: 法令に基づく申請に、相当の期間を過ぎても応答しない {gyo-aia-inaction-scope-001}
    - 不作為の審査請求人 [抑えめ] :: 法令に基づき申請をした者だけ {gyo-aia-inaction-applicant-001}
  - 審査請求人 [抑えめ] :: 法律上の利益がある者。法人でない社団・財団も代表者の定めがあればできる {gyo-aia-noncorporate-group-001}
    - 代理人・総代 [重点] :: 代理人は取下げに特別の委任が要る。総代は取下げできない {gyo-aia-agent-withdrawal-001}
  - 審査庁 :: 原則は処分庁の最上級行政庁。上級行政庁がなければ処分庁
  - 期間 :: 処分を知った日の翌日から3か月・処分の日の翌日から1年 {gyo-aia-review-period-001}
    - 再調査の請求のあと :: 決定を知った日の翌日から1か月
    - 不作為 :: 期間の制限なし
  - 方式 [抑えめ] :: 書面が原則。他の法律・条例に定めがあれば口頭も
- 審理 [重要] @gyosei-d/appeal-review
  - 審理員 [抑えめ] :: 審査庁の職員から指名。処分に関与した者はなれない {gyo-aia-examiner-affiliation-001}
    - 名簿 :: 作るのは努力義務、作ったら公にする義務 {gyo-aia-examiner-roster-001}
    - 不作為の審査請求も審理員が審理する {gyo-aia-inaction-examiner-001}
  - 流れ :: 弁明書 → 反論書・意見書 → 審理員意見書 → 審査会へ諮問 → 裁決
  - 口頭意見陳述 :: 申立てがあれば機会を与える。審理員の許可を得て処分庁に質問できる {gyo-aia-oral-opinion-001}
  - 書面審理が原則 :: 審理員は職権でも証拠を集められる（物件の提出要求・参考人の陳述・検証など）
  - 物件の閲覧・写しの交付 :: 審査請求人・参加人が求められる
  - 行政不服審査会への諮問 :: 原則必要。地方では条例で置く機関 {gyo-aia-review-board-consultation-001}
- 執行停止 [重要]
  - 原則 :: 執行不停止
  - 職権でもできる審査庁 [抑えめ] :: 処分庁・処分庁の上級行政庁。それ以外の審査庁は申立てがあるときだけ {gyo-aia-stay-authority-001}
  - しなければならない場合 :: 重大な損害を避けるため緊急の必要（公共の福祉への重大な影響などの例外あり）
  - 審理員の意見書 [抑えめ] :: 審理員は執行停止をすべき旨の意見書を出せる {gyo-aia-examiner-stay-opinion-001}
- 裁決 [重要] {gyo-aia-decision-kinds-001}
  - 却下 :: 要件を満たさず不適法
  - 棄却 :: 理由がない。事情裁決もここ（違法・不当を宣言）
  - 認容 :: 取消し・撤廃・変更。変更できるのは上級行政庁か処分庁の審査庁だけ
  - 不作為の認容 :: 違法・不当を宣言し、処分をすべき旨を命じる／自らする {gyo-aia-order-disposition-001}
  - 不利益変更の禁止 :: 審査請求人に不利に変えられない {gyo-aia-no-adverse-change-001}
  - みなし棄却 :: 行政不服審査法にはない
- 教示 [重要]
  - 方法 [抑えめ] :: 書面でする処分は書面で教示。利害関係人から求められれば教示 {gyo-aia-guidance-request-001}
  - 教示しなかったとき :: 処分庁へ不服申立書を出せる {gyo-aia-guidance-omission-001}
  - 誤った教示 :: 教示どおりにした者は救われる（審査庁を誤った場合など）

# 行政事件訴訟法 | 裁判所に取り消してもらう [重点]
> 「訴訟要件（入口）→ 審理 → 終了（判決）」の順。入口の処分性・原告適格・訴えの利益は理屈より判例の暗記。
> 優先度：毎年3問と記述の常連。訴訟要件・執行停止・判決の効力に時間を使う。
- 法律上の争訟 [ひっかけ] :: 行政権の主体として義務の履行を求める訴えは当たらない（宝塚市パチンコ条例）。財産権の主体としてなら当たる {gyo-litigation-legal-dispute-001}
- 訴えの類型 [重要]
  - 抗告訴訟
    - 取消訴訟 :: 処分・裁決の取消し。中心となる訴え
    - 無効等確認訴訟 :: 期間の制限なし。現在の法律関係の訴えで足りるなら使えない（補充性） {gyo-litigation-invalidity-subsidiarity-001}
      - 執行停止 [抑えめ] :: 準用される {gyo-litigation-invalidity-stay-001}
    - 不作為の違法確認訴訟 [抑えめ] :: 申請をした者だけ。期間制限なし。処分されれば訴えの利益が消える {gyo-litigation-nonaction-standing-001} {gyo-litigation-nonaction-period-001}
    - 義務付け訴訟 :: 非申請型は重大な損害と補充性。申請型は取消訴訟などを併合して出す {gyo-written-h30-duty-inaction-001}
    - 差止め訴訟 :: 処分がされようとしているとき。重大な損害と補充性
    - 義務付け・差止めの出訴期間 [抑えめ] :: ない {gyo-litigation-no-filing-period-001}
  - 当事者訴訟
    - 形式的当事者訴訟 [抑えめ] :: 処分を争うが、当事者どうしで争う（収用の補償金の増減） @gyosei-d/suit-other
    - 実質的当事者訴訟 :: 公法上の法律関係の確認など（在外日本人選挙権） {gyo-litigation-substantive-party-action-001}
  - 客観訴訟（法律に定めがあるときだけ） [抑えめ] {gyo-litigation-objective-suits-001}
    - 民衆訴訟 :: 自分の利益と関係なく、選挙人・住民として（住民訴訟・選挙訴訟）
    - 機関訴訟 :: 行政機関どうしの争い
  - 争点訴訟 :: 処分の無効を前提に民事訴訟で争う（45条） {gyo-litigation-issue-suit-001}
- 取消訴訟の訴訟要件 [重要] @gyosei-d/suit-gate
  - 処分性 [重要] [処分性の暗記ドリル](../tools/quiz3.html)
    - 判断基準 :: 公権力性・直接具体的に権利義務を形成・確定・外部への効果
    - あり :: 保育所廃止条例、土地区画整理事業計画、病院開設中止の勧告 {gyo-litigation-nursery-ordinance-001} {gyo-litigation-land-readjustment-plan-001} {gyo-litigation-medical-recommendation-001}
    - なし [抑えめ] :: 用途地域の指定（一般的抽象的）、通達 {gyo-litigation-zoning-001}
  - 原告適格 [重要] {gyo-litigation-standing-001}
    - 基準 :: 「法律上の利益を有する者」＝法律上保護された利益説（9条1項）
    - 第三者の判定（9条2項） :: 法令の文言だけでなく、趣旨・目的、利益の内容・性質を考慮
  - 訴えの利益（狭義） [重要]
    - 消える例 :: 事後の事情の変化、回復の可能性がない（建築工事の完了など）
    - 残る例 :: 効果がなくなっても回復すべき法律上の利益があれば残る（9条1項かっこ書） {gyo-litigation-interest-after-effect-001}
    - 非公開決定 [抑えめ] :: 文書が書証として出されても、取消しの利益は消えない {gyo-litigation-document-evidence-interest-001}
  - 被告適格 :: 処分をした行政庁が所属する国・公共団体（行政庁ではない） {gyo-litigation-defendant-001} @gyosei-d/suit-procedure
  - 裁判管轄 [捨て候補] :: 被告の所在地または処分した行政庁の所在地の地方裁判所など
  - 不服申立前置 :: 原則不要（自由選択主義）。個別法に定めがあるときだけ前置 {gyo-litigation-review-prerequisite-001}
  - 出訴期間 :: 知った日から6か月・処分の日から1年（正当な理由があれば例外） {gyo-litigation-filing-period-001}
- 審理 [重要]
  - 審理の対象
    - 主張の制限 [抑えめ] :: 自分の法律上の利益に関係のない違法は主張できない（10条1項） {gyo-litigation-claim-restriction-001}
    - 原処分主義 [抑えめ] :: 裁決の取消訴訟では、原処分の違法を主張できない（10条2項） {gyo-written-r7-decision-defect-001}
    - 違法判断の基準時 [抑えめ] :: 原則として処分時
    - 専門技術的判断 [抑えめ] :: 審査基準と判断過程に不合理な点があるかを見る（伊方原発） {gyo-litigation-ikata-review-001}
  - 訴訟主体の役割 [抑えめ]
    - 処分権主義・弁論主義 :: 民事訴訟と同じが基本
    - 職権証拠調べ :: できる（24条）。ただし職権探知まではしない
    - 釈明処分の特則 :: 処分の理由を明らかにする資料の提出を求められる
  - 審理過程の諸問題 [抑えめ]
    - 関連請求の移送・併合 :: 関連する請求をまとめて審理できる
    - 訴えの変更 :: 国・公共団体への損害賠償請求などに変えられる
    - 訴訟参加 [重点] :: 第三者（22条）・他の行政庁（23条） {gyo-litigation-intervention-001}
  - 執行停止 [重要] @gyosei-d/suit-procedure
    - 原則 :: 執行不停止
    - 要件 :: 本案が係属し、重大な損害を避けるため緊急の必要 {gyo-litigation-stay-001}
    - 消極要件 :: 公共の福祉に重大な影響のおそれ・本案に理由がないとみえる
    - 内閣総理大臣の異議 [抑えめ] :: 執行停止の前後を問わず述べられる。裁判所は従う {gyo-litigation-pm-objection-001}
    - 民事保全法の仮処分 [抑えめ] :: できない（44条） {gyo-litigation-no-provisional-disposition-001}
  - 仮の義務付け・仮の差止め
    - 要件 :: 償うことのできない損害を避けるため緊急の必要＋本案に理由があるとみえる
    - 本案の係属 :: 義務付け・差止めの訴えを出していることが前提 {gyo-litigation-provisional-mandate-main-action-001}
    - 申立てが必要 [捨て候補] :: 職権ではできない {gyo-litigation-provisional-injunction-application-001}
    - 公共の福祉に重大な影響 [捨て候補] :: あればできない {gyo-litigation-provisional-injunction-public-001}
  - 教示（46条） [抑えめ] :: 書面でする処分には、被告・出訴期間・前置の有無を教示する
- 訴訟の終了 [重要] @gyosei-d/suit-procedure
  - 判決によらない終了 [捨て候補] :: 訴えの取下げ・原告の死亡（一身専属なら終了）。和解は争いあり
  - 却下と棄却 [ひっかけ] :: 訴訟要件を欠く→却下、要件はあるが理由がない→棄却 {gyo-litigation-dismissal-rejection-001}
  - 事情判決 :: 違法だが取り消すと公益に著しい障害。主文で違法を宣言 {gyo-litigation-special-circumstances-001}
  - 認容判決の効力 {gyo-litigation-cancel-judgment-effects-001}
    - 形成力 :: 処分は初めからなかったことになる
    - 第三者効 :: 取消判決は第三者にも効く（32条）
    - 既判力 :: 同じ争いを蒸し返せない
    - 拘束力 :: 処分庁と関係行政庁を縛る（33条）。同じ理由で同じ処分をできない
  - 棄却判決の効力 :: 既判力だけ

# 国家賠償・損失補償 | 損害を金銭で埋める [重点]
> 違法な行為による損害は国家賠償（国賠法1条・2条）、適法な行為による損失は損失補償（憲法29条3項）。
> 優先度：毎年2問。1条と2条の判例の結論を覚えれば取れる。
- 国賠法1条（公務員の行為） [重要] @gyosei-d/state-comp-official
  - 公権力の行使 :: 純粋な私経済作用と2条以外の全部。行政指導・学校の教育活動も含む {gyo-state-comp-public-power-scope-001}
  - 職務を行うについて [抑えめ] :: 客観的な外形で判断（非番の警察官の強盗殺人） {gyo-state-comp-objective-appearance-001}
  - 規制権限の不行使 [抑えめ] :: 著しく合理性を欠くときは違法（筑豊じん肺・泉南アスベスト） {gyo-state-comp-regulatory-inaction-001}
  - 公務員個人の責任 [抑えめ] :: 被害者に直接は負わない。国は故意・重過失のときだけ求償 {gyo-state-comp-public-official-liability-001}
  - 取消訴訟との関係 :: 先に取消判決は要らない {gyo-state-comp-no-prior-cancel-001}
- 国賠法2条（営造物） [重要] @gyosei-d/state-comp-facility
  - 瑕疵 :: 通常有すべき安全性を欠く。過失は要らない（無過失責任） {gyo-state-comp-public-facility-001}
  - 予算がない [抑えめ] :: 免責されない（高知落石事件） {gyo-state-comp-facility-budget-001}
  - 供用関連瑕疵 [抑えめ] :: 騒音など周辺住民への被害も含む（大阪空港・国道43号） {gyo-state-comp-facility-use-related-001}
- 費用負担者（3条） [抑えめ] :: 管理者と費用を負担する者の両方が責任を負う {gyo-state-comp-cost-bearer-001}
- 民法・失火責任法（4条） [抑えめ] :: 消防職員の消火ミスにも失火責任法が適用される（重過失が必要） {gyo-state-comp-fire-liability-001}
- 相互保証（6条） [抑えめ] :: 外国人は、その国が日本人に賠償する場合だけ
- 損失補償 [抑えめ]
  - 根拠 :: 個別法に規定がなくても、憲法29条3項を根拠に直接請求できる
  - 正当な補償 [重点] :: 土地収用は完全な補償。建築制限を受けたことは考えない価格で {gyo-loss-compensation-project-restriction-value-001}

# 地方自治法 | 自治体の仕組みと住民の権利 [抑えめ]
> 数字（1/50・1/3・2/3・3/4）と、請求先（長・監査委員・選挙管理委員会）をセットで。
> 優先度：毎年3問出るが範囲が広く、1問あたりの費用が高い。住民の直接請求・監査請求と条例・事務の区分に絞る。

  - 普通地方公共団体 :: 都道府県・市町村
  - 特別地方公共団体 :: 特別区・地方公共団体の組合・財産区
  - 特別区と指定都市の区 [ひっかけ] :: 特別区は法人（特別地方公共団体）、指定都市の区は法人でない {gyo-local-special-ward-001}
- 機関 @gyosei-d/local-structure
  - 議会 :: 条例・予算などを議決
  - 長 :: 執行機関の中心
  - 委員会・委員 :: 教育委員会・選挙管理委員会・監査委員など（執行機関の多元主義）
  - 長と議会の関係 [捨て候補] {gyo-local-reconsideration-001}
    - 不信任議決 :: 2/3以上出席・3/4以上の同意。長は10日以内に解散できる
    - 解散後の再不信任 :: 2/3以上出席・過半数で、長は失職
    - 再議 :: 条例・予算に異議があれば長が求められる。違法な議決は求めなければならない
    - 専決処分 :: 議会が成立しない・議決すべきことを議決しないときなど
- 事務 [重点] @gyosei-d/local-structure
  - 自治事務 :: 法定受託事務以外のもの（控除式の定義） {gyo-local-autonomous-affairs-001}
  - 法定受託事務 :: 国などが本来果たすべき役割に関わる事務。これにも条例を作れる {gyo-local-statutory-entrusted-ordinance-001}
  - 関与 [重要]
    - 関与の法定主義 [抑えめ] :: 法律・政令の根拠が必要 {gyo-local-involvement-law-001}
    - 種類 [抑えめ] :: 自治事務は是正の要求、法定受託事務は是正の指示・代執行まで {gyo-local-involvement-types-001}
- 条例制定権の限界 [重点] [重要] @gyosei-d/local-structure
  - 範囲 :: 法令に違反しない限り。義務を課し権利を制限するには条例が要る
  - 法令との関係 :: 趣旨・目的・内容・効果を比べて矛盾抵触がないか（徳島市公安条例）
  - 罰則 :: 2年以下の拘禁刑・100万円以下の罰金・拘留・科料・没収・5万円以下の過料 {gyo-local-ordinance-penalty-001}
  - 規則の罰則 [ひっかけ] :: 長の規則は5万円以下の過料だけ。刑罰は置けない
- 住民の地位 [重点] [重要] @gyosei-d/local-residents
  - 直接請求
    - 条例の制定改廃 :: 1/50の署名で長へ。地方税・使用料・手数料の徴収は対象外 {gyo-local-ordinance-direct-request-001}
    - 事務の監査 :: 1/50の署名で監査委員へ
    - 議会の解散 :: 1/3の署名で選挙管理委員会へ → 住民投票
    - 議員・長の解職 :: 1/3の署名で選挙管理委員会へ → 住民投票
    - 主要公務員の解職 :: 1/3の署名で長へ → 議会（2/3出席・3/4同意）
    - 署名数の緩和 :: 1/3の請求は、有権者40万人を超える部分の要件が軽くなる
  - 住民監査請求 [抑えめ] :: 住民なら1人でもできる。財務会計上の行為・怠る事実が対象。行為から原則1年以内 {gyo-local-audit-one-resident-001} {gyo-local-resident-suit-neglect-001}
  - 住民訴訟 :: 住民監査請求をした住民だけ（監査請求前置）。4類型 {gyo-local-residents-audit-001}
- 公の施設 @gyosei-d/local-structure
  - 利用関係 :: 正当な理由なく拒めない。不当な差別的取扱いの禁止 {gyo-local-public-facility-use-001}
  - 指定管理者 :: 条例で定め、指定には議会の議決が要る。法人その他の団体 {gyo-local-designated-manager-001}
  - 給水契約の拒否 [捨て候補] :: 指導要綱に従わないだけでは「正当の理由」にならない（武蔵野マンション） {gyo-local-water-supply-refusal-001}
