## 法の一般原則（全科目）

- 法理 :: 信義誠実の原則
  別名 :: 信義則
  正確 :: 権利の行使と義務の履行は、相手方の信頼を裏切らないよう誠実に行わなければならないという原則。私法だけでなく、行政上の法律関係にも及ぶ。
  やさしく :: 法律に書いていない細かい場面でも、相手の信頼を裏切るやり方は許されない、という決まりです。\n税務署が納税者に「この申告で大丈夫です」と公式に答え、納税者がそれを信じて申告したとします。後から税務署が「やはり課税する」と言うと、納税者は裏切られたことになります。税金は法律どおりに集めるのが原則なので、信義則で課税処分が違法になるのは特別な事情があるときだけですが、道がゼロではありません。
  根拠 :: 民法1条2項、最判昭62.10.30
  過去問 :: 平成24年問8 令和3年問8 令和6年問10
  カード :: gyo-act-good-faith-tax-001 min-tort-employer-liability-recourse-001

- 法理 :: 権利濫用の禁止
  正確 :: 形式的には権利の行使に見えても、社会的に許される範囲を超えていれば、権利の行使として認められないという原則。行政権の行使にも当てはまる。
  やさしく :: 権利を持っていても、嫌がらせや不当な目的で使うことはできない、という決まりです。\n温泉の湯を引く管が、他人の荒れ地をわずかに通っていました。ある人がその荒れ地を買い、「管を外せ。嫌なら高値で土地を買え」と温泉側に迫りました。裁判所は、この請求を認めませんでした。\n行政も同じです。町が風俗店の開業を止めるためだけに、近くの公園を児童遊園として認可してもらった事件では、その認可は違法とされました。
  根拠 :: 民法1条3項、大判昭10.10.5（宇奈月温泉事件）、最判昭53.5.26
  過去問 :: 令和3年問8
  カード :: gyo-act-good-faith-tax-001

- 法理 :: 禁反言の原則
  別名 :: エストッペル
  正確 :: 自分の言動で相手に一定の事実を信じさせた者は、後からそれと矛盾する主張をすることが許されないという原則。信義則の一つの現れとされる。
  やさしく :: 「前に自分が言ったことをひっくり返して得をしてはいけない」という決まりです。\n息子が親の代理人だと嘘をついて、親の土地を売りました。その後に親が亡くなり、息子が単独で親を相続しました。息子が買主に「親の立場で追認を拒絶します」と言っても通りません。売った本人が、相続した途端に「あの売買は無効だ」と言うのは虫がよすぎるからです。\nこれとは逆に、親が息子を相続した場合は、親は何も嘘をついていないので、親は追認を拒絶できます。
  根拠 :: 最判昭40.6.18、最判昭37.4.20
  過去問 :: 平成28年問28
  カード :: min-general-unauthorized-agency-succession-001

- 法理 :: クリーンハンズの原則
  正確 :: 自ら不法な行為に関わった者は、その不法を理由に裁判所へ救済を求めることができないという原則。民法708条の不法原因給付がその現れとされる。
  やさしく :: 「自分の手が汚れている人は、裁判所に助けを求められない」という決まりです。\n賭博で負けて、相手にお金を払いました。賭博の約束は無効です。しかし、払った人が相手に「無効なのだから返せ」と裁判を起こしても、お金は返ってきません。裁判所は、違法なことをした人の後始末を手伝わないからです。\nただし、不法の原因が受け取った側にだけあるときは、払った側は返還を請求できます。
  根拠 :: 民法708条、最大判昭45.10.21
  過去問 :: 平成22年問33 平成25年問34 令和7年問34

- 法理 :: 安全配慮義務
  正確 :: ある法律関係に基づいて特別な社会的接触の関係に入った当事者は、相手方の生命・健康を危険から保護するよう配慮する義務を信義則上負うという法理。国と公務員の間にも及ぶ。
  やさしく :: 仕事などで「指示する側」と「従う側」の関係に入ったら、指示する側は、相手の命や健康を守る義務を負う、という決まりです。\n自衛隊の車両の整備中に、隊員が事故で亡くなりました。国は「公務員との関係は民間の雇用契約とは違う」と言いたいところですが、最高裁は、国も隊員に対して安全配慮義務を負うとしました。契約書に書いていなくても、この義務は生じます。
  根拠 :: 最判昭50.2.25
  過去問 :: 平成23年問25 平成27年問9 令和5年問9

## 民法

- 法理 :: 権利外観法理
  別名 :: 表見法理
  正確 :: 真実と異なる外観があり、その外観の作出について真の権利者に帰責性があるとき、外観を信頼した第三者を保護するという法理。
  やさしく :: 「嘘の見た目を作った人は、それを信じた人に負ける」という考え方です。\nAさんが借金取りから逃げるために、友人Bさんと示し合わせて、自分の土地の登記を嘘の売買でBさんの名義にしました。Bさんは自分の土地のふりをしてCさんに売り、Cさんは本当にBさんの土地だと信じて買いました。Aさんは、Cさんに「あの売買は嘘だから返せ」と言えません。\n判定は3つです。①嘘の見た目があるか、②本人にその見た目を作った落ち度があるか、③相手がそれを信じたか。3つそろえば、本人が負けます。脅されて土地を売らされた人は②が無いので守られます。\n虚偽表示、表見代理、受領権者としての外観を有する者への弁済、商法の表見支配人は、全部この同じ考え方でできています。
  根拠 :: 民法93条2項・94条2項・109条・110条・112条・478条、商法24条、会社法354条
  過去問 :: 平成20年問27 平成26年問33 平成27年問28 令和元年問28 令和4年問27 令和7年問45
  カード :: min-general-false-representation-third-party-001 min-general-third-party-fraud-duress-001 com-gen-manager-authority-001

- 法理 :: 無権利の法理
  正確 :: 何人も自分が有する以上の権利を他人に譲渡できないため、無権利者から譲り受けた者は原則として権利を取得しないという法理。
  やさしく :: 「持っていないものは売れない」という、当たり前の決まりです。\n人の時計を預かっているだけのBさんが、自分の物のふりをしてCさんに売っても、Cさんは原則として持ち主になれません。無から有は生じないからです。\nこの原則を破って買主を守るのが例外です。民法の問題では、「原則は無権利。では、例外（94条2項の第三者、即時取得、時効）に当たるか」の順に考えます。
  根拠 :: 民法94条2項・162条・192条は、この原則の例外
  過去問 :: 平成23年問29 令和2年問46
  カード :: min-property-good-faith-acquisition-001

- 法理 :: 公示の原則
  正確 :: 物権の変動は、登記や引渡しなど外から認識できる形を備えなければ、第三者に対抗できないという原則。
  やさしく :: 「誰の物かを、外から見える形にしておきなさい」という決まりです。\n土地をAさんから買ったBさんが登記をしないでいる間に、AさんがCさんにも同じ土地を売り、Cさんが先に登記をしました。この場合、Cさんの勝ちです。Bさんが先に買っていても、Bさんは登記をしなかったので負けます。土地は登記、動産は引渡しが、その「見える形」です。
  根拠 :: 民法177条・178条
  過去問 :: 平成25年問28 令和5年問28
  カード :: min-property-registration-bad-faith-001 min-property-prescription-registration-001 min-inheritance-renunciation-registration-001

- 法理 :: 公信の原則
  正確 :: 権利の外形を信頼して取引した者は、実際には権利がなくても保護されるという原則。動産の占有には認められ、不動産の登記には認められない。
  やさしく :: 公示の原則と名前が似ていますが、別の話です。公示は「見える形がないと負ける」、公信は「見える形を信じたら守られる」です。\nBさんが腕時計を持っていれば、普通はBさんの物だと信じます。だから、Cさんが落ち度なくBさんから買えば、本当はAさんの時計でも、Cさんは持ち主になれます（即時取得）。\n一方、土地の登記を信じて買っても、それだけでは守られません。登記に公信力が無いからです。土地の買主を守るのは、94条2項やその類推適用の出番です。
  根拠 :: 民法192条
  過去問 :: 平成23年問29
  カード :: min-property-good-faith-acquisition-001 min-security-collective-movables-001

- 法理 :: 背信的悪意者排除の法理
  別名 :: 背信的悪意者排除論
  正確 :: 不動産の二重譲渡を知っていただけの悪意者は177条の第三者に当たるが、登記の欠缺を主張することが信義に反する背信的悪意者は第三者に当たらないとする判例法理。
  やさしく :: 二重譲渡では、前の売買を知っていても、先に登記をした人が勝ちます。知っていただけなら、自由競争の範囲だからです。\nところが、Aさんの土地をBさんが買ったと知ったCさんが、「Bさんを困らせて高く売りつけてやろう」と考えて先に登記をした場合は別です。Cさんは、登記がないBさんに対しても負けます。\nそのCさんから事情を知らないDさんが買った場合、Dさん自身が背信的悪意者でなければ、DさんはBさんに勝てます。悪さをしたのはCさんで、Dさんではないからです。
  根拠 :: 民法177条、最判昭43.8.2、最判平8.10.29
  過去問 :: 平成24年問29 平成25年問28 令和2年問46 令和5年問28
  カード :: min-property-registration-bad-faith-001

- 法理 :: 私的自治の原則
  別名 :: 契約自由の原則はその代表
  正確 :: 私人間の法律関係は、各人の自由な意思で形成できるという原則。所有権絶対の原則・過失責任の原則と並ぶ近代私法の基本原理とされる。
  やさしく :: 「個人どうしのことは、国が口を出さず、本人たちが決める」という決まりです。\n誰と、どんな内容で契約するかは、本人の自由です。会社がどんな人を雇うかも、原則として会社の自由です。\n憲法の人権規定が会社と従業員のような私人どうしに直接は適用されないのも、この原則があるからです。民法90条などを通じて、著しい差別だけを違法とします。
  根拠 :: 民法521条、最大判昭48.12.12（三菱樹脂事件）
  過去問 :: 平成25年問4 平成27年問5
  カード :: leg-terms-requirement-001 con-gen-private-effect-001

- 法理 :: 過失責任の原則
  正確 :: 故意または過失がなければ、他人に損害を与えても賠償責任を負わないという原則。
  やさしく :: 「注意していたのに起きた事故なら、責任を負わなくてよい」という決まりです。\n責任を負うのは、わざと、またはうっかりで他人に損害を与えた人だけです。誰もが自由に活動できるように、こう定められています。\nこの原則だけでは被害者を救えない場面があるので、次の報償責任・危険責任の考え方が例外を作ります。
  根拠 :: 民法709条
  過去問 :: 平成21年問34 平成23年問53
  カード :: min-tort-medical-standard-001 min-tort-structure-owner-001

- 法理 :: 報償責任・危険責任
  正確 :: 報償責任は、利益を得る者は損失も負担すべきという考え方。危険責任は、危険を作り出した者はそこから生じた損害に責任を負うべきという考え方。無過失責任や中間責任の根拠とされる。
  やさしく :: 過失責任の原則の例外を支える2つの考え方です。\n報償責任は「儲けている人は、損も引き受けなさい」です。お店は店員を使って儲けているので、店員が仕事中に客にけがをさせたら、店も賠償します（使用者責任）。\n危険責任は「危ないものを持っている人は、責任も持ちなさい」です。ブロック塀が倒れて通行人がけがをしたら、まず建物を借りている人（占有者）が責任を負います。借りている人が十分に注意していたなら、次に塀の持ち主が責任を負い、持ち主は過失がなくても逃げられません（工作物責任）。
  根拠 :: 民法715条・717条、国家賠償法2条
  過去問 :: 平成21年問34 平成23年問19 平成28年問34
  カード :: min-tort-employer-liability-recourse-001 min-tort-structure-owner-001 gyo-state-comp-public-facility-001 gyo-state-comp-facility-budget-001

- 法理 :: 信頼関係破壊の法理
  正確 :: 賃貸借のような継続的契約では、形式的に義務違反があっても、当事者間の信頼関係を破壊するとはいえない特段の事情があれば、解除は認められないとする判例法理。
  やさしく :: 賃貸借は長く続く関係なので、小さな違反だけでは追い出せない、という決まりです。\n借主が家賃を1回だけ少し遅らせた程度では、貸主が解除しても、裁判所は解除を認めないことが多いです。貸主と借主の信頼が壊れたとまでは言えないからです。\n反対に、使い方が著しくひどく、信頼が完全に壊れているときは、貸主は催告なしで解除できます。自治体が貸す公営住宅にも、この法理は使われます。
  根拠 :: 民法612条、最判昭28.9.25、最判昭27.4.25、最判昭59.12.13
  過去問 :: 平成22年問10 平成23年問32 平成30年問9
  カード :: min-contract-termination-minor-breach-001

- 法理 :: 担保物権の通有性
  別名 :: 付従性・随伴性・不可分性・物上代位性
  正確 :: 担保物権に共通する性質。債権がなければ成立・存続しない付従性、債権とともに移転する随伴性、全額弁済まで全部に及ぶ不可分性、目的物の代わりの金銭等に及ぶ物上代位性をいう。
  やさしく :: 担保は「お金を貸した話」にくっついて動く、というのが基本です。\n・付従性：借金を全部返したら、抵当権も消えます。\n・随伴性：貸した側が貸金の権利を他人に譲ると、抵当権も一緒に移ります。\n・不可分性：9割返しても、抵当権は土地全部に残ります。\n・物上代位性：抵当に入れた家が焼けたら、抵当権者は家の代わりの火災保険金を押さえられます。ただし、保険金が支払われる前に差し押さえる必要があります。\n留置権には物上代位性がなく、根抵当権は元本が確定するまで付従性と随伴性が弱まります。
  根拠 :: 民法296条・304条・372条・398条の7
  過去問 :: 平成26年問30 平成30年問30 令和6年問30
  カード :: min-security-subrogation-attachment-001 min-security-revolving-mortgage-001 min-obligation-guarantee-prescription-001

- 法理 :: 同時存在の原則
  正確 :: 相続人や受遺者は、被相続人や遺言者の死亡の時に権利能力者として存在していなければならないという原則。胎児については、すでに生まれたものとみなす例外がある。
  やさしく :: 財産を受け取る人は、亡くなる人が死んだ瞬間に生きていなければならない、という決まりです。\nおじいさんが孫に土地を遺贈する遺言を書きましたが、孫が先に亡くなりました。この場合、孫の子どもが代わりに遺贈を受けることはできず、遺贈は効力を生じません。\n例外はお腹の中の子どもです。相続と損害賠償請求については、胎児は生まれたものとみなされます。死産だった場合は、この扱いはなくなります。
  根拠 :: 民法721条・886条・965条・994条1項
  過去問 :: 平成19年問35 平成24年問27
  カード :: min-inheritance-legatee-predecease-001 min-inheritance-substitution-cause-001

- 法理 :: 一身専属権
  正確 :: 特定の個人だけに結び付いた権利で、相続や譲渡の対象にならないもの。民法896条ただし書は、被相続人の一身に専属したものを相続の対象から除く。
  やさしく :: 「その人だけのもの」として、死んだら消える権利です。\n親が生活保護を受ける権利は、親個人の生活を支えるためのものです。親が亡くなっても、子は「親の分の保護を引き続き受ける権利」を相続しません。生活保護の裁判の途中で本人が亡くなると、裁判はそこで終わります（朝日訴訟）。\n一方、親が持っていた普通の貸金の権利や土地は、子が相続します。
  根拠 :: 民法896条ただし書、最大判昭42.5.24（朝日訴訟）
  過去問 :: 平成28年問26 令和4年問8 令和4年問35

## 行政法

- 法理 :: 法律による行政の原理
  別名 :: 法治主義の行政法版
  正確 :: 行政活動は法律に従って行われなければならないという原理。法律の法規創造力、法律の優位、法律の留保の3つからなる。
  やさしく :: 「役所は、国民の代表である国会が作った法律に従って動きなさい」という決まりです。\n・法律の法規創造力：国民の権利義務に関わる新しいルールを作れるのは、法律だけです。\n・法律の優位：役所は、法律に反することをしてはいけません。\n・法律の留保：役所が一定のことをするには、法律の根拠が必要です。\n3つ目で「どの範囲に根拠が要るか」には争いがあり、国民の権利を制限したり義務を課したりするときに必要だとする侵害留保説が、実務の考え方です。このため、お願いである行政指導には、法律の根拠がなくてもよいと整理されます。
  根拠 :: 憲法41条、行政手続法2条6号
  過去問 :: 平成24年問9 平成28年問8 令和2年問8 令和4年問9
  カード :: gyo-legislation-delegation-limit-001 gyo-legislation-circular-nature-001 gyo-enforcement-immediate-compulsion-001

- 法理 :: 比例原則
  別名 :: 警察比例の原則
  正確 :: 行政目的を達成するための手段は、目的に照らして必要な範囲にとどまり、目的と釣り合っていなければならないという原則。
  やさしく :: 「雀を撃つのに大砲を使ってはいけない」という決まりです。\n公務員が1回だけ軽い規則違反をしたときに、役所がいきなり懲戒免職にすると、違反の重さと処分の重さが釣り合いません。処分は裁量の範囲を超えて違法になります。\n平等原則と取り違えないようにします。「他の人と違う扱い」は平等原則、「やり過ぎ」は比例原則です。
  根拠 :: 最判平24.1.16

- 法理 :: 罪刑法定主義
  正確 :: どのような行為が犯罪となり、どのような刑罰が科されるかは、あらかじめ法律で定めておかなければならないという原則。憲法31条・39条などに現れる。
  やさしく :: 「何をしたら、どんな罰を受けるのか」は、先に法律で決めておきなさい、という原則です。\n国王や役人が「気に入らないから牢に入れる」と決められた時代の反省から生まれました。\nここから、慣習を根拠に処罰できない、法律にない行為を似ているからと処罰できない（類推解釈の禁止）、後から作った法律で処罰できない、というルールが導かれます。条例で罰則を定められるのは、地方自治法の委任があるからです。

- 法理 :: 法の支配
  別名 :: 法治主義と対比される
  正確 :: 専断的な権力の支配を排し、権力者も法に拘束されるとする英米法の原理。法の内容の正しさまで問う点で、法律の形式を重視した戦前ドイツの法治主義とは異なるとされる。
  やさしく :: どんな権力者も、法の下にある、という考え方です。イギリスで、国王も法に従うべきだと主張した話がよく出ます。\n似た言葉の「法治主義」は、もともと法律の形さえ整っていれば中身は問わない、という考え方でした。ナチスのような悪い法律も通ってしまう弱点があります。\n「法の支配」は、法律の中身が正しいかまで問います。だから違憲審査制と結び付きます。
  根拠 :: 憲法81条・97条・98条

- 法理 :: 法解釈の方法
  別名 :: 文理解釈・拡張解釈・縮小解釈・類推解釈・反対解釈・勿論解釈
  正確 :: 文理解釈は文言どおりの解釈、拡張・縮小解釈は文言の意味を広げ・狭める解釈、類推解釈は類似の事項に規定を及ぼす解釈、反対解釈は規定のない事項に反対の結論を導く解釈、勿論解釈は当然に及ぶとする解釈。
  やさしく :: 「公園に車を入れてはいけない」という決まりで考えると分かりやすいです。\n・文理解釈：書かれている「車」をそのまま読みます。\n・拡張解釈：バイクも「車」に含めます。\n・縮小解釈：救急車は「車」に含めません。\n・類推解釈：馬は車ではないけれど、似て危ないので同じ扱いにします。\n・反対解釈：車だけ禁止なのだから、馬は入ってよいとします。\n・勿論解釈：車がダメなら、もっと危ない戦車はもちろんダメです。\n刑罰法規では類推解釈が禁止されます。解釈で準用と同じことをするときは「類推適用」と言います。
  根拠 :: 法解釈の用語（条文なし）
  過去問 :: 平成25年問1 平成26年問2

- 法理 :: 条理
  正確 :: 物事の筋道、社会一般の道理のこと。法律にも慣習にもない事件では、明治8年の太政官布告（裁判事務心得）が、条理によって裁判すべきとしたものとして知られる。
  やさしく :: 法律も慣習も何も無い事件が裁判に来たとします。裁判所は「法律が無いから判断しません」とは言えません。人には裁判を受ける権利があるからです。\nそのときは「普通に考えればこうなる」という筋道で判断します。これが条理です。民事ではこのように判断できますが、刑事では罪刑法定主義があるので、条理で処罰することはできません。
  根拠 :: 裁判事務心得（明治8年太政官布告103号）3条、憲法32条
  過去問 :: 令和5年問1

- 法理 :: 処分権主義・弁論主義
  正確 :: 処分権主義は、訴訟の開始・対象・終了を当事者に委ねる原則。弁論主義は、判決の基礎となる事実と証拠の提出を当事者の権能かつ責任とする原則。職権探知主義と対比される。
  やさしく :: 民事裁判は、当事者が主役です。\n処分権主義は「何について裁判するかは本人が決める」です。訴える人がいなければ裁判は始まりませんし、100万円の請求に裁判所が200万円を認めることもできません。\n弁論主義は「事実と証拠は本人が出す」です。裁判所は、当事者が言っていない事実で判決を書けません。時効も、当事者が援用しなければ裁判所は使えません。\n行政不服審査でも、審査請求がなければ審理は始まりません。役所が勝手に始めるという肢は誤りです。
  根拠 :: 民事訴訟法246条、民法145条
  過去問 :: 平成19年問28 平成25年問15

- 法理 :: 悪法もまた法なり
  正確 :: 内容が不当でも法として効力を持つという法格言。法実証主義の考え方で説明され、悪法は法ではないとする自然法思想と対比される。
  やさしく :: 法律の中身がひどくても法律は法律だ、という考え方と、ひどい法律は法律ではない、という考え方の対立です。\n前者は法実証主義と呼ばれ、人が作った法律だけを法と考えます。後者は自然法思想と呼ばれ、人が作る法の上に、正しさの基準があると考えます。\n試験では、この組合せを覚えていれば答えられます。

- 法理 :: 法の不知は許さず
  正確 :: 法律を知らなかったことは言い訳にならないという法格言。刑法38条3項に表れるが、情状により刑を減軽できる。
  やさしく :: 「その法律を知らなかったので無罪にしてください」は通りません。全員が全部の法律を知っていることを前提に、法律は動いているからです。\nただし、事情によって刑を軽くすることはできます。また、事実を知らなかった場合は別です。自分の傘と間違えて他人の傘を持ち帰った人には、盗む故意がありません。\n法格言の形は「事実の不知は許されるが、法の不知は許されない」です。
  根拠 :: 刑法38条3項
  過去問 :: 平成19年問2

- 法理 :: 合意は守られなければならない

  正確 :: 当事者が合意した以上、その合意に拘束されるという法格言。契約の拘束力の根拠とされる。
  やさしく :: 約束は守らなければならない、という当たり前の決まりです。\n一度契約すると、「気が変わった」という理由だけでは抜けられません。私的自治で自由に決めてよいからこそ、決めたことには責任を持ちます。\nだから、解除やクーリング・オフのように約束から抜けられる場面は、法律や契約に特別に定めがあるときだけです。
  根拠 :: 民法522条
