# 行政書士・○×学習カード作成ルール

このルールは行政法だけでなく、今後追加する憲法・民法・商法・基礎法学・一般知識のカードにも適用する。

## 1. カードの基本構造

- `subjectId` は科目を表す安定した英数字IDにする。画面表示名は `category` に入れる。
- 回答履歴との互換性を保つため、現在の `studyDecks[0].id` は変更せず、今後の科目も同じ1デッキへ追加する。科目の切替はデッキ分割ではなく `subjectId` で行う。
- `topic` は科目内の分野、`subtopic` は1枚のカードで覚える一つの論点にする。
- Aは試験で○×判定できる一つの命題にする。複数の独立した条件を一文に詰め込まない。
- Bはやさしい言い換えを2案用意し、`variants.b`と`variants.bCasual`へ保存する。
- Cは**Aの命題を最短にした形**にする。「正しい結論の要約」ではない。
- **Cには、その結論が成り立つ場面を必ず残す。** 短くするために場面を落とすと、別の制度の話と区別がつかなくなる。
  - 悪い例: `形式不備 → 補正を求めるほかなく、拒否できない`
  - 良い例: `申請 → 形式上の要件に不備 → 補正を求めるほかなく、拒否できない`
  - 「申請なのか審査請求なのか」「申請に対する処分なのか不利益処分なのか」で結論が変わる論点が多い。
    その分かれ目になる語をCの先頭に置く。矢印でつないで場面 → 条件 → 結論の順に並べると短いまま残せる。
- `correction`（画面では「正しい形で覚えると」）は、Aのどこがどう違うのかを**条文番号付きで**書く。
  ひとことの言い換えで終わらせない。Aが複数のことを言っている肢なら、**その全部**に答える。
  たとえばAが「補正しなければならない」「補正なしに拒否してはならない」の2つを言っているなら、
  correction も両方に触れる。
- 普通の解説、深掘り、根拠、常識力、実際の肢をカードごとに持つ。

## 1.1 出題された論点だけをカードにする

このサービスは**頻出論点を○×にする教材**であり、法改正の解説サイトではない。

- 新しいカードを作る前に、非公開編集データの `all_subjects/`（平成18〜令和7年度・1,139問）を
  検索し、**その論点を直接問う肢が実際にあること**を確認する。1問も見つからない条文だけを
  根拠にカードを作らない。
- **号番号・項番号のずれをひっかけとして扱わない。** 本試験が問うのは条文の結論であって、
  「これは何号か」ではない。条文番号は `correction` と `legalBasis` へ正確に書けば足りる。
- 法改正は独立したカードにせず、**既存の頻出カードの中身を現行法へそろえる形**で反映する。
  取得元教材が改正前の条数を書いている場合は、こちらの条数だけを現行に直す。
- 2026-07-28に「住民票の記載事項に氏名の振り仮名が含まれる」を1枚のカードにしたが、
  振り仮名は令和7年5月26日施行で、令和7年度試験の基準日（令和7年4月1日）より後にあたり、
  過去20年で一度も出題されていない。号ずれをひっかけとした説明もあわせて誤りだったため、
  2026-07-29に取り下げ、記載事項カードの一項目として残した。

## 1.15 ○と×のバランスを必ず確認する

**科目を追加したら、その科目の中で○と×がどちらかへ寄っていないかを数える。**
2026-07-29に憲法20枚を作ったとき、**20枚すべてが×**になった。誤りの肢は解説の題材として
書きやすいので、放っておくと自然に×へ寄る。この状態では、**×と答え続ければ全問正解できて
しまい、カードが問題として成立しない。**

- 目安は、科目ごとに**○が3〜5割**に収まること。
- ○のカードを作るときは、その設問の**正解肢の原文**をAに使う。判例や条文の言い回しを
  そのまま覚える練習になるので、×のカードより学習効果が高い場面もある。
- 数え方:

```bash
/opt/homebrew/bin/python3.12 -c "
import json,os
from collections import Counter
b=json.load(open(os.path.expanduser('~/.local/share/yuki-services/gyousei-lab/gyousei-production.json')))
c=b['explanationCards']
for s in sorted({x['subjectId'] for x in c}):
    sub=[x for x in c if x['subjectId']==s]; n=Counter(x['correct'] for x in sub)
    print(f'{s:22} ○{n[True]:3d} ×{n[False]:3d} ({n[True]/len(sub)*100:.0f}%)')
"
```

## 1.2 元問題へのリンク

- カードには必ず `sourceRefs` を持たせ、そこから画面の「元問題」リンクを作る。
  `relationship` が `provider-explanation-primary` / `written-origin` / `direct-topic` の
  いずれかを、そのカードの出どころとして先頭に置く。
- リンクURLは `related_question_source.json` の `records` から引く。カード側にURLを直接書かない。
  合格道場のページが `providerUrl`、試験実施機関のPDFが `officialQuestionUrl` で、
  両者が同じ値のときは公開bundle側で `officialQuestionUrl` を落とす。

## 2. B・CはAと同じ結論を保つ（最優先）

**A・B1・B2・Cは、4つとも回答ボタンより上に表示される。** `static/index.html` の
`.study-variants` は `.study-answer-buttons` より前にある。だから、

> **B・Cは、Aと同じ結論の文でなければならない。**
> Aが誤りの命題なら、B・Cも同じ誤りの命題を平易にしただけの文にする。

これを外すと、B・Cを読んだ時点で○×が分かってしまい、カードが問題として成立しない。
2026-07-28の点検では、98枚中44枚（行政法32・基礎知識12）がこの違反をしていた。

### やってはいけない書き方

| 種類 | 例 | なぜだめか |
| --- | --- | --- |
| 逆の結論 | Aが「復権後も資格なし」／Bが「復権すればまた資格を持てます」 | 答えそのもの |
| 否定でほのめかす | 「〜というわけではありません」「〜する必要はありません」 | 同上 |
| メタ解説 | 「問題文は①しか選べないように書いているので、そこがおかしい部分です」 | 同上 |
| 正解の条文を書く | Aが「2年」／Bに「必要な年数は通算20年」 | 同上 |
| 引用型の文体 | 「この命題は〜と言っています」「この文は〜としています」 | 民法8枚がこの型で、使っているのが×のカードだけだったため、言い回しだけで答えが割れていた |
| 並びと結論の矛盾 | 「同意が要らないのは次の3つ」と並べた直後に「②は同意が必要」 | 読み手が矛盾に気づいて答えを逆算できる |

### 書き方

**断定型で統一する。** Aの主張を、そのまま平易な断定文にする。誤った命題でも断定文で書く
（Aがすでに断定文なので、これで増える害はない）。「この文は〜と言っています」という
引用の型は使わない。

Aを判定するのに必要な周辺知識（用語の定義、場面、条件の分解、制度の全体像）はBへ置いてよい。
ただし**それ自体でAの真偽が決まってしまう知識は、Bから外して回答後の解説へ回す**。
`correction`・`explanations`・`memoryPoint` は回答後にしか出ないので、正解はそちらへ書く。

## 2.1 Bのやさしい言い換え

- 頭が回っていないときでも、一度で場面を想像できる言葉を使う。
- 1行の雑な要約で終わらせず、誰が・いつ・何をできるかを平易に書く。
- 専門用語を専門用語のまま言い直さない。最初に出る専門用語はその場でほどく。
- 1案目は日常の場面から説明し、2案目は「用語からほどく」「条件を並べる」「時間の流れで追う」など、問題に合う方法を選ぶ。
- 短さだけを目的にしない。最短の確認はCが担当する。
- 1段落を長くしすぎない。改行は意味の切れ目だけに使う。

## 3. ⑤ 実際の肢・本番での聞かれ方

- 平成28年度以降の実際の過去問肢だけを表示する。
- 同じ命題だけでなく、逆向き、条件、例外、直接比較も含める。
- 組合せ問題・個数問題の肢も表示してよい。元の問題の `questionFormat` を `combination` にすると、画面のfooterへ「組合せ問題の肢」と出る。記述式は⑤へ出さず、頻度だけへ反映する。
- 全カードが⑤の肢を1本以上持つようにする。関連出題があるのに⑤が空のままのカードを作らない。
- 単に同じ章に出ただけの `same_topic` は、学習上有用な場合だけ表示し、頻出度には数えない。
- 平成18〜27年度の問題文は表示せず、内部の頻出度判定だけに使う。
- 同じ年度・同じ問題の複数肢や別名データは、頻出度では1問として数える。
- 肢は原文のまま表示するため、肢の本文へ装飾記法を書かない。目立たせたい語はカードの `evidenceHighlights`（語の配列）に入れると、肢の中の一致部分だけが表示上ハイライトされる。
- 肢が「携帯電話番号」のような**語句だけ**の場合は、肢データの `contextSummary` に何を問われた項目かを1行で書く。画面では肢本文の上に小さく出る。肢の原文は書き換えない。
- **法改正で結論が変わった肢は⑤へ載せない。** 例として、令和3年改正で廃止された行政機関個人情報保護法を前提とする平成29〜令和3年度の基礎知識の肢は採用していない。載せるのは、`examEvaluation` と `currentEvaluation`（`currentLawAsOf = 2026-04-01`）が一致することを条文で確かめた肢に限る。

## 4. ⑥ 似た制度・他分野との違い

- 試験で本当に混同しやすく、結論や要件の違いを短く説明できる場合だけ `crossFieldComparisons` を付ける。
- ないカードには空配列を入れ、画面には⑥自体を表示しない。
- 「同じ行政法だから」など広すぎる関連付けはしない。
- `title` は何を混同しやすいか、`explanation` は両制度の違い、`memoryCue` は見分ける着眼点を書く。
- 対応する学習カードが存在するときだけ `relatedCardId` を付ける。
- 将来は科目をまたぐ比較も同じ構造で扱う。例: 行政法と民法、憲法と行政法。

## 4.1 ⑦ 法律ごとの結論くらべ（`comparisonTable`）

行政法は、**行政手続法・行政不服審査法・行政事件訴訟法で同じ場面の結論が変わる**ところが本試験の
事故多発地点である。⑥が1対1の比較なのに対し、⑦は3つ以上を同じ列で並べる表として持つ。

- `title`: 何を比べているか。「出てきた書面に不備があったとき、補正させるかどうか」のように場面で書く。
- `rows`: 2〜4行。`label`（法律名）/ `article`（条文）/ `rule`（その法律での扱い）/ `conclusion`（短い結論）。
  `label` の重複は不可。対応する規定がない法律も、`rule` に「対応する規定はない」と書いて1行として置いてよい。
- `memoryCue`: どこで見分けるか。**なぜそう分かれるのかの理由**を書く。並べただけでは覚えられない。
- **⑦の本文には装飾記法を使わない。** 表の中は素の文字列として表示する。
- 全カードに付けるものではない。三法で結論が分かれることを本当に確認できた論点だけに付ける。

比較の理由は、⑦の`memoryCue`だけでなく②深掘りの「制度の背景・理由」にも書く。
たとえば行政手続法7条が「補正または拒否」で、行政不服審査法23条・民事訴訟法137条が「補正命令が義務」
なのは、前者が**これから権利を得ようとする入口**（拒否されても理由が示され、争えて、出し直せる）であるのに対し、
後者が**すでに受けた不利益を争う最後の入口**（期間制限があり、閉ざすと二度と争えない）だからである。
このレベルまで書いて初めて、暗記ではなく理解になる。

## 5. 解説図と画像

- 全体マップや比較表は独立した「図で整理」ページだけに置く。
- 学習カード本文と図版は別々に管理する。

## 6. 大量データでの追加手順

1. 科目ごとに過去問の生データと候補肢を保存する。
2. 補助索引で同一分野候補と分野横断候補を別々に抽出する。
3. 問題単位に重複をまとめて頻出度を一次判定する。
4. 別担当で頻出度と関連範囲を再確認する。
5. A・B二案・C・解説・常識力・⑤・必要な⑥を作る。
6. schema、bundle、API、PC・スマホ画面を検証してから本番へ反映する。

過去問原文と記述式にも `subjectId` を付ける。画面は学習カード、原問、記述式の三か所で同じ科目カタログを使い、件数を「行政法220問」のようにコードへ固定しない。

自動類似度は候補を探す補助に限る。最終的な「同じ論点」「直接比較」「単に同じ分野」の区別は、カード単位の編集判断として保存する。

## 7. 本文の文字装飾

**装飾は飾りではなく、文の役割を色で固定するための記号**である。集中力が落ちているときでも、色を追うだけで「誰が・どんな条件で・どうなるか」を拾えることを目的とする。だから**同じ色は全カードで必ず同じ意味**にする。カードごとに好きな色を選ばない。

### 7.1 色と役割の対応（全カード共通・変更禁止）

| 記法 | 見た目 | 役割 | 何を囲むか |
| --- | --- | --- | --- |
| `%%語%%` | 青いチップ | **だれ** | 人・立場・当事者。保証人、後順位抵当権者、被保佐人、買主、行政庁、審査請求人 |
| `__語__` | 緑の下線 | **条件・期間** | 要件、場合分け、数字、期限。1か月以上、善意無過失、期間内に、書面によって |
| `**語**` | 濃い緑の太字 | **用語・制度** | その論点の中心にある法律用語。詐術、即時取得、追認、対抗、教示 |
| `==語==` | 黄色のマーカー | **結論** | できる／できない、有効／無効、認められる。1文につき原則1か所（下の7.2参照） |
| `!!語!!` | 赤字 | **判定の分かれ目** | 本試験で書き換えられる箇所、数字、例外、取消権を失う、対抗できない |
| `@@語@@` | 灰色の小さめ | **根拠・補足** | 条文番号、判例番号、年度の出典。民法145条、最判平11.10.21 |

読む順は「**青（だれ）→ 緑下線（条件）→ 黄（結論）**」。この3つだけ追えば命題が再構成できる状態を目指す。

### 7.2 使い方の決まり

- 対象は `variants.a`・`b`・`bCasual`・`c`、`correction`、`memoryPoint`、`explanations` の各文。⑤の肢は原文なので装飾しない（`evidenceHighlights` を使う)。
- **Aには赤（`!!`）を使わない。** Aは本試験の肢の見え方をそのまま出す場所なので、こちらで印を付けない。青・緑下線・黄・太字は使ってよい。
- **赤は「誤っている箇所」ではなく「判定の分かれ目」を指す。** 本試験がここの数字・主体・期間を書き換えてくる、という印である。この意味なら**○のカードにも赤を付けられる**ので、赤の有無だけで答えが割れることはない。B・Cで使ってよいのはこの意味に限る。
  - 良い例（×のカード）: 「!!復権の前か後かで結論が動くのか!!が、判定の分かれ目です」
  - 悪い例: 「!!「復権をした後においても」が誤りです!!」→ これは`correction`に書く。
- **読点で区切られたひとまとまりにつき装飾は1か所まで**、1文では多くても4か所。全部の語を装飾すると、どれも目立たなくなる。
- **黄（`==`）は1文につき原則1か所。ただし対になった2つの結論を1文で示すときだけ2か所まで。3か所以上は不可。** 「明渡しは単独で==請求できる==が、賠償は==請求できない==」のように、**対比そのものが論点**なら、片方だけ黄にするほうが読み違いを生む。単に結論めいた語をいくつも黄にするのは不可。
- **同じ語を同じ文で何度も装飾しない。** 初出だけを装飾する。
- 記法の入れ子は不可。1か所に2種類を重ねない。**同じ記法**を続けて隣り合わせにもしない（`!!A!!!!B!!` ではなく `!!AB!!`）。種類の違う記法が続くのは可で、`==結論==@@（民法145条）@@` のように結論の直後へ根拠を置く形は既存カードでも使っている。
- 装飾は文言を変えない。記法を取り除いた結果が元の本文と完全一致することを、適用時に必ず機械照合する。
- 迷ったら装飾しない。無装飾の地の文があるほうが、装飾した箇所が効く。

### 7.3 例

```
A: %%後順位抵当権者%%は、先順位抵当権の被担保債権の**消滅時効**を==援用することができない==。

correction: %%保証人%%・%%物上保証人%%・%%第三取得者%%は@@民法145条@@の明文で援用できるが、
%%後順位抵当権者%%は__権利の消滅について正当な利益を有する者__にあたらず、!!援用できない!!。
```
