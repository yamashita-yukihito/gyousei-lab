# 行政書士・○×学習カード作成ルール

このルールは行政法だけでなく、今後追加する憲法・民法・商法・基礎法学・一般知識のカードにも適用する。

## 1. カードの基本構造

- `subjectId` は科目を表す安定した英数字IDにする。画面表示名は `category` に入れる。
- 回答履歴との互換性を保つため、現在の `studyDecks[0].id` は変更せず、今後の科目も同じ1デッキへ追加する。科目の切替はデッキ分割ではなく `subjectId` で行う。
- `topic` は科目内の分野、`subtopic` は1枚のカードで覚える一つの論点にする。
- Aは試験で○×判定できる一つの命題にする。複数の独立した条件を一文に詰め込まない。
- Bはやさしい言い換えを2案用意し、`variants.b`と`variants.bCasual`へ保存する。
- Cは結論を短く確認するための読み替えにする。
- 普通の解説、深掘り、根拠、常識力、実際の肢をカードごとに持つ。

## 2. Bのやさしい言い換え

- 頭が回っていないときでも、一度で場面を想像できる言葉を使う。
- 1行の雑な要約で終わらせず、誰が・いつ・何をできるかを平易に書く。
- 専門用語を専門用語のまま言い直さない。最初に出る専門用語はその場でほどく。
- 1案目は日常の場面から説明し、2案目は「用語からほどく」「条件を並べる」「時間の流れで追う」など、問題に合う方法を選ぶ。
- 短さだけを目的にしない。最短の確認はCが担当する。
- 1段落を長くしすぎない。改行は意味の切れ目だけに使う。

## 3. ⑤ 実際の肢・本番での聞かれ方

- 平成28年度以降の実際の過去問肢だけを表示する。
- 同じ命題だけでなく、逆向き、条件、例外、直接比較も含める。
- 組合せ問題・個数問題の肢も表示してよい。元の問題の `questionFormat` を `combination` にすると、画面のfooterへ「組合せ問題の肢」と出る。記述式は⑤へ出さず、頻度だけへ反映する。
- 全カードが⑤の肢を1本以上持つようにする。関連出題があるのに⑤が空のままのカードを作らない。
- 単に同じ章に出ただけの `same_topic` は、学習上有用な場合だけ表示し、頻出度には数えない。
- 平成18〜27年度の問題文は表示せず、内部の頻出度判定だけに使う。
- 同じ年度・同じ問題の複数肢や別名データは、頻出度では1問として数える。
- 肢は原文のまま表示するため、肢の本文へ装飾記法を書かない。目立たせたい語はカードの `evidenceHighlights`（語の配列）に入れると、肢の中の一致部分だけが表示上ハイライトされる。

## 4. ⑥ 似た制度・他分野との違い

- 試験で本当に混同しやすく、結論や要件の違いを短く説明できる場合だけ `crossFieldComparisons` を付ける。
- ないカードには空配列を入れ、画面には⑥自体を表示しない。
- 「同じ行政法だから」など広すぎる関連付けはしない。
- `title` は何を混同しやすいか、`explanation` は両制度の違い、`memoryCue` は見分ける着眼点を書く。
- 対応する学習カードが存在するときだけ `relatedCardId` を付ける。
- 将来は科目をまたぐ比較も同じ構造で扱う。例: 行政法と民法、憲法と行政法。

## 5. 解説図と画像

- 全体マップや比較表は独立した「図で整理」ページだけに置く。
- 学習カード本文と図版は別々に管理する。

## 6. 大量データでの追加手順

1. 科目ごとに過去問の生データと候補肢を保存する。
2. 補助索引で同一分野候補と分野横断候補を別々に抽出する。
3. 問題単位に重複をまとめて頻出度を一次判定する。
4. 別担当で頻出度と関連範囲を再確認する。
5. A・B二案・C・解説・常識力・⑤・必要な⑥を作る。
6. schema、bundle、API、PC・スマホ画面を検証してから本番へ反映する。

過去問原文と記述式にも `subjectId` を付ける。画面は学習カード、原問、記述式の三か所で同じ科目カタログを使い、件数を「行政法220問」のようにコードへ固定しない。

自動類似度は候補を探す補助に限る。最終的な「同じ論点」「直接比較」「単に同じ分野」の区別は、カード単位の編集判断として保存する。

## 7. 本文の文字装飾

**装飾は飾りではなく、文の役割を色で固定するための記号**である。集中力が落ちているときでも、色を追うだけで「誰が・どんな条件で・どうなるか」を拾えることを目的とする。だから**同じ色は全カードで必ず同じ意味**にする。カードごとに好きな色を選ばない。

### 7.1 色と役割の対応（全カード共通・変更禁止）

| 記法 | 見た目 | 役割 | 何を囲むか |
| --- | --- | --- | --- |
| `%%語%%` | 青いチップ | **だれ** | 人・立場・当事者。保証人、後順位抵当権者、被保佐人、買主、行政庁、審査請求人 |
| `__語__` | 緑の下線 | **条件・期間** | 要件、場合分け、数字、期限。1か月以上、善意無過失、期間内に、書面によって |
| `**語**` | 濃い緑の太字 | **用語・制度** | その論点の中心にある法律用語。詐術、即時取得、追認、対抗、教示 |
| `==語==` | 黄色のマーカー | **結論** | できる／できない、有効／無効、認められる。1文につき最大1か所 |
| `!!語!!` | 赤字 | **ひっかけ・失うもの** | 逆を答えさせる箇所、例外、取消権を失う、対抗できない |
| `@@語@@` | 灰色の小さめ | **根拠・補足** | 条文番号、判例番号、年度の出典。民法145条、最判平11.10.21 |

読む順は「**青（だれ）→ 緑下線（条件）→ 黄（結論）**」。この3つだけ追えば命題が再構成できる状態を目指す。

### 7.2 使い方の決まり

- 対象は `variants.a`・`b`・`bCasual`・`c`、`correction`、`memoryPoint`、`explanations` の各文。⑤の肢は原文なので装飾しない（`evidenceHighlights` を使う)。
- **Aには赤（`!!`）を使わない。** Aは○×を判定する問題文で、誤りの箇所を赤くすると答えが割れる。Aで示すのは「どこを判定すればよいか」までにとどめる。青・緑下線・黄・太字は使ってよい。
- **読点で区切られたひとまとまりにつき装飾は1か所まで**、1文では多くても4か所。全部の語を装飾すると、どれも目立たなくなる。
- **同じ語を同じ文で何度も装飾しない。** 初出だけを装飾する。
- 記法の入れ子は不可。1か所に2種類を重ねない。記法どうしを隣り合わせにもしない（`!!A!!!!B!!` ではなく `!!AB!!`）。
- 装飾は文言を変えない。記法を取り除いた結果が元の本文と完全一致することを、適用時に必ず機械照合する。
- 迷ったら装飾しない。無装飾の地の文があるほうが、装飾した箇所が効く。

### 7.3 例

```
A: %%後順位抵当権者%%は、先順位抵当権の被担保債権の**消滅時効**を==援用することができない==。

correction: %%保証人%%・%%物上保証人%%・%%第三取得者%%は@@民法145条@@の明文で援用できるが、
%%後順位抵当権者%%は__権利の消滅について正当な利益を有する者__にあたらず、!!援用できない!!。
```
